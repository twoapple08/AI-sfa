# C안 최종 시험 (봉인, 2026-11-02)

- 사용자 결정(11-02): P-01·P-03 — 새로 받은 작품으로 따로 최종 시험(C안). 학습·검증·설정 선택에 쓰지 않고 마지막에 한 번만 쓴다.
- `makgora/`: '막고라' 11컷(243장, 24/24). 같은 작가의 옛 작품이 학습 자료에 있으나 기술이 크게 늘어난 새 작품(사용자). **다른 작가 일반화의 증거가 아니며, 독립 단위는 작품 1개에 가깝다.**
- 앱에서 내보낸 영상(854×480, 245장)은 비공개로 Drive에만 둔다(`manifest.json`의 video). 각 파일 첫 장의 영상 위치는 `video_start` — 서버 렌더와 영상 평균 차 ≤ 2(레이어 투명도 반영 뒤).
- 레이어 투명도(LayerDef `Opacity`)를 7파일이 쓴다. 수집 441파일에 없던 새 앱 기능이라 정답 문장에 표현이 없다 → 그 장은 만점 불가, 결과를 따로 보고한다.
- `chute/`: 사용자가 처음 보는 작가(11-02, 학습 자료에 없을 가능성 높음)의 스틱맨 동작 1컷(40장). 앱 영상(30fps, 100장, Drive)에서 SFA 장마다 약 2.5번씩 나온다. 학습 자료와 같은 그림 없음.
- 다음: 다른 작가의 작품을 더 모으면 같은 방식으로 추가(작가마다 1–2작품, 가능하면 앱 영상도).
