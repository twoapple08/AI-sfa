## 파일 확인(Claude 11-06, char_sheet.read_all)
- 채운 칸: 정면·우반측면·우측면·우후반측면·후면·좌후반측면·좌측면·좌반측면(8). 위·아래 칸은 비어 있음 — 지금 동작 생성은 좌우 방향(yaw)만 쓰고 위아래(pitch)는 쓰지 않아 당장 필요 없음.
- 칸마다: 망토(몸통에 붙은 곡선 3개, 흔들림 계산 대상), 가면(머리에 붙은 선 5개). 가면은 뒤쪽 3면(우후반측면·후면·좌후반측면)에서 빠짐 — 정상.
- **붉은 날은 시트에 그려져 있지 않음.** 코드는 오른 아래팔(farm_r) 가까이 그린 액세서리를 아래팔에 붙여 따라 움직이게 한다 → 시트에 날을 그려 주면 바로 붙음.
