**3. ‘자연스러운 스틱맨 움직임’의 정의**

제안하는 정의는 다음과 같습니다.

> **동작의 의도와 힘의 흐름이 읽히고, 지지·접촉·타격 관계가 일관되며, 정지와 이동 간격이 의도대로 유지되는 움직임.** **[③]**

부드러움은 그중 하나일 뿐입니다. 좋은 타격도 순간적으로 큰 가속·급정지를 갖습니다. 모든 좌표를 강하게 평활화하면 떨림은 줄지만 타격감도 사라질 수 있습니다. **[②]**

원본 카메라 투영을 그대로 복제할지, 스틱맨식으로 재연출할지는 **학습 자료의 용도를 나눠 판단**하는 것이 좋겠습니다.

- **원본 대응 기록:** 화면 관절·타이밍·가림·카메라 상태를 가능한 만큼 보존합니다. 관측 근거로 사용합니다.
- **생성기용 목표 동작:** 스틱맨 비율과 구조에서 읽히도록 재구성하되, 준비→실행→접촉→반동의 사건 순서와 시간을 보존합니다.

둘을 연결해 보관하고, 재연출한 부분을 표시하자는 제안입니다. 원본 추적값과 편집된 목표를 구분하지 않으면 생성기는 관측 오류와 연출 선택을 같은 종류의 정답으로 배우게 됩니다. **[③]**

**조각 길이는 안정적인 기본값으로 삼되, 모든 상황의 절대 규칙으로 확정하지 않겠습니다.** 고정 길이의 3D 팔도 카메라를 향하면 화면에서 짧아집니다. 따라서 ‘원본 투영 그대로’와 ‘화면상 모든 뼈 길이 고정’은 항상 동시에 만족하지 않습니다. **[②]**

수집 파일 4개의 길이가 거의 일정하다는 요청 문서의 관측은 중요한 기준이지만, 모든 회전·원근 표현의 정답을 증명하지는 않습니다. 고정 길이 버전과 제한적 단축을 허용한 버전을 같은 장면에서 비교할 필요가 있습니다. **[① 문서 인용, ③ 제안]**

24/24 출력에서도 원본이 의도적으로 멈춘 장은 같은 자세로 유지할 수 있어야 합니다. **24장 모두 저장하는 것과 매 장 새로운 중간자세를 만드는 것은 별개의 선택**입니다. 앱의 추가 트위닝에 맡기지 않고, 각 장의 자세를 명시하는 것을 전제로 합니다. **[① 출력 조건, ③ 해석]**

**4. 추천 경로와 차선**

**추천: 사람 검수 중심의 2D 재구성**

`컷·시간표 확인 → 인물 영역 지정 → 핵심 자세·접촉 표시 → 2D 추적/포즈 초기안 → 목표 스틱맨 골격 피팅 → 장별 수정 → SFA → 앱 검증`

핵심은 추적기를 정답 판정자로 쓰지 않는 것입니다. 사람은 준비·극점·접촉·반동, 몸이 돌아 좌우가 모호해지는 장을 지정하고, 모델은 그 사이의 반복 작업을 줄입니다. 스미어 장은 전후 동작과 타격 방향을 보고 별도로 판단합니다. **[③]**

이 경로를 우선 제안하는 이유는 최종 목표가 2D 편집 골격이고, 수정 근거를 직접 남기기 쉽기 때문입니다. **3D보다 품질이 높다는 실측 결론은 아닙니다.**

**차선: 사람의 제약을 받는 3D 복원·재투영**

`같은 영상·키포즈 → GVHMR 또는 WHAM 초기안 → 관측 관절·접촉을 이용한 3D 후최적화 → 목표 골격으로 변환 → 2D 재투영·수정 → SFA`

3D의 가치는 몸 돌리기·가림을 일관되게 해석하거나 시점을 바꾸는 데 있습니다. 하지만 최종 2D에서 이득이 사라지고 수정량만 늘어난다면 채택 이유가 약해집니다. 반대로 해당 구간의 자세·접촉 오류가 줄고 사용자가 결과를 선호하면 주 경로로 올려야 합니다. **[③]**

**공통 출력 조건 [①·③]**

기본 템플릿의 연결을 복제하고, 같은 역할의 AO ID는 장 사이에 유지합니다. AP ID는 파일 전체에서 새로 발급하고 AC를 해당 장의 점으로 다시 연결합니다. 머리 원의 지름 끝점을 모델의 코·눈 좌표로 오인하지 않아야 합니다. 정적 검사에 통과한 뒤에도 앱에서 골반 이동·팔다리 굽히기·저장 후 다시 열기를 확인해야 편집성을 입증할 수 있습니다.

**5. 가장 작은 첫 실험**

**nian41의 1초 구간 두 개, 총 48장**을 제안합니다. **[③]**

| 구간 | 선정 기준 | 가르는 주장 |
|---|---|---|
| A: 관측이 쉬운 동작 | 컷 없이 한 인물의 몸통·사지가 대체로 보이고 준비와 실행이 포함됨 | 관측이 충분할 때도 스틱맨 재구성 자체가 어색한가? |
| B: 회전·가림 동작 | 컷 없이 몸 돌리기 또는 사지 가림이 포함되고 전후 자세는 판독 가능 | 3D 경유가 어려운 구간의 해석을 실제로 개선하는가? |

방법별 출력을 보기 **전에** 구간을 고르고 원본 파일·시간·프레임 번호를 고정합니다. 가장 쉬운 장면 하나만으로 결론내리지 않습니다.

나카무라는 별도의 **타격 전후 1초·24장**을 추가해 몸의 정지·접촉·이펙트 발생 시점의 관계를 평가합니다. 처음부터 이를 전신 골격 복원 정확도의 대표 시험으로 삼지는 않습니다. 이 구분은 애니메이터별 고정 범위를 따릅니다. **[① 범위, ③ 시험 설계]**

실험은 두 단계로 진행하면 원인을 분리할 수 있습니다.

1. **CPU 진단:** 같은 수작업 관측 좌표와 접촉 표시를 사용해 2D 골격 피팅과 작은 3D 골격 피팅·재투영을 비교합니다. 검출기 성능을 잠시 배제하고, 표현 방식의 차이를 봅니다. 단안 3D는 여러 해가 가능하므로 복수 초기값을 시험합니다.
2. **GPU 실용성 시험:** 2D 추적기와 3D 복원기를 각각 초기안으로 사용합니다. 동일한 수정 허용량에서 품질을 비교하고, 별도로 합격 품질까지 필요한 수정량도 기록합니다.

첫 단계는 GPU 없이 가능합니다. 두 번째는 모델 학습 없이 짧은 클립 추론부터 시작하고, T4 한 장에서 시간·최대 메모리를 측정합니다. **실행시간을 지금 보장할 근거는 없습니다.** 문서에 적힌 기존 학습 종료를 실제로 확인하고 사용자 허락을 받은 뒤 실행합니다. **[③]**

**잠정 합격선 [③ — 실측 후 조정 가능]**

- SFA의 잘못된 참조·AP ID 중복·관절 분리: **0건**.
- 사용자에게 승인된 목표 자세 대비 관절 오차: 몸 높이로 정규화해 **중앙값 3% 이하, 95백분위 8% 이하**.
- 접촉·타격 시점: 원본에서 사건 시점이 명확한 경우 **±1장 이내**.
- 명시적으로 지지한 발의 접지면 상대 이동: 한 지지 구간에서 **몸 높이의 2% 이하**. 의도적 미끄러짐은 별도 표시.
- 좌우 오인·잘못된 접촉 관계가 남아 있지 않고, 사용자 정상속도 평가에서 **학습 재료로 사용 가능** 판정.

이 수치는 보편적 자연스러움의 법칙이 아니라 첫 실험의 판정 규칙입니다. 48장으로 전체 방법의 우열까지 일반화하지는 않습니다.
