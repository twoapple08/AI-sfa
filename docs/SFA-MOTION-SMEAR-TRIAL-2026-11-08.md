## 판정과 변형

`tools/sfa_motion_smear.py`는 v18의 현재 리그 ID4560000과 팔4/6·정강이8/10을 전제로 한다. 임의의 SFA에 자동 적용하는 범용 리그 인식기가 아니다.

1. Layer1의 연결된 기존 선 사슬을 효과로 묶는다. 같은 색 인물의 기본 팔꿈치–손목/무릎–발목에 거리로 대응시킨다. 가면/망토/테두리는 판정에서 제외한다.
2. ±2장의 몸통 기준 손발 위치/부위 벡터를 사용한다. 공통 평행이동·균등 스케일 영향은 줄이나 완전한 카메라 추정은 아니다. 숨은 부위/짧은 표본/급격한 이동·크기 변화/먼 효과는 보수적으로 유지한다.
3. 회전형 기준은 각도 변화≥.32rad, 경로 굽힘≥.10, 회전 일관성≥.65, 몸통 길이 기준 속도≥.035다. 회전 조건 미충족 후 부위 길이 변화≥.28/속도≥.055이면 길이 변화형 후보다. **수동 기하 임계값이며 애니메이터의 판단을 학습한 기준이 아니다.**
4. 유형은 효과 단위로 고정한다. 기존 사슬의 불균등 점 배열을 재사용하고 정규화/재샘플링/무작위 지터를 하지 않는다. 붙은 효과는 가장 가까운 원래 접점을 고정한다. 회전형 곡선도 실질 굽힘이 작은 선에는 넣지 않는다.
5. 원본 꺾임을 재사용하지만 기존12~26% 밀도 규칙을 다시 실행하거나 변형 뒤 깊이 비율까지 동일하다고 보증한 것은 아니다. 밀도가 필요하면 검토 후 별도 조정한다. 선택 안 된 분리형만 의도적인 짧은 공백을 만들 수 있다.
6. 새 객체는1.4b 영역, 점은1.95b 이상을 예약해 원본과 분리한다. 같은 논리 객체의 TypeId는 장 사이에 바뀌지 않게 한다. 새 AC는 양방향·동일 좌표로 생성한다.

## 재현·검증·남은 일

테두리 없는 원본 v18 XML을 읽어 `sfa_motion_smear.build(source)` 호출 후 `sfa_outline_trial.build(result, mode='glow', color=0xff303030)`을 호출한다. 생성 SFA ZIP 안 XML을 저장하면 된다. 기존 테두리 판에 중복 실행하지 않는다. ZIP에 관련 코드와 원본 대비 기준 글로우 SFA도 넣었다.

합성7개 테스트는 직선/회전/길이변화 분기, 공통 이동·스케일 불변, 누락/급변 거부, 몸 보존·연결 검사를 다룬다. 실제240장 파일은 원본 노드 보존/새 ID 고유성/곡선 점 수/새 연결 양방향/좌표 일치/객체 종류 일관성/새 선 불투명/ZIP 무결성을 검사했다. 영상 길이·장 수는 ffprobe로 확인했다.

현재는 서버 렌더 비교 시험이며 **실제 앱 표시·편집 추종·사용자 미관 승인 미완**이다. 2D 뼈대만으로 앞뒤 운동이나 의도적인 잔상을 확정할 수 없다. 다음은 비교 영상에서 유형이 어울리지 않거나 접점/밀도가 나빠진 장을 사용자와 고르고 분류 임계값·변형 강도를 보정하는 것이다. 기존240장 자동 누락 탐지 실패와 별개다.
