# 전체 학습 준비 계획 — 2026-10-21

사용자 지시: "모든 걸 다 학습시켜, 기존 학습 방식도 바꿔." 그리고 "제한 두지 말고 할 수 있는 최대한. Colab 클라우드 GPU 가능. 쓸 수 있는 모든 걸 동원하고, 나한테 부탁할 건 전부 말해."

## 1. 바뀌는 학습 방식

| 영역 | 이전(v0.1) | 새 방식 |
|---|---|---|
| 2D 포즈 | YOLO11m-pose | 여러 최신 모델을 표본에서 비교해 가장 좋은 것으로 재추출(애니 그림에 강한 것 우선) |
| 몸 동작 | 펀치 자세 53장 + 규칙 자세 | 3D로 올린 연속 동작 데이터 → 동작 데이터베이스 + 생성 모델(GPU 학습) → 기기용으로 줄임 |
| 평면 | 2D 옆모습 | 3D 리그 + 카메라 투영(단축법·원근·앞뒤 겹침) |
| 카메라 | 없음 | 배경 광류로 카메라 움직임 추정 → 타격 전후 카메라 패턴 학습 |
| 이펙트 | 원·직선, 덩어리 찍기 | 그림 단위 학습: 선 + 밑색 영역 + 반투명 명암 층(포물선 조각, 상한 없음) → 형태·색·변형 생성 모델 |
| 파편 | 원 | 3D 조각(면 3색·테두리·그림자) + 학습한 물리 분포 |
| 출력 | 레이어 1장 | 레이어 5장(배경/그림자/색/선/앞 이펙트), 검은 바탕 가능 |

## 3. 준비 단계 (P0–P6)

| 단계 | 내용 | 실행 위치 | 산출물 |
|---|---|---|---|
| P0 보존·환경 | 서버 임시 자료(자동 태그 26MB, CLIP 52MB, 포즈) Drive 백업, 원본 Drive 경로 대조, Colab 노트북 틀 | 서버 | 백업, 노트북 |
| P1 몸 동작 | 2D 포즈 모델 비교 → 재추출(전 애니메이터의 몸 부분은 §6 확인) → 정리(좌우 뒤바뀜·보간·이상치, 정지 보존) → 3D 올리기 → 리그 A 3D 회전 → 자동 분류(공격·이동·피격·막기·회피·쓰러짐·대기) → 발 접지 | Colab + 서버 | 동작 DB, 라벨, 통계 |
| P2 카메라 | 배경 광류(캐릭터 가림) → 프레임별 카메라 이동·확대·회전 → 타격 ±1초 패턴, 3D 카메라 각도 분포 | Colab + 서버 | 카메라 이벤트 표본 |
| P3 이펙트 그림 | 장면 선별(자동 태그·CLIP·GPT 138개 + 이번에 새로 분할) → 이펙트 분리(SAM 2) → 선화·밑색·명암·하이라이트 층 분해 → 층별 벡터화(상한 없음) → 시간 추적 → 종류별 형태·색·변형 수치 | Colab + 서버 | 레이어 이펙트 사전(Drive만), 통계 |
| P4 파편 | 돌 파편 영상 + 전 애니메이터 파편 장면: 크기·속도·방향·회전·정지·면 색·그림자 분포 | 서버(+Colab 분할) | 파편 분포 |
| P5 SFA 출력 | 레이어 5장 구조, 채우기·반투명·검은 바탕 시험 SFA → 사용자 휴대폰 Stick Fighter 확인, 서버 렌더러 대조 | 서버 + 사용자 | 출력 규격 |
| P6 학습 설계 확정 | 모델 형태·입출력·평가 기준·기기 변환 방법 | 서버 | 학습 계획서 |

순서: P0 → P1·P2·P3·P4 동시(Colab과 서버 CPU 나눠 씀) → P5 → P6 → 본 학습.

## 4. 검증

- 단계마다 수치(재구성 겹침, 색 차이, 관절 오차, 깊이 일관성)를 먼저 보고, 표본 이미지는 최소한으로 본다(전체 약 15–25장).
- 사람 눈 확인이 필요한 곳은 사용자에게 표본을 보낸다.
- 추정·가정과 실측 확인을 구분해 기록한다.

## 5. 사용자에게 부탁할 것

1. **Drive 권한 변경(가장 중요):** 지금 rclone은 `drive.file` 권한이라 Claude가 만든 파일만 보인다. Colab 결과를 Claude가 바로 읽으려면 rclone을 `drive`(전체) 또는 `drive.readonly` 범위로 다시 인증해야 한다. 방법은 별도 안내한다. 이 권한이 없으면 Colab 결과를 매번 대화 첨부로 받아야 한다(20MB·50MB 제한).
2. **Colab 실행:** Claude가 만든 노트북을 순서대로 돌린다. 가능하면 Colab Pro(A100·L4, 긴 런타임)가 품질·속도에 유리하다. 무료 T4도 되지만 큰 모델(Sapiens 대형, GVHMR 등)은 느리거나 메모리가 부족할 수 있다.
3. **Hugging Face 계정 토큰:** 일부 모델 가중치는 로그인이 필요하다. 토큰은 Colab 비밀 값(Secrets)에만 넣고 대화에 붙이지 않는다.
4. **휴대폰 확인:** 시험 SFA를 Stick Fighter로 열어 결과(열림·속도·레이어·반투명·검은 바탕)를 알려 준다.
5. **눈 검수(선택):** 분해·동작 표본을 보고 좋음/나쁨을 알려 준다. GPT에게 맡겨도 된다.
