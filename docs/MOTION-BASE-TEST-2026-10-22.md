# 기초 동작 모델 시험 — MoMask 공개 가중치(학습 없음) (2026-10-22)

목적: '기초 모델 + 우리 자료 추가 학습' 구조의 첫 단계. 공개 글→동작 모델이 기준 프롬프트 1의 동작을 기본기 수준으로 만드는지 서버 CPU로 확인.

## 환경(서버, GPU 없음)
- 코드: github.com/EricGuo5513/momask-codes(얕은 복제, 저장소 밖 scratchpad/motion). 가중치: HumanML3D 학습판(188MB, README의 Google Drive 링크).
- 서버 Python 3.13·numpy 2 호환을 위해 고친 곳(외부 코드라 저장소에 넣지 않음): `numpy.core.umath_tests` → `np.matmul`, `np.float/np.int/np.bool` → 내장형, 글 파일 줄끝 개행 때문에 길이(`#프레임`)가 무시되던 것(`line.strip()`), matplotlib 3D 그림 저장(서버에서 실패) 생략.
- 실행: 문장 5개(아래), 20fps 기준 길이 지정 → CPU 약 40초. 출력: 22관절(SMPL 순서) 3D 좌표 npy + BVH.

## 넣은 문장(기준 프롬프트 1의 동작 부분, 영어)
1. 하늘에서 떨어져 한쪽 무릎·주먹을 짚는 착지(80프레임)
2. 웅크린 착지 자세에서 천천히 일어섬(40)
3. 카메라 쪽으로 천천히 걸어옴(96)
4. 걷다가 점점 빨라져 달리기(80)
5. 오른 주먹을 뒤로 당겼다 강하게 내지름(32)

## 결과(정면 투영 눈 확인)
- 돌아간다: 공개 모델만으로 문장 → 3D 관절이 나온다. 걷기·일어서기는 자연스럽다.
- 1번: 공중에서 내려와 웅크렸다 일어서는 정도. '한쪽 무릎·주먹을 짚는' 슈퍼히어로 착지 자세는 약하다.
- 4번: 가속해서 달리기로 넘어가는 변화가 작다.
- 5번: 앞으로 내지르는 펀치가 아니라 위로 크게 휘두르는 동작에 가깝다.
- 전체가 실제 사람(모캡) 움직임이라 부드럽다. 애니식 끊어짐(2프레임 유지, 빠른 정점)·과장은 없다 → 우리 자료로 입혀야 할 부분이 그대로 보인다.

## SFA 연결 (`tools/motion_to_sfa.py`, 같은 날)
- SMPL 22관절 → 리그 A 모양 14점(직선 TypeId 1 + 머리 원 TypeId 2, AC 연결, AO ID 프레임마다 고정) → 3D 핀홀 카메라 투영 → SFA. 먼 쪽 팔다리 회색(뒤), 선 굵기는 거리에 반비례.
- 시간: 20fps → F(24)로 다시 뽑고 hold 2(2프레임마다 새 자세). 카메라는 키 프레임(인물 기준 상대 위치 가능) 선형 보간.
- 기준 프롬프트 1 동작·카메라만(이펙트·배경 없음): 393프레임(16.4초). 계획 파일 `docs/storyboards/bench01_motion_plan.json`.
- 확인(서버 렌더): 하늘 올려다보기 → 떨어짐 → 착지 → 뒤로 빠지는 카메라 앞으로 걸어옴(점점 작아짐) → 달리기 → 카메라 앞 펀치까지 이어진다.
- 문제: ① 땅·배경이 없어 원근·속도감이 안 보인다. ② 낙하는 기초 모델이 못 만들어 높이를 더해 넣었다(착지 순간 자세가 서 있음). ③ 펀치가 카메라 쪽 내지르기가 아니다. ④ 걷기→달리기 가속이 약하다. ⑤ 길이가 AI 추정(9.6초)보다 긴 16.4초 — 동작 조각 길이를 장면 길이에 맞추는 단계가 아직 없다.
