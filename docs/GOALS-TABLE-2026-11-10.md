# 목표 정리표 (2026-11-10)

근거 문서: 정본 조건 `docs/REPLAN-CONDITIONS-2026-11-05.md`, 계획·체크 목록 `docs/REPLAN-PLAN-DRAFT-2026-11-05.md`, 최종 목표(AGENTS.md '최종 목표'·'실행 위치').
이 표는 기존 결정을 한곳에 모은 것이며 새 결정을 만들지 않는다.

## 1. 한 줄 목표

**사용자 고유의 캐릭터·능력으로, 수집한 애니메이터 스타일을 섞은 액션 애니메이션을 스틱파이터 SFA(24,24)로 만들어 주는 창작 AI.**

## 2. 최종 모습

| 항목 | 목표 | 현재 결정·상태 |
|---|---|---|
| 무엇을 | 액션물(카툰·귀여운 디자인 아님) | 확정 |
| 출력 | 편집 가능한 `.sfa`, (24,24)로 1초 24장 모두 그림 | 확정 |
| 입력 ① 캐릭터 시트 | 양식 파일 + 설명 글, 액세서리 포함 | 시트 v3(10면) 완성 |
| 입력 ② 능력 | 글 설명(예: 붉은 가시) | 이펙트 단계에서 |
| 입력 ③ 무기 | 무기 파일(확대판 + 잡는 법). 생성기는 손목 위치·각도만 | 미착수 |
| 입력 ④ 장면 | 글·태그·시간 구간·스토리보드·레퍼런스·음악·앞 장면 | 기준 프롬프트 1(`bench01`) |
| 부정 프롬프트 | 두 겹(유도 + SFA 문법 금지), 자율 보강 정도 조절 | 설계만 |
| 실행 위치 | 휴대폰은 화면, 생성은 GPU 서버(임시 결정 B). 기기 안 실행은 보류 | 임시 |
| 사용 범위 | 사용자 혼자 쓰는 개인용 | 확정 |

## 3. 구성 요소별 목표와 진척

| 구성 요소 | 목표 | 진척 | 남은 핵심 |
|---|---|---|---|
| **스틱맨 추출(지금 주력)** | 애니 영상 → 편집 가능한 2D 스틱맨을 **'딸깍'으로 거의 완벽하게**(사용자 11-10) | 10초 구간 승인. 새 구간 자동 오차 중앙 0.83 머리(키 기준) | 팔만 보이는 근접, 검출 없는 장, 다리, 뒷모습 자동 판별 |
| **레이어(앞뒤)** | 원본과 같은 앞뒤를 앱에서 그대로 | 깊이 칸·앱 순서 고정·머리 분리·뒷모습 구간 | 앱 확인, 뒷모습 자동화, 새 구간 대조 |
| **몸 스미어** | 원본 스미어를 스틱맨 팔다리에 붙여 옮김 | 10초 반완성(사용자 확인 라벨 기반) | 자동 탐지(학습은 허락 필요), 새 구간 적용 |
| **움직임 자료** | 애니메이터 액션 구간 약 300개·20분 + 태그 | 672장(약 28초)만 — **미달** | 추출 '딸깍'이 되면 대량 생산 |
| **생성 모델** | 거대 사전학습 모델 + LoRA, 정지 → 움직임 2단계 | 적합 시험 끝, 학습 작업자 준비 | 학습 실행(GPU 허락 필요) |
| **스타일** | 애니메이터 스타일을 하나로 섞음(작가 선택 없음). 유지 리듬·예비 동작·타격 멈춤 등으로 보정 | 특징 실측·채점기 있음 | 학습 후 보정 |
| **캐릭터 입히기** | 시트의 색·가면·망토를 스틱맨에 | 완성(앱 확인) | 실제 신체 묘사(나중) |
| **이펙트** | 직선·곡선 조각, 면적·두께 자유, 반투명 겹·글로우, 나카무라 우선 | 형태 사전·조사 | 나중 단계 |
| **배경** | 3D 공간 → 카메라 → 윤곽선 + 밑색, 거리별 선 두께, 파손 반영 | 미착수 | 나중 단계 |
| **이어 만들기·음악** | 앞 장면 전체 읽고 템포, 배경 상태 유지, 박자 맞춤 | 미착수 | 나중 단계 |
| **앱 연결** | 안드로이드 APK(첫 플랫폼) | 미착수 | 마지막 |

## 4. 지금 순서

1. **스틱맨 추출을 '딸깍' 수준으로** — 수정은 장 지정 데이터가 아니라 공통 규칙(코드)으로. 지표: `tools/stickman_key_eval.py`.
2. 레이어·스미어를 같은 원칙으로 자동화(새 구간에서 재사용 시험).
3. 추출이 자동으로 되면 움직임 자료를 대량으로 만들고 → 학습(GPU 허락 후).
4. 그다음 이펙트 → 배경 → 이어 만들기·음악 → 앱.

## 5. 지켜야 할 것(요약)

- 3D에 매몰되지 않는다. 캐릭터 그림체는 학습하지 않는다(움직임만).
- GPU·새 학습·Kaggle 실행은 사용자 허락 후에 한다.
- 원본 영상·추출물·역컴파일물은 공개 저장소에 넣지 않는다(Drive 비공개).
- 형식 검사 통과를 품질로 보고하지 않는다. 원본과 장별로 대조한다.
- 잘된 것은 바꾸지 않는다. 명백한 오류는 묻지 않고 고친다.
- 가려진 몸은 숨기지 않는다(깊이 칸으로). 추론한 부위는 앞에 두지 않는다.
- 머리 지름은 가림으로 줄이지 않는다.
