# GPT 작업: 이펙트 35구간 자동 마스크 결과 판정 (2026-10-24)

## 배경
확인된 이펙트 후보 35구간(`data/p3/fx_confirmed35_2026-10-23.csv`)을 Kaggle v3 자동 마스크로 전부 SFA로 만들었다. 사용자는 PC에서 자동 마스크 위에 틀린 곳만 클릭해 고친다(`docs/PC-CLICK-MASK-GUIDE-2026-10-24.md` 고치기 방식). GPT는 **어느 구간을 고쳐야 하는지, 무엇을 더하고 뺄지**를 그림으로 판정한다. Claude는 서버 계산만 한다.

## 자료 (Drive `AI-sfa/04_SFA시험작/이펙트35_자동/`)
- `sheet_<번호>_<게시물>_<시작>.jpg` 35개: 구간에서 고르게 8장. 한 줄 = **원본 | 자동 마스크(분홍) | SFA(검정 바탕)**.
- `비교_<번호>_<게시물>_<시작>.mp4`: 원본과 SFA를 정상 속도로 나란히 놓은 영상(장면 사이가 애매할 때).
- 서버 숫자(마스크가 거의 없는 장 = 면적 0.3% 미만): 009 전부 빈 장 25/25, 005 13/18, 011 18/38, 001 10/49, 007 10/25, 030 9/25(평균 0.3%), 034 5/36, 006 4/25. 면적이 큰 구간: 025 평균 65%, 016 평균 45%(배경이 섞였는지 확인).

## 기준
- 마스크 = **이펙트만**(섬광·빛·불꽃·연기·먼지·파편·충격파·집중선·스미어 등). 인물·바위·건물·하늘 배경은 빠져야 한다.
- 화면 전체를 덮는 이펙트(전면 섬광·전면 집중선, 예: 005의 635장 이후)는 이펙트다. 자동 마스크가 놓쳤으면 '더하기'.
- 3D·캐릭터 동작은 다루지 않는다.

## 판정 칸 (UTF-8 CSV)
`번호,게시물,시작,판정,더할것,뺄것,장,확신,메모`
- 판정: `그대로`(자동 마스크로 충분) / `고침`(클릭으로 고치면 됨) / `처음부터`(자동이 거의 못 잡아 새로 클릭) / `제외`(이펙트 구간이 아님)
- 더할것·뺄것: 짧은 말(예: "화면 전체 보라 집중선", "가운데 인물").
- 장: 문제가 보이는 원본 장 번호(시트 왼쪽 초록 숫자). 클릭할 장을 정하는 데 쓴다.
- 확신: 높음/보통/낮음
