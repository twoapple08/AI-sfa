# GPT 작업: 이펙트 구간 판정 (2026-10-23)

## 배경
나카무라 영상에서 자동 검출기로 뽑은 '이펙트 구간' 146개가 있다. 사람이 확인하지 않아서 틀린 것이 많다(예: 폭발이 아닌 장면이 폭발로, 이펙트가 없는 장면이 이펙트로). 이 구간들로 이펙트를 SFA로 복원하는 시험을 하려면 먼저 **사람 눈으로 맞는지** 가려야 한다.

## 자료
- 판정 시트: Drive `AI-sfa/02_분석자료/이펙트_구간판정/판정시트_01.jpg` ~ `판정시트_25.jpg` (rclone 연결됨)
  - 한 줄 = 구간 하나. 왼쪽 큰 숫자 = 구간 번호, 그 아래 = 길이(프레임). 오른쪽 6장 = 구간 시작 → 끝을 고르게 뽑은 장면.
- 번호 ↔ 원본 대응: 저장소 `data/p3/fx_judge_index_2026-10-23.csv` (자동 태그 칸은 믿지 말 것)

## 판정 항목(구간마다)
| 칸 | 값 |
|---|---|
| 번호 | 시트의 세 자리 번호 |
| 종류 | 폭발 / 연기·먼지 / 파편 / 불 / 섬광·빛 / 충격파 / 번개·전기 / 빔·광선 / 기타이펙트 / 이펙트아님. 여럿이면 `;`로, 가장 큰 것 먼저 |
| 이펙트_프레임 | 전부(6장 모두 이펙트) / 일부(몇 장만) / 없음 |
| 장면전환 | 있음 / 없음 (6장 사이에 컷이 바뀌면 있음) |
| 배경 | 단순(단색·흐린 바탕) / 복잡 |
| 인물_겹침 | 없음 / 조금 / 많음 (이펙트 위에 인물이 겹치는 정도) |
| 확신 | 높음 / 보통 / 낮음 |
| 메모 | 한 줄(무엇이 보이는지, 이펙트 위치 등) |

판정 원칙: 장면을 보고 판단한다. 자동 태그를 따라가지 않는다. 애매하면 확신 '낮음'으로 두고 메모에 이유를 적는다.
