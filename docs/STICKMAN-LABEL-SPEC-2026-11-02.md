# 애니 → 스틱맨 라벨 정의 v1 (2026-11-02, Claude·GPT 4차 합의 반영)

목적: 원본 애니 장면의 관측을 기록하는 라벨(관측 라벨)과, 스틱맨 목표 자세 라벨(목표 라벨)을 같은 규칙으로 남긴다.
근거: docs/ANIME-TO-STICKMAN-DEBATE-2026-11-02.md(1–4차), GPT 3·4차 문서.

## 0. 공통 원칙
- **대상 지정이 먼저다.** 모든 라벨은 `대상 ID`(장면·컷 안에서 고정한 인물 번호) 하나에 대해 붙인다. 인물이 여럿이면 대상마다 따로 붙인다.
- 모든 항목은 다음 세 값을 허용한다.
  - `값`
  - `대상 없음`(그 장에 대상이 보이지 않음)
  - `판정 불가`(가림·너무 작음·흐림·스미어 등으로 판단 못 함). 억지로 값을 넣지 않는다.
- 라벨러는 상대 라벨을 보기 전에 독립적으로 쓴다. 고정한 뒤에 대조한다. 재판정은 원본을 덮어쓰지 않고 별도 파일에 이유와 함께 남긴다.
- 표시
  - 근거: `[측정]` 도구 수치, `[눈]` 시각 판독(해상도·도구 명시), `[가설]`.
  - 라벨러: `Claude`, `GPT`, `사용자`.

## 1. 장 쌍 라벨(인접 장 또는 지정한 두 장)
| 항목 | 값 | 정의 |
|---|---|---|
| 작화 변화 | 같음 / 다름 | 대상의 선·면이 다시 그려졌는가. 화면 이동·확대만 있고 같은 그림이면 '같음'. 얼굴·머리카락만 바뀌어도 '다름' |
| 골격 자세 변화 | 없음 / 작음 / 큼 | 스틱맨 골격(머리·몸통·팔·다리 마디 방향)이 바뀌었는가. 작화가 달라도 골격은 '없음'일 수 있다(#23처럼 1장 단위 작화) |
| 화면 이동 | 없음 / 있음 | 대상이 화면에서 움직였는가(카메라·인물 이동 구분 없이 관측). 물리적 원인은 적지 않는다 |
| 이동 원인(선택) | 카메라 / 인물 / 섞임 / 판정 불가 | 배경과 함께 움직이면 카메라 쪽. 근거가 없으면 '판정 불가' |

- '긴 정지 후보'(연속 여러 장)는 첫 장과 끝 장만이 아니라 **중간 장도** 확인한다. 각 인접 쌍에 라벨을 붙인다.

## 2. 장면 조건 라벨(장 단위)
| 항목 | 값 | 정의 |
|---|---|---|
| 회색 배경 | 예 / 아니오 | 배경이 무채색(회색·흰색·검정)인가 |
| 색 마스크 적합 | 맞음 / 일부만 / 맞지 않음 | 실제 HSV 마스크(`tools/anime_char_hold.py`)를 겹쳐 그렸을 때 대상을 덮고 배경·이펙트를 덜 덮는가 |
| 대상 크기 | 화면 높이 대비 대상 높이 % | 상자 높이 / 화면 높이 |
| 가시성 | 전신 / 상반신 / 일부 / 클로즈업 | |

## 3. 관절 관측 라벨(장 단위, 대상마다)
- 점: 머리 위(정수리)·목·골반·좌우 어깨·팔꿈치·손목·엉덩이·무릎·발목.
- 각 점에는 다음을 붙인다.
  - `(x, y)` 원본 해상도 픽셀
  - 상태: `보임` / `가려짐(추정)` / `판정 불가`
- **좌우:** 대상 몸 기준(대상의 왼팔 = left)이다. 앞뒤가 불명확한 장(측면·회전 중)은 좌우를 억지로 정하지 않는다. `좌우 불명`을 표시하고, 두 팔(두 다리)을 묶어 기록한다.
- '가려짐(추정)' 좌표는 관측 정답으로 쓰지 않는다. 평가에서는 따로 보고한다.

## 4. 목표 라벨(스틱맨)
- 앱 골격에 맞춘 자세: 목·골반(루트)·팔 2(위·아래)·다리 2(위·아래)·머리 방향.
  - 10조각은 첫 실험의 기본 구조다. 필수 조건은 '앱에서 연결 유지 + 포즈 편집 가능'이다.
- 관측에서 바꾼 부분(재연출)은 이유와 함께 표시한다. 예: 가려진 팔을 읽기 쉽게 폈음.
- 인물 고유 비율: 여러 명확한 자세에서 추정한 마디 길이 중앙값으로 정하고, 불확실성을 같이 적는다.

## 5. 오차 단위와 합격선(미확정)
- 분모: 대상별 기준 길이 = 명확한 자세들에서 잰 몸통(목–골반) 길이의 중앙값.
- 보고는 세 갈래로 나눈다.
  - ① 화면 궤적 오차(원본 좌표 그대로)
  - ② 루트·배율 정렬 뒤 자세 오차
  - ③ 루트·배율 자체의 오차
- 정렬로 이동·크기 오류를 숨기지 않는다.
- 합격선: 예전 3%·8%는 몸 높이 분모의 잠정치였다. 분모가 바뀌었으므로 **라벨 반복·상호 일치도를 잰 뒤 다시 정한다.**

## 6. 사용자 확인 표본
- AI 두 라벨러가 갈린 장, 그리고 일치한 장 가운데 무작위 표본(일치 장의 일부)을 함께 보낸다.
- 사용자에게 모든 장의 정밀 좌표를 요구하지 않는다. 자연스러움·재연출 선호는 사용자가 정한다.

## 7. 보조 도구의 위치
- `tools/anime_char_hold.py`(M1): **정지 후보 생성기**다. 문턱 아래를 '같은 그림'으로 확정하지 않는다. 경계(0.1–0.3)와 긴 구간은 라벨로 확인한다.
- `tools/frame_pair_aligned_diff.py`(정렬 잔차): **보조 근거**다.
  - status가 '판정 불가'(정렬 실패·이동 과대·배율 범위 밖·전단·겹침 부족·상관 낮음)면 쓰지 않는다.
  - 작은 대상은 `--roi`로 대상 주변을 따로 본다.
  - 문턱 아래 차이는 평균 잔차로 함께 본다.
  - dx·dy를 카메라 이동으로 확정하지 않는다.
- 2판 도구 실측(28쌍)
  - 3쌍(#4·9·14)이 '판정 불가'로 걸러졌다. #4는 예전 출력이 dx −5,370px, 배율 3.6이었다.
  - 나머지 25쌍은 '정렬 유효'다.
