# 애니 → 스틱맨 라벨 정의 v1.2 (2026-11-02, Claude·GPT 4차 합의 + GPT 5·6차 보완)

목적: 원본 애니 장면의 관측을 기록하는 라벨(관측 라벨)과, 스틱맨 목표 자세 라벨(목표 라벨)을 같은 규칙으로 남긴다.
근거: docs/ANIME-TO-STICKMAN-DEBATE-2026-11-02.md(1–4차), GPT 3·4차 문서.

## 0. 공통 원칙
- **대상 지정이 먼저다.** 모든 라벨은 `대상 ID`(장면·컷 안에서 고정한 인물 번호) 하나에 대해 붙인다. 인물이 여럿이면 대상마다 따로 붙인다.
- 모든 항목은 다음 세 값을 허용한다.
  - `값`
  - `대상 없음`(대상이 장면·화면 밖에 있음. 장면 안에서 전부 가려진 경우는 `완전 가림`으로 따로 적는다 — §0-1 4번)
  - `판정 불가`(가림·너무 작음·흐림·스미어 등으로 판단 못 함). 억지로 값을 넣지 않는다.
- 라벨러는 상대 라벨을 보기 전에 독립적으로 쓴다. 고정한 뒤에 대조한다. 재판정은 원본을 덮어쓰지 않고 별도 파일에 이유와 함께 남긴다.
- 표시
  - 근거: `[측정]` 도구 수치, `[눈]` 시각 판독(해상도·도구 명시), `[가설]`.
  - 라벨러: `Claude`, `GPT`, `사용자`.

## 0-1. v1.1 보완(GPT 5차 제안 수용)
1. **관절 단위 판정과 장 단위 요약을 나눈다.**
   - 관절마다 `맞음 / 틀림 / 판정 불가`와 이유를 남긴다.
   - 장 요약은 다음 순서로 정한다(v1.2, GPT 6차 제안).
     1. 평가 가능한 관절이 0개 → `판정 불가`
     2. 평가한 관절 중 틀림이 1개 이상 → `일부 틀림`(틀린 관절 목록)
     3. 나머지 → `맞음(검증 범위)` + 미검증(판정 불가) 관절 목록
   - **부분 검증과 전체 통과를 나눈다.** 장 요약과 함께 `평가 관절 집합`, `맞음/틀림/판정 불가 개수`, `가림 관절 목록`을 저장한다. '맞음'이 어깨 두 점만 검증한 것인지 전신을 검증한 것인지 구분한다. 학습 채택 조건은 이 개수로 따로 정한다(미정).
   - 가림 관절이 있다고 보이는 관절까지 평가 불가로 만들지 않는다.
2. **파생점과 해부학 점을 구분한다.**
   - RTMW 몸 17점에는 정수리·목·골반 중심이 없다.
   - 어깨 중점·엉덩이 중점처럼 계산한 점은 `파생점`으로 표시하고, 수작업 해부학 점과 섞지 않는다.
   - 분모는 '앱 목–골반'과 '어깨 중점–엉덩이 중점'을 구분해 적는다.
3. **좌표 메타데이터:** 영상 SHA-256, 0부터 시작하는 장 번호(디코딩 순서), PTS·FPS, 원본 크기, 크롭·축척·회전·반전 변환, 대상 ID, 관절 순서 정의, 모델·가중치 버전(관측 출처가 모델일 때).
   - 클릭 도구는 표시 좌표 → 원본 좌표 변환을 시험 점으로 검증한 뒤 쓴다.
4. **'대상 없음'과 '완전 가림'을 구분한다.**
   - `대상 없음` = 장면·화면 밖.
   - `완전 가림` = 장면 안에 있으나 전부 가려져 위치를 모름.
5. **없음·작음·큼은 지금은 질적 판정이다.** 기준 예시(#23 = 작화 바뀜 + 골격 작음, #20 = 골격 큼, #26 = 골격 없음 + 화면 이동)를 고정한다. 수치 기준은 좌표 일치도 시험 뒤에 정한다.
6. **관측 투영 길이와 목표 골격 길이를 구분한다.** 화면 길이 중앙값은 원근·가림·과장 작화의 영향을 받는 '관측 투영 길이'다. 목표 리그 길이는 이 값을 참고해 **선택**하는 것이고, 선택 근거와 불확실성을 적는다(실제 길이 복원으로 취급하지 않는다). §4·§5의 '중앙값'도 이 뜻이다.
7. **대표 장: 자동 후보 구간과 확인 구간을 나눈다(v1.2).**
   - `tools/drawing_segments.py` 출력은 **후보**(`candidate_segments`)다. 원본 확인 경계는 확인 파일(`--verified`, 예: `data/stickman_motion/verified_boundaries_1913_2026-11-02.json`)로 따로 넣어 `verified_segments`를 만든다.
   - 구간 안의 모든 인접 쌍이 '같음'으로 확인된 구간만 `pose_copy_ok`(한 포즈 복사 가능)다. 애매한 쌍이 든 후보 구간은 확인 전까지 복사하지 않는다.
   - **복사 가능한 것은 루트 기준 상대 포즈뿐이다.** 같은 그림 안에서도 화면 위치(B325–333에서 장마다 약 1.1–1.2px)와 배율은 장별 관측을 유지한다. 정합값을 물리적 카메라 이동으로 확정하지 않는다.
   - 경계 번호는 '새 그림의 첫 장'이다. 범위 끝에서 잘린 구간은 표시한다.
   - `mask_none_pairs`(마스크 없음)는 대상 부재가 아니다. 대상 부재는 라벨로 확인한다.
   - **고정 간격만으로 작화 구간을 확정하지 않는다.** 일정 간격의 검수·무작위 표본은 보조로 쓸 수 있다.
   - 반례 기록: B325–333은 파란 마스크로 한 후보였으나, 원본 확인 결과 325–327 / 328–330 / 331–333이었다(경계 점수 0.283·0.255 < 문턱 0.3).
   - 접촉·가림·좌우 교차·대상 배정 경계 장은 따로 추가한다.
8. **라벨러 편향 줄이기:** 독립 좌표 라벨은 모델 겹침이 **없는** 원본 장에서 찍는다.
9. **보조 통계의 이름**
   - '133점 상대 대응 일관성'은 관절 정답률이 아니다.
   - '정렬 유효'는 QC 통과이지 정답 인증이 아니다.
   - '대상 배정됨'은 신원 정확도가 아니다.

## 1. 장 쌍 라벨(인접 장 또는 지정한 두 장)
| 항목 | 값 | 정의 |
|---|---|---|
| 작화 변화 | 같음 / 다름 | 대상의 선·면이 다시 그려졌는가. 화면 이동·확대만 있고 같은 그림이면 '같음'. 얼굴·머리카락만 바뀌어도 '다름' |
| 골격 자세 변화 | 없음 / 작음 / 큼 | 스틱맨 골격(머리·몸통·팔·다리 마디 방향)이 바뀌었는가. 작화가 달라도 골격은 '없음'일 수 있다(#23처럼 1장 단위 작화) |
| 화면 이동 | 없음 / 있음 | 대상이 화면에서 움직였는가(카메라·인물 이동 구분 없이 관측). 물리적 원인은 적지 않는다 |
| 이동 원인(선택) | 카메라 / 인물 / 섞임 / 판정 불가 | 배경과 함께 움직이면 카메라 쪽. 근거가 없으면 '판정 불가' |

- '긴 정지 후보'(연속 여러 장)는 첫 장과 끝 장만이 아니라 **중간 장도** 확인한다. 각 인접 쌍에 라벨을 붙인다.

## 2. 장면 조건 라벨(장 단위)
| 항목 | 값 | 정의 |
|---|---|---|
| 회색 배경 | 예 / 아니오 | 배경이 무채색(회색·흰색·검정)인가 |
| 색 마스크 적합 | 맞음 / 일부만 / 맞지 않음 | 실제 HSV 마스크(`tools/anime_char_hold.py`)를 겹쳐 그렸을 때 대상을 덮고 배경·이펙트를 덜 덮는가 |
| 대상 크기 | 화면 높이 대비 대상 높이 % | 상자 높이 / 화면 높이 |
| 가시성 | 전신 / 상반신 / 일부 / 클로즈업 | |

## 3. 관절 관측 라벨(장 단위, 대상마다)
- 점: 머리 위(정수리)·목·골반·좌우 어깨·팔꿈치·손목·엉덩이·무릎·발목.
- 각 점에는 다음을 붙인다.
  - `(x, y)` 원본 해상도 픽셀
  - 상태: `보임` / `가려짐(추정)` / `판정 불가`
- **좌우:** 대상 몸 기준(대상의 왼팔 = left)이다. 앞뒤가 불명확한 장(측면·회전 중)은 좌우를 억지로 정하지 않는다. `좌우 불명`을 표시하고, 두 팔(두 다리)을 묶어 기록한다.
- '가려짐(추정)' 좌표는 관측 정답으로 쓰지 않는다. 평가에서는 따로 보고한다.

## 4. 목표 라벨(스틱맨)
- 앱 골격에 맞춘 자세: 목·골반(루트)·팔 2(위·아래)·다리 2(위·아래)·머리 방향.
  - 10조각은 첫 실험의 기본 구조다. 필수 조건은 '앱에서 연결 유지 + 포즈 편집 가능'이다.
- 관측에서 바꾼 부분(재연출)은 이유와 함께 표시한다. 예: 가려진 팔을 읽기 쉽게 폈음.
- 인물 고유 비율(목표 리그 길이): 여러 명확한 자세의 관측 투영 길이 중앙값을 **참고해 선택**하고, 선택 근거·불확실성을 같이 적는다(§0-1 6번). 실제 길이를 복원한 것으로 보지 않는다.

## 5. 오차 단위와 합격선(미확정)
- 분모: 대상별 기준 길이 = 명확한 자세들에서 잰 몸통 길이의 중앙값. **목–골반(해부학 라벨)인지 어깨 중점–엉덩이 중점(파생점)인지 파일마다 적는다.**
- 보고는 세 갈래로 나눈다.
  - ① 화면 궤적 오차(원본 좌표 그대로)
  - ② 루트·배율 정렬 뒤 자세 오차
  - ③ 루트·배율 자체의 오차
- 정렬로 이동·크기 오류를 숨기지 않는다.
- 합격선: 예전 3%·8%는 몸 높이 분모의 잠정치였다. 분모가 바뀌었으므로 **라벨 반복·상호 일치도를 잰 뒤 다시 정한다.**

## 6. 사용자 확인 표본
- AI 두 라벨러가 갈린 장, 그리고 일치한 장 가운데 무작위 표본(일치 장의 일부)을 함께 보낸다.
- 사용자에게 모든 장의 정밀 좌표를 요구하지 않는다. 자연스러움·재연출 선호는 사용자가 정한다.

## 7. 보조 도구의 위치
- `tools/anime_char_hold.py`(M1): **정지 후보 생성기**다. 문턱 아래를 '같은 그림'으로 확정하지 않는다. 경계(0.1–0.3)와 긴 구간은 라벨로 확인한다.
- `tools/frame_pair_aligned_diff.py`(정렬 잔차): **보조 근거**다.
  - status가 '판정 불가'(정렬 실패·이동 과대·배율 범위 밖·전단·겹침 부족·상관 낮음)면 쓰지 않는다.
  - 작은 대상은 `--roi`로 대상 주변을 따로 본다.
  - 문턱 아래 차이는 평균 잔차로 함께 본다.
  - dx·dy를 카메라 이동으로 확정하지 않는다.
- 2판 도구 실측(28쌍)
  - 3쌍(#4·9·14)이 '판정 불가'로 걸러졌다. #4는 예전 출력이 dx −5,370px, 배율 3.6이었다.
  - 나머지 25쌍은 '정렬 유효'다.
