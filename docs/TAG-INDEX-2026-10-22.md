## 사용
```
python tools/tag_index.py build
python tools/tag_index.py tags
python tools/tag_index.py find 공격_킥 --animator nian41
python tools/tag_index.py extract 임팩트_연필 <출력 폴더> --videos <영상 폴더>,<영상 폴더> --pad 6
```
한글 기준 태그와 원래 영어 태그(explosions, impact_frames_pencil …)를 둘 다 받는다. 추출물(영상 조각)은 원본 유래라 저장소에 넣지 않는다.

## 확인한 것 / 한계
