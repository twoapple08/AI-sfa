## 2. 고친 판정 계획(초안 — 사용자 확정 전)

**초기 관문(PC 2시간 + 사전 지정 1회 연장)**

1. **필수 — 생성 건전성**(잠정값, 첫 결과로 바꾸지 않는다)
   - 평가 장 모두 측정됨(OOM으로 빠진 장 0)
   - 정답에 오브젝트가 있는데 빈 출력인 장 0
   - 길이 한도에 걸려 미완료인 장 10% 이하
   - 오브젝트 수 비율(AI/원본) 중앙값 0.5–2
2. **핵심 — 영상 위치 사용**: 위치 시험 장마다 학습에 없던 이동 4방향(예: (+6,+4), (−6,−4), (+6,−4), (−6,+4), 배율 1.05)을 만든다. 정답을 고정한 채 맞는 이동 영상과 다른 이동 영상으로 각각 생성해 위치·형상 부분 점수를 비교한다. **맞는 영상이 이긴 파일이 다수이고 우연이 아닐 것**(18파일이면 13파일 이상, 단측 부호 검정 p<0.05). 비용 때문에 마지막 두 판정 시점(100·120분)에만 한다.
3. **보조 — 외움보다 나음**: 위치 시험 A(옮긴 정답 대비 부분 점수)가 같은 평가 목록의 외움 기준선 + 5점(기본 20장이면 20.9점) 이상. 이 +5는 GPT가 제시한 사전 고정 잠정 여유다.
4. **기록만(판정에 안 씀)**: A·B·A−B, gen_ 부분 점수·재현율·정밀도, 분야별 연습 점수, 첫 점/이어지는 점, 현재 단계 해상도 대 360 점수, 단계별 업데이트 수·평가 시간, 고정 그림 시트(스틱맨 장면 포함).

판정:
- **진행**: 1·2·3을 모두 만족하면 이어서 학습한다(이후 Kaggle).
- **1회 연장**: 1은 만족하는데 2·3이 오르는 중이거나 360 관측이 부족하면 한 번 연장한다.
- **원인 조사**: 충분히 학습한 360 단계에서 2·3이 안 되고, 출력이 빈 장·고정 자세·길이 한도에 머물면 원인을 조사한다. 자료와 생성 경로를 먼저 보고, 그다음 방식 실험(sin 등)을 한다.

**최종 목표(본 학습 끝)**: 새 파일(gen_)에서 엄격 F1(재현율·정밀도) 70% 이상. 대상은 2,048 이하 장이고, 범위 밖 장 비율을 함께 보고한다. 색·면·배경·순서와 만점 수도 함께 보고한다.

## 3. 구현할 것(사용자 확정 뒤)
1. 만점 판정의 원 비교를 중심·반지름으로(시험 포함)
2. 위치 시험 이동 4방향 자료 + 옮기기 전 정답을 (파일, Position)으로 연결해 보존
3. 입력 교환 생성 대조(마지막 두 판정 시점), 파일 단위 부호 검정
4. 생성 건전성 기록: EOS 완료율, 빈 출력, 길이 한도, 오브젝트 수 비율, OOM 장 수
5. 정밀도·F1, 부분 점수 이름 정리, 외움 기준선을 평가 목록마다 자동 계산
6. `--gen-minutes 20`(PC 시험), 단계별 업데이트 수·평가 시간 기록, 현재 단계 해상도 고정 몇 장 평가
7. 숫자 분야 잠정 진단 범위(벡터 거리·실제 값 상대 오차·글로우 항목별·BIG 복원) — 기존 엄격 맞힘은 유지

허용 범위 눈 판정 시트(한 속성만 바꾼 렌더)는 그다음에 만든다.
