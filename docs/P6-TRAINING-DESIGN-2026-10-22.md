## 2. 구성 제안 (기기 안, 단계별로 규칙 → 학습 모델로 교체)

```
태그/자연어 ─▶ ① 입력 이해 ─▶ ② 안무 계획(사건 열) ─▶ ③ 몸동작 생성(두 사람) ─▶ ④ 타이밍 층(그림 유지)
                                              │                                     │
                                              └──────▶ ⑤ 이펙트 생성 ◀─────────────┘
                                                        ⑥ 카메라 ─▶ ⑦ SFA 작성(결정적, 지금 코드)
```

| 모듈 | 1단계(지금~) | 학습 모델안 | 기기 크기 목표 |
|---|---|---|---|
| ① 입력 이해 | 태그 규칙(지금) | 소형 언어 모델(0.5~1.5B, 4비트)로 자연어 → 태그·조건 JSON | 300MB~1GB(선택 설치) |
| ② 안무 계획 | 규칙(Choreo, 지금) | 사건 토큰 트랜스포머: (공격자, 동작, 세기, 결과, 간격) 열. 학습 자료 = 애니 동작 분류 + 타격 정점·임팩트 시각 | < 5MB |
| ③ 몸동작 | nian41 펀치 자세 + 규칙 자세 | **동작 토큰화(VQ-VAE) + 소형 GPT**(T2M-GPT 계열). 조건 = 동작 라벨·목표 위치·상대 위치 | 20~60MB(int8) |
| ④ 타이밍 층 | 2프레임 정지 규칙 | 부드러운 동작 → 그림 유지 열(1s/2s/3s) 다시 고르기. 학습 자료 = 애니 유지 분포·정점 앞뒤 유지 | < 1MB |
| ⑤ 이펙트 | 사전 형태 배치(지금) | 형태 계수 VAE(포물선 조각 윤곽을 고정 조각 수로 다시 뽑아 잠재값) + 종류·시간 조건, 층(선·밑색·반투명 명암) | 5~20MB |
| ⑥ 카메라 | 없음 | P2 통계 규칙(흔들림·확대) → 나중에 소형 모델 | 규칙 |
| ⑦ SFA 작성 | 있음 | 그대로 | — |

**확산 모델(MDM 등)을 먼저 쓰지 않는 이유(제안):** 수십 단계 반복이라 폰에서 느리다. 토큰 + 자기회귀 방식이 폰 실행·길이 조절·조건 넣기가 쉽다. 품질 비교는 서버에서 둘 다 해 볼 수 있다(시간 제한 없음 지시).

**핵심 설계 결정(제안): 동작과 타이밍을 나눈다.** 모캡·3D 올리기 결과는 매 프레임 부드럽고, 애니는 2s 바탕·타격 앞뒤 2~3프레임 유지·정점 이동 약 2배다(P1-STRIKE-TIMING). ③은 부드러운 '무엇을'을, ④는 애니식 '언제 새 그림을'을 맡는다. 모캡 68.7시간은 ③에, 애니 타이밍은 ④에 쓴다.

## 3. 학습 순서

1. **③ 몸동작 사전학습(모캡):** 18관절 → 리그 A 각도(10개 + 엉덩이 위치·땅 높이)로 바꿔 VQ-VAE → GPT. 조건은 모캡 태그(공격·걷기·점프·방어·피격 등).
2. **③ 애니 스타일 미세조정:** 애니 3D(나카무라·nian41, 몸점수 ≥ 2.8, 뼈 고정)로 미세조정. 3D 떨림이 커서 **그대로 정답으로 쓰지 않는다**: 시간 평활 + 뼈 고정 + 낮은 가중치, 또는 2D 투영 손실(애니 2D 포즈에 맞추기)로 쓴다.
3. **두 사람 상호작용:** 지금 자료는 대부분 혼자 동작이다. ②가 둘의 위치·접촉 시각을 정하고 ③이 각자 만드는 방식으로 시작한다. 두 사람 모캡(아래 §6 부탁 1)이 생기면 상대 조건을 넣어 학습한다.
4. **④ 타이밍 층:** 애니 2D 추적의 유지 열(픽셀 기준 새 그림, 검증된 측정)을 동작 속도와 함께 학습(작은 순환망 또는 통계 표).
5. **② 안무 계획:** 동작 분류기(T03+T04 학습)를 애니 추적 전체에 돌려 사건 열을 만든다. 정확도가 53~59%라 확신 높은 구간 + GPT 정답만 쓴다.
6. **⑤ 이펙트:** P3 층 분해가 끝난 뒤. 종류별 형태 계수 분포 → VAE.

## 5. 기기 변환

PyTorch → ONNX → ONNX Runtime(안드로이드, NNAPI/XNNPACK) 또는 ExecuTorch. int8 양자화 후 품질 표를 다시 잰다. 모델 파일은 APK와 따로 두고 처음 실행 때 내려받거나 PC 뷰어처럼 옆에 둔다(개인용).
PC판(SfaViewer)은 ONNX Runtime(.NET)으로 같은 모델을 돌린다 — 먼저 PC에서 시험하기 쉽다.
