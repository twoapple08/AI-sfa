# 스미어 거리 기반 밀도 시스템 v1

원래 지그재그 사슬을 입력하면 거리 측정 → 필요한 구간의 왕복 추가 → 불균등 간격 → 간격에 따른 깊이 조절 → 연결된 단일장 SFA와 검증 바인딩까지 처리한다. 사용자가 긍정한 원래 꺾임점은 좌표와 순서를 보존한다. 영상에서 스미어를 찾아 원래 점을 자동 판독하는 기능은 포함하지 않는다.

## 실행

Python과 numpy/scipy가 필요하다. 프로젝트 루트 또는 전달 ZIP을 푼 폴더에서 실행한다.

```bash
python tools/smear_density.py --input examples/smear_density_input.json --output ../smear-output-01
```

출력 디렉터리는 비어 있는 새 경로여야 한다. 재실행에는 다른 경로를 사용한다. 원본/좌표 보호를 위해 저장소 내부 출력은 거절한다. 전달 ZIP을 푼 폴더도 이 규칙에서 코드 루트로 취급하므로 형제 폴더 등에 출력한다. 합성 예시는 공개용이며 실제 애니 프레임/좌표가 아니다.

입력은 `sfa-smear-density-input/1`, 화면 너비·높이, 고유 사례ID, 순서 있는 `points_px`다. 사례마다 단일장 효과를 생성한다. 대안으로 `template_points_px`, `rail_a`, `rail_b`, 선택적인 초기 `segments`를 넣으면 기존 두 경계 보간을 먼저 실행한다. 두 입력 방식을 동시에 지정하지 않는다. 이미 밀도 조절한 결과 JSON은 입력 스키마가 달라 재처리를 거절한다. 원래 사슬 입력을 보존해 매번 거기서 생성한다.

`--profile`로 별도 프로필을 지정할 수 있다. 기본은 `profiles/smear_density_v1.json`. 결과는 `{id}.sfa`와 `density.binding.json`. 한 사례라도 처리 불가하면 해당 사례는 `needs_review`와 이유를 남기고 SFA를 만들지 않으며 종료코드2를 반환한다. 전체 성공은0이다. 잘못된 공통 설정은 전체 실행을 거절한다. 임시 ZIP을 완성한 뒤 최종 SFA 이름으로 교체한다.

## 거리와 선 수

같은 쪽 경계의 인접 꺾임점 거리와 긴 획의 길이를 측정해 기록한다. 선 수 결정에는 인접 왕복 획 사이의 수직 간격을 획의1/4·1/2·3/4 위치에서 근사한 최댓값을 사용한다. 획 자체의 길이를 간격으로 오인하지 않는다.

화면852×480 기준 간격 목표는 `max(1.2, min(6.0, .10 × 인접 두 획 중 짧은 길이))`다. 넓은 구간만 필요한 수로 분할하고 왕복쌍을 넣는다. 실제 길이 단위는 화면 너비/852로 함께 조절하므로 같은 장면을 균일 확대해도 선 수와 정규화된 형태가 유지된다. 간격 가중치로 추가점의 위치를 불균등하게 배치한다. 기존 점은 이동하지 않는다.

이 목표값은 같은 원본 개발사례를 보고 조정한 검토 기본값이다. 보편적인 작가 규칙이나 모든 화면에서 보장되는 실제 픽셀 간격이 아니다. 불균등 배치/교차/끝점 이동 뒤에는 화면상 간격이 달라질 수 있다. 지나친 분할이나 방향 상쇄는 검토 필요로 반환한다.

## 좁은 간격에서는 깊이도 축소

추가점의 깊이 배열은 기준12~26% 안에서 서로 다르다. 배열은 수동 표현 조절값으로 작가에서 측정하거나 학습한 패턴이 아니다.

불균등 간격 배치 후, 안쪽으로 당기기 전의 추가점 주변을 측정한다. 각 추가 왕복의 양쪽 끝에서 같은 경계의 앞·뒤 점까지 거리 네 개 중 가장 좁은 거리를 고른다. `배율=min(1, 주변 간격/기준 간격)`로 해당 왕복 양 끝의 깊이와 깊이 최솟값·최댓값을 함께 곱한다. 기준 간격은852너비에서6px이며 화면 크기에 따라 비례한다.

예를 들어 주변 간격이 기준의 절반이면 기준12~26%는6~13%로 줄고 범위 폭도14%p에서7%p가 된다. 원래 점에는 이 이동을 적용하지 않는다. 깊이가 줄면 추가점은 바깥 경계에 더 가까워진다. 기준 간격과 프로필은 수정 가능하며 미관상 적절한지는 결과 이미지로 판단한다.

## 출력 불변 조건과 기록

굵기 .14, 활성선 알파255, 면/글로우0. 선만 추가하며 기존 점 좌표/순서를 보존한다. 모든 선이 이어지는 사슬, 선 양 끝 좌표, 연결의 상호 참조, ID 중복, 채움/글로우와 굵기를 검사한다. 사례 사이에도 점 ID가 겹치지 않게 배정한다. 같은 원본/프로필 재실행은 같은 SFA 바이트를 만든다.

바인딩에는 원래 점·출력 점·고정 마스크·구간별 거리/획 길이/분할 수/실제 깊이/축소 배율/유효 깊이 범위·입력/프로필/SFA SHA를 저장한다. 바인딩은 비공개로 보관한다. `(24,24)`는 단일장 검토의 바인딩 조건이며 확인되지 않은 FPS 저장 필드를 쓰지 않는다.

## 완료 범위와 검증

이번 완성 범위는 입력된 원래 사슬의 밀도 처리 모듈/CLI/프로필/단일장 SFA 저장/검증/재현이다. 새 생산 생성기 기본 경로로 연결하지 않았다. 앱의 실제 편집, 영상의 자동 경계 판독, 연속장 선 추가 시 튀는 현상, 다른 영상 일반화는 미검증이다. 장면 전체나 애니메이션 학습 시스템의 완성으로 세지 않는다.

합성 검사에서는 기존 점/깊이 범위·간격이 이미 좁은 입력의 동일성·화면2배 확대·SFA 연결 검증/훼손 검출·바이트 재현·사례 간 새 ID·부분 실패·입출력 스키마·기존 파일 보호·두경계 입력·CLI 종료코드·간격반감 시 깊이 최소/최대 동반감소를 확인했다.

실제 검토자료는 동일 원본의 기존4사례를 같은 프로필/예외 처리 없이 실행해12/20/14/28선을 생성했다. 독립 평가가 아니며 held_out=false/training_ready=false. 새 깊이 규칙 적용 후 추가점의 유효 범위는2번 약2.47~9.40%,3번4.79~10.38%,4번2.56~11.27%였다. 이 범위는 여러 추가 왕복의 최소/최대 포락이며 각 왕복은 고유한 더 좁은 범위를 갖는다. 1번은 추가점이 없다. 12~26%는 원래 고정점에 대한 비율이 아닌 추가점 기준 범위임에 유의한다.
