# Gemini 작업 지시서: 액션 동작 종류 세기 (2026-10-20, Claude 조정)

## 왜 Gemini인가

- 동작 종류(주먹·발차기·잡기·회피 등)는 사쿠가 태그와 Claude 관찰 기록에 없다. 영상을 직접 봐야 셀 수 있다.
- 그래서 영상을 바로 볼 수 있는 Gemini에 맡긴다.
- **추천 모델·설정:**
  - Gemini 중 영상 이해가 가장 정확한 상위 모델을 쓴다. 사용자가 말한 "아르곤" 쪽이 상위라면 그것을 쓴다.
  - 속도가 빠른 Flash 계열은 동작을 놓치기 쉽다. 쓰더라도 검증용으로만 쓴다.
  - 추론 강도는 높게 둔다.
- Claude가 세운 이펙트·연출 부족분 순위(docs/ACTION-GAP-2026-10-20.md)도 영상으로 확인한다. 관찰 기록 키워드 집계라 근사값이기 때문이다.

## 자료

- Drive `AI-sfa/00_목록/제미나이_동작종류/`
  - `묶음목록.csv`: 묶음(B01–B18), animator, post_id, drive_path. 영상 415개를 묶음당 25개 안팎으로 나눴다.
  - `지시문.txt`: 아래 '붙여넣을 지시문'과 같다.
- 영상 위치: `AI-sfa/01_원본영상/` 아래
  - yutaka_nakamura_디지털 (B01–B09)
  - nian41 (B10–B11)
  - riooo (B12–B13)
  - optical-core (B14–B15)
  - yukina_kosaka (B16–B18)
- 셀 시대 자료와 기법 자료는 넣지 않았다.

## 진행 방법 (사용자)

1. Gemini 새 대화에 '붙여넣을 지시문'과 묶음 번호 하나(예: B10)를 준다.
2. 결과 CSV를 받아 Claude에게 붙여넣는다. Drive의 같은 폴더에 `결과_B10.csv`로 저장해도 된다.
3. 묶음 하나를 대화 하나로 처리한다. 길어지면 Gemini가 앞부분을 잊는다.
4. 처음에는 B10(nian41)이나 B15(8개)로 시작하는 것을 권한다. Claude가 품질을 확인한 뒤 나머지를 진행한다.

## 붙여넣을 지시문 (v2, 2026-10-20 B15 검증 뒤 개정)

B15를 검증한 결과는 22건 중 맞음 13, 부분 맞음 4, 틀림 5였다.
- 없는 동작을 지어냈다: 변신, 회피, 질주, 주먹.
- 이펙트를 많이 빠뜨렸다: 연쇄 폭발, 출혈.
- 10MB가 넘는 파일은 열지 못했다.
그래서 v2는 저용량 사본(854px, 6MB 이하)을 쓰고, 지어내지 말 것과 이펙트를 적을 것을 강조한다.

결정(사용자 2026-10-20): Gemini를 계속 쓰고, Claude가 결과 전부를 영상으로 검수한다.

```
너는 애니메이션 액션 장면을 분류하는 검수자다. 한국어로 답한다.

자료(Google Drive 공유 폴더 AI-sfa):
- 목록: AI-sfa/00_목록/제미나이_동작종류/묶음목록_v2.csv  (열: 묶음, animator, post_id, drive_path)
- 영상: drive_path 경로(AI-sfa/01_원본영상/_Gemini용_저용량/ 아래, 모두 mp4·6MB 이하)

이번에 볼 묶음: B01

규칙(가장 중요):
1. 각 영상을 처음부터 끝까지 실제로 재생한다. 썸네일·제목·작품 지식으로 추측하지 않는다.
2. 화면에 분명히 보인 것만 적는다. 애매하면 적지 말거나 뚜렷함 1로 적는다. 없는 동작을 지어내면 안 된다.
3. 이펙트·연출도 빠짐없이 적는다(폭발, 연쇄 폭발, 연기, 파편, 출혈, 충격파 등도 '기타:이름'으로).
4. 못 연 영상은 "열기 실패" 한 줄만 적는다.

적을 동작·요소:
[공격] 주먹 / 발차기 / 몸통·박치기 / 잡기·조르기 / 던지기·메치기 / 검 / 창·봉 / 둔기 / 총 / 활 / 기타무기 / 손에서 에너지 발사
[방어·이동] 회피 / 막기·쳐내기 / 구르기·낙법 / 점프·공중동작 / 벽타기·벽차기 / 질주·대시 / 순간이동·잔상·분신
[피격] 맞고 날아감 / 맞고 쓰러짐·바닥충돌 / 밀려남 / 맞는 순간 경직
[기타 동작] 곡예(공중회전·비틀기) / 1대다수 / 다수대다수 / 탈것 위 전투 / 비행 전투 / 거대 상대(괴수·메카)와 전투
[이펙트·연출] 기 모으기·충전 / 오라 방출 / 카메라 회전·궤도 / 슬로모션·정지 / 마법진·문양 / 변신 / 비·눈 / 증기 / 기타:이름

출력은 CSV 코드 블록 하나로만 한다. 머리줄:
묶음,post_id,시작초,끝초,분류,동작,주체,뚜렷함,메모
- 분류: 공격/방어·이동/피격/기타 동작/이펙트·연출
- 주체: 사람/괴수/메카/동물/기타
- 뚜렷함: 3=크게 잘 보임, 2=보이지만 작거나 짧음, 1=멀거나 가려져 겨우 보임
- 메모: 20자 이내, 본 것 그대로
- 아무것도 없는 영상은 "없음" 한 줄
CSV 뒤에 3줄 이내 요약.
```
