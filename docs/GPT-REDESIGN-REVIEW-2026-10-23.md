# GPT 재설계 제안 검토 — 현재 코드·자료·검증과 대조 (2026-10-23, Claude)

대상: [GPT 설계 제안](GPT-REDESIGN-2D-SFA-2026-10-23.md). 조건: 3D 없음, 이펙트·연출부터(AGENTS '방향 결정'). 제안의 GPU·시간·통과 수치는 추정으로만 다룬다.

## 1. 동의하는 부분과 고칠 부분

**동의(그대로 채택)**
- 역할 분리 + 사건(접촉 프레임·방향·발생/최대/소멸·앞뒤·카메라) 공유. 이펙트는 래스터·층 그림 → 기존 분해기 → SFA 벡터, XML·ID는 변환기 책임.
- 첫 산출물은 큰 생성 모델이 아니라 **복원 시험과 변형 시험의 분리**. 복원이 안 되면 변환·자료 문제, 복원은 되는데 변형이 안 되면 학습 문제.
- 마스크 안 RGB 잘라내기 ≠ 깨끗한 RGBA(반투명 연기·빛은 배경색이 섞임). 128×128·16프레임 통일은 형태 실험용일 뿐 — 원래 노출시간·사건 시점을 따로 저장. 같은 원본 클립은 학습/검증을 같은 쪽에.
- 화면 전체 사각 마스크를 기계적으로 버리지 않기(전면 임팩트·암전·섬광일 수 있음).
- 버릴 것 목록(3D 경로, 한꺼번에 배우는 모델, 실루엣 + 팔레트, 16프레임 통일, 규칙 뿌리기, 코드 키 자세, 임팩트 보간, 숫자만으로 품질 선언).

**고칠 부분**
1. **단계 A는 처음부터가 아니다.** 복원 경로는 이미 있다: `tools/effect_layers.py`(밑색 + 반투명 명암 + 선 획 분해) → `tools/effect_clip_sfa.py`(`--mask`로 이펙트만, `--check`로 서버 렌더 ΔE). 이펙트만 있는 4장면 + 폭발 시험 1개가 SFA로 Drive `04_SFA시험작/이펙트_재현/`에 있고(1.3–10.9MB), 임팩트 51장면은 층 분해 책이 있다. 새로 만들 것은 **표본을 20개로 늘리기, 정상 속도 나란히 영상, 시간 떨림 확인, 앱 확인**이다.
2. **가장 먼저 막혀 있는 것은 앱 확인이다.** 곡선 경계 채우기·반투명 겹침·도형 2,500개 파일이 실제 Stick Fighter에서 열리고 그렇게 보이는지는 한 번도 확인되지 않았다(P5 시험 파일 2개를 만들었지만 결과 칸이 비어 있음, 지금까지 앱 확인은 직선 삼각형 채우기뿐). 이게 안 되면 이펙트 SFA 전체가 다시 설계돼야 하므로 GPU·학습보다 먼저 확인한다.
3. **'좋은 20개' 고르기는 사용자가 한다.** 품질(감각) 판단은 사용자, 후보 만들기·정리는 Claude(2026-10-23 분담). Claude가 ΔE로 고르지 않는다 — ΔE는 누락·색 오류 찾는 보조.
4. **카메라 흐름(P2)을 연출 정답으로 쓰지 않는다는 지적**에 동의하며 하나 더: 지금 조립기(`storyboard_compose.py`)의 카메라는 3D 카메라다. 3D 금지에 따라 연출 시험은 2D 변환(이동·확대·회전·레이어별 변환·컷)으로 새로 짠다. 조립기는 기록용으로 둔다.
5. 연출 의도: 사용자 최신 의도(인물이 화면을 가려 전환 → 도시 구도에서 떨어져 착지)를 따른다 — GPT도 같은 판단.

## 3. 가장 먼저 할 작업

### 3-1. 앱 확인(사용자, 30분 이내 예상 — 실측 아님) — 막힌 것 풀기

### 3-2. 복원 후보 만들기(Claude, 서버 CPU) — 3-1과 동시에
