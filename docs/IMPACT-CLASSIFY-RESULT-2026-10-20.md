## 2. 과정

1. `tools/impact_cands.py`로 프레임 지표에서 후보를 뽑았다.
   - 1차 3,119구간을 뽑았다.
   - 누락 점검 뒤 규칙을 보완해 111구간을 더했다(3절).
2. `tools/impact_context.py`로 앞뒤 문맥과 같은 그림인지 쟀다.
   - `same_style=1`인 구간은 807개였다.
   - 이 가운데 표본 60을 눈으로 확인했고, 60건 모두 '아님'이었다.
   - 나머지 747개는 자동으로 '아님' 처리했다.
3. 나머지 후보는 `tools/impact_sheets.py` 띠(160×90, 앞 3·후보 최대 4·뒤 3)로 판정자 18명이 나눠 판정했다.
   - 지침은 [IMPACT-JUDGE-GUIDE](IMPACT-JUDGE-GUIDE-2026-10-20.md)다.
4. '아님_옆에실제'에서 판정자가 짚은 칸을 실제 프레임 번호로 바꿔 '맞음_옆에서찾음'을 만들었다.
5. 맞음·애매 582건의 재료를 480×270으로 다시 봤다(`tools/impact_hr_sheets.py`).
   - 결과는 연필 120, 디지털 256, 해당없음(그림 없는 섬광) 199, 불명 7이다.
   - pencil_strength가 2~3인 연필은 96건(46개 영상)이다.

## 3. 검증

- **사용자 판정 A**
  - 사용자가 임팩트로 본 4건은 모두 '맞음'이었다.
  - 사용자가 '옆에 실제'로 본 3건 중 2건은 같은 구간이 '맞음'으로 잡혔다. 70207은 후보에 없었다.
  - 사용자가 애매로 본 2건은 하나가 애매, 하나가 아님(200380)이었다.
  - 사용자가 아님으로 본 것 가운데 2건이 '애매'로 올라왔다: 119371 f527-535(캐릭터 공격동작), 230354 f163(전기 공격).
- **`impact_frames` 태그 영상 97개**
  - 1차에서는 88개에 맞음, 5개에 애매만 있었고, 4개에서는 아무것도 못 찾았다.
  - 못 찾은 4개를 다시 확인했다.
    - 203326: 영상 전체가 흑백이어서 흰 바탕 해칭 삽입 f60-63을 놓쳤다. 주변 ±12프레임 밝기 비교 규칙을 더해 잡았고, 판정은 맞음이다.
    - 252543: f75(노랑 바탕 검은 실루엣)가 후보에 없었다. 직접 '맞음'으로 넣었다. 이 규칙의 누락 원인은 아직 고치지 않았다.
    - 263191: 판정자가 전체 프레임을 훑어 f1517-1530의 색 반전 삽입을 찾았다. 14프레임으로 길다.
    - 205406: 붉은 바탕 한자 카드 f318-341만 있어 애매로 두었다. 사용자 검사에서 아님으로 정해졌다.
- **같은 그림 자동 처리:** 표본 60건 중 60건이 '아님'이었다.

## 4. 한계와 사용자 확인이 필요한 점

- 연필/디지털 판단(medium_hr·pencil_strength)은 참고용 기록이다. 사용자가 "맞음은 전부 학습 자료"로 정해 학습 사용 여부에는 쓰지 않는다. 사용자 규칙으로는 302394만 디지털이고 나머지는 연필이다.
- 직접 본 표본 12장(pencil_strength 2~3)은 대부분 연필·거친 붓 질감이었다. 74684 f1315-1321은 경계선이다.
- 계획 3절 3의 범위 밖 채점 표본 100개는 아직 하지 않았다.
- 후보 탐지의 재현율은 태그 영상 기준으로만 확인했다. 태그 없는 195개 영상 가운데 40개에서 맞음이 나왔다.

## 5. 다시 만들기

작업 폴더 `/home/user/imp`는 새 세션에 남지 않는다. 원본과 `/home/user/feats` 프레임 지표는 다시 만들어야 한다.

1. `tools/impact_cands.py <feats> cands.csv`로 후보를 뽑는다.
2. `tools/impact_context.py`로 문맥을 잰다.
3. `tools/impact_sheets.py`로 띠를 만든다.
4. 판정자가 판정한다.
5. `tools/impact_hr_sheets.py`로 재료 재확인용 띠를 만든다.
6. `tools/impact_drive_frames.py`와 `tools/impact_drive_build.py`로 Drive 폴더를 만든다.

뒤의 세 도구는 일회성이고 경로가 고정돼 있다.
