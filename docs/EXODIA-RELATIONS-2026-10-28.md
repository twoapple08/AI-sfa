# 엑조디아 학습법 — 요소 사이 관계 재기 (2026-10-28 사용자 제안)

## 생각(사용자)
파편·임팩트 프레임·불/폭발·연기/풍압/먼지·배경·인물을 따로 배워 모으면 최강이 될까?
문제: 애니에선 이미 합쳐져 있다. 나누면 구멍이 나고(메울 수 있음), 요소 B는 A 없이 설명이 안 된다(사진: 폭발 기둥과 파편·고리·인물 테두리광, 부서진 블록과 한 점으로 모이는 집중선·그림자).
합의: 굳이 나누지 않고, **요소들이 어떻게 이어져 있는지 설명하는 무언가(장면 설명서: 요소 목록 + 원인 + 관계)**가 핵심. 요소 수는 다섯 개로 한정하지 않는다(비유).
관계 = 원인 기준 상대값: 원인(위치·시점·크기·색) → 각 요소의 방향·거리·지연·색 물들임·그리는 순서.

## 2차 실험: 위치(원인 점에서 바깥으로 퍼지는가) — 22컷
대상: 원인(섬광·임팩트·폭발)이 컷 안에서 시작하고 그 뒤 파편·먼지·충격파·연기·불티가 시작하는 GPT 태그 구간 22개(scratch `exo/cands.json`).
원인 점 = 원인 장에서 밝기가 오른 상위 2% 픽셀의 무게중심. 시트에서 대부분 그럴듯한 자리(미사일 명중점, 섬광 중심 등).
퍼짐 점수 = 움직임 벡터와 '원인 점→그 픽셀' 방향의 코사인(움직임 크기 가중), -1 모임 ~ +1 퍼짐. 화면 격자 모든 점의 점수와 비교해 원인 점 순위를 본다.
- 1판(전체 화면 Farneback 광류, `exo/radial.py`): 원인 점이 뚜렷이 퍼지는 중심인 컷 4/22. 섬광·2장 찍기·카메라 이동으로 광류가 틀림 → 측정 방식 문제.
- 2판(같은 그림 반복 장 건너뜀, 움직인 영역 모서리점 LK 추적 + 되돌려 확인, 카메라 이동 = 중앙값 빼기, `exo/radial2.py`):
  원인 점이 상위 6% 안이고 최고점과 가까운 컷 5/19(s0013 0.62, s0326 0.36, s0416 0.43, s0180 0.47, s0346 0.47; 추적점 3개 미만 3컷 제외).
  중간 3(s0016·s0391·s0418), 반대 방향(원인 점 쪽으로 모이거나 다른 쪽으로 쓸림) 4(s0042 -0.67, s0173, s0386, s0410).
- 눈으로 본 유형(Claude, 시트 `exo/sheet_lk.jpg`): **방사형 폭발**(운석 충돌 s0013 등)과 **한 방향 쓸림**(빔에 밀린 바위 s0042, 지면을 쓸고 가는 파편 s0263)이 다른 관계다.
  최고점이 화면 가장자리·모서리에 붙은 컷은 대부분 한 방향 쓸림(퍼짐 점수는 먼 점에서 평행 흐름도 높게 준다).
- 한계: 섬광 장에서 추적이 튀는 긴 오추적 화살표가 남음. 원인 점 자동값이 틀린 컷 있음(s0042은 원인이 빔 발사점일 수 있음). 22컷은 GPT 태그로 고른 것이라 '파편'이 실제로 주인공이 아닌 컷도 섞임.
