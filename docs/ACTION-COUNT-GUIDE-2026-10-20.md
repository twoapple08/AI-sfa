# 액션 동작 세기 지침 (판정자용)

각 영상은 시트 이미지 여러 장이다: /home/user/act/<묶음>/<post_id>_<n>.jpg
- 한 장 = 6×4칸, 칸 간격 0.5초(한 장 12초). 칸 왼쪽 위 노란 글자 = 영상 안 시각(분:초).
- 영상 길이·시트 수: /home/user/act/<묶음>/index.csv
- 맡은 영상의 시트를 1번부터 끝까지 모두 본다.

규칙
1. 화면에 분명히 보인 것만 적는다. 애매하면 뚜렷함 '하'로 적거나 적지 않는다. 지어내지 않는다.
2. 0.5초 간격이라 아주 빠른 동작은 앞뒤 칸의 자세 변화로 판단한다(예: 팔이 뻗었다 돌아옴 → 주먹).
3. 이펙트·연출도 적는다(폭발, 연기, 파편, 출혈, 충격파, 임팩트프레임, 스미어, 배경동화, 카메라 회전 등).
4. 영상 전체를 장면 단위로 빈틈없이 나눈다. 액션이 없는 장면은 '비액션' 한 줄.

동작 이름
[공격] 주먹 / 발차기 / 몸통·박치기 / 잡기·조르기 / 던지기·메치기 / 검 / 창·봉 / 둔기 / 총 / 활 / 기타무기 / 손에서 에너지 발사
[방어·이동] 회피 / 막기·쳐내기 / 구르기·낙법 / 점프·공중동작 / 벽타기·벽차기 / 질주·대시 / 순간이동·잔상·분신
[피격] 맞고 날아감 / 맞고 쓰러짐·바닥충돌 / 밀려남 / 맞는 순간 경직
[기타 동작] 곡예(공중회전·비틀기) / 1대다수 / 다수대다수 / 탈것 위 전투 / 비행 전투 / 거대 상대(괴수·메카)와 전투
[이펙트·연출] 기 모으기·충전 / 오라 방출 / 카메라 회전·궤도 / 슬로모션·정지 / 마법진·문양 / 변신 / 비·눈 / 증기 / 기타:이름
여러 개면 "복합(질주+도약)"처럼 쓴다.

출력 CSV(UTF-8), 머리줄 그대로:
묶음,post_id,시간구간,동작,주체,뚜렷함,이펙트,배경고정,캐릭터고정,특이사항
- 시간구간: 0:05~0:08
- 주체: 1인/2인/다수/없음 · 뚜렷함: 상/중/하
- 이펙트: 세미콜론 구분 · 배경고정/캐릭터고정: O/X(카메라·배경이 고정인지, 캐릭터가 제자리인지)
- 특이사항: 본 것 그대로 한 문장(40자 이내). 쉼표가 들어가면 큰따옴표로 감싼다.
