## 볼 것과 문제 구분
| 증상 | 문제 층 | 다음 조치(설계 유지) |
|---|---|---|
| 아예 안 열림, 오류 메시지, 빈 화면 | **파일 참조**(XML 구조·ID·점 연결) | 오류 문구 사진 → 변환기의 참조 규칙만 고침. 같은 파일을 서버 검사기로 대조 |
| 열리는데 채우기가 없거나 직선으로 꺾임·삐져나옴 | **곡선 채우기**(FS 경계의 곡선 구간 해석) | 곡선 경계를 짧은 곡선/직선 여러 조각으로 나누는 판을 만들어 비교 |
| 색은 있는데 겹침 순서가 이상함(명암이 밑색 아래, 선이 가려짐), 반투명이 불투명처럼 보임 | **합성 순서**(레이어·DrawOrder·알파) | 레이어 배정·그리는 순서 규칙만 바꿔 다시 만듦 |
| 600개는 되는데 2,500개에서 매우 느림·편집 불가 | **도형 수** | 같은 그림을 더 적은 조각으로(곡선 맞춤 허용 오차) — 품질 대비 측정 |
| 큰 파일에서 앱이 꺼짐·로딩이 매우 김 | **메모리** | 프레임·파일 나누기, 도형 수 줄이기 |

## 서버 렌더러로 이미 보이는 것(앱 확인 아님)
- 이펙트만 SFA를 검정·흰·회색·하늘색 바탕에 옮기면 **얇은 흰 테두리**가 보인다(원본 흰 바탕이 마스크 가장자리로 들어옴, `--grow 2`). 흰 바탕에서만 안 보인다 → 배경 오염. 앱에서도 같은지 함께 본다.
