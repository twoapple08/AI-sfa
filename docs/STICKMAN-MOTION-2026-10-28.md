# 스틱맨 움직임 자료 (2026-10-28 사용자: "내 주된 목적은 스틱맨의 움직임을 다루는 것")

사용자가 모은 SFA(`data/user_sfa/`, 393개)의 주된 쓰임은 **스틱맨의 움직임**이다. 이펙트·기법 정보는 부수적으로 쓴다.
SFA 스틱맨은 선·점 자체가 뼈대라 포즈 추정(추측)이 필요 없고, 장이 바뀌어도 같은 오브젝트 ID가 남아 관절이 그대로 이어진다.

## 뼈대 추출 (`tools/sfa_stickman_extract.py`, 시험 `tests/test_sfa_stickman_extract.py`)
- AC로 이어진 점 + 0.3 단위 안에 겹친 끝점(AC 없는 옛 파일)을 한 관절 노드로 합치고, 원 1개 + 직선 6개 이상 덩어리를 스틱맨 후보로 본다.
- 목 = 머리 원이 붙은 노드, 엉덩이 = 목에서 나가는 선 중 파란점(Flags 3)·가지 많은 쪽, 팔 = 목에서, 다리 = 엉덩이에서 나가는 사슬. 좌우는 오브젝트 ID 순(장 사이 유지).
- 결과 `data/stickman_motion/user_sfa_skeletons_2026-10-28.jsonl`: 151파일 25,774 스틱맨-장. **표준 뼈대(팔 2·다리 2, 각 2마디) 20,311**. 같은 몸통 ID로 10장 이상 이어진 트랙 740개(20,891장).
- 확인: 겹침 영상(모션작1·予定調和·달리기·X_SPECTRUM 96장) — 머리·몸통·팔·다리가 원본 선과 일치(Claude 눈 판정).
- 못 잡는 것: 팔이 몸통 중간에 붙는 등 비표준 연결(약 3,800장, `arms` 0개), 반투명 잔상(앞 장 흔적) 인물, 네발 생물.

## 주의
- T/F를 모른다 → 장 번호는 순서로만 쓰고 시간·속도로 읽지 않는다.
- 같은 애니의 저장본 여러 개(X_SPECTRUM·X·X_SPECTRUM-1 등)는 거의 같은 움직임 → 학습 전 유사 중복 제거 필요.
- 품질(잘 만든 동작 vs 연습)과 동작 종류(걷기·달리기·타격·검·쓰러짐) 태그는 아직 없다.

## 스파 연계 교본 — 관절 궤적 시각화 (34장, 레이어 3)
- 레이어 1: 검은 스틱맨(추출기 34/34장 검출, 팔 2·다리 2).
- 레이어 2: 관절마다 정해진 색 선이 **이전 장 관절 위치 → 지금 관절 위치**를 잇는다(끝점 대조: 지금 장·이전 장 관절과 1 SFA 단위 안). 색 = 관절: 자홍 FF00FB 팔0 팔꿈치, 하늘 00F5FF 팔1 팔꿈치, 빨강 FF0000 팔0 손, 파랑 1100FF 팔1 손, 노랑 E0E912 다리0 무릎, 진초록 038A00 다리1 무릎, 주황 FF8C00·연두 06FF00 발. 즉 관절 간격(spacing)과 궤적을 그린 교본.
- 레이어 3: 반투명 보라(알파 0x73) 곡선이 몸 전체를 감싸는 덩어리 윤곽(실루엣·무게 덩어리).
- 쓰임: 관절 궤적 학습의 정답 예시(사람이 의도한 궤적 표시), 생성 결과 검사용 시각화 형식(우리 미리보기에도 같은 방식으로 관절 궤적 선을 그릴 수 있음).
