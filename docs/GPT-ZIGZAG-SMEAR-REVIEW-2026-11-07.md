# 사용자 정정 v3 — 불투명 지그재그 선 스미어

## 이번 정정이 우선한다

사용자는면표현/반투명으로스미어의들쭉날쭉한가장자리와역동성이사라졌다고지적했다. **스미어는채움면으로만들지않고,투명도는웬만하면사용하지않는다. 4.sfa처럼지그재그로연결한선묶음에서꺾임을늘려이동거리/속도감을표현한다.** 위/아래공중두형태는사다리꼴이며끝이반드시가늘필요없다. 넓어지는쪽은이동방향의앞이아니라 **움직이는부위의가장바깥쪽**이다.

High를권장하고이전면판을정정했다. 사용량갱신후이어진진행지시는현재수정의계속으로처리했으며새작업으로리셋하거나사용량잔여치를추정하지않았다. 이번은사용자지침에따른형태후보이며실제작가의형태를자동학습한것은아니다. 기존면판은기록으로보존하고스미어의채택기본으로쓰지않는다. 일반발광이펙트전체의채움/알파기능을금지하는뜻으로확대하지않는다.

## 실제 구현

`tools/zigzag_smear_review.py`는같은승인원본216076/수동팔축/위아래영역중심을재사용한다. 새원본·작가·모델·GPU·생산기본값변경없음.

- **팔:**팔꿈치에서시작폭0,손쪽바깥으로갈수록벌어지는지그재그연속선. 팔축좌표/Flags는그대로이며첫점은기존팔꿈치에AC접합한다.
- **공중두형태:**각원본영역중심과현재팔꿈치를연결하는바깥방향을해석한다. 팔꿈치에가까운경계폭0.55,먼경계폭1의사다리꼴포락형태에지그재그선을친다. 양끝폭이남는다. 위/아래두형태를요청대로다시보존하며이전판의손근접영역자동삭제를적용하지않는다.
- **이동/궤적의역할:**이전의서로다른손중심과현재손중심거리로지그재그벌어짐크기를조절하고,이동방향의접선성분으로휨을조절한다. 이동벡터를반대로바꿔도같은바깥쪽경계가넓도록폭의극성과분리했다. 반복그림은이전유효이동거리/방향을유지한다.
- **거친겉선:**연속선의꺾이는지점마다폭을조금씩달리해매끈한면경계가되지않게했다. 면·면마스크를사용하지않았다. 모든효과객체는직선TypeId1이다.

이동거리×0.12,공중폭의추가벌어짐,0.55의안쪽폭비,가장자리변주등은검토계수다. 실제물리속도/원본작가정답이아니다. 공중부위의진짜회전축과과거/현재/미래손대응은여전히미확정이다. 여기서는현재수동팔꿈치를근위기준으로삼은재구성가설이다.

처음38연결선/묶음으로만들었으나작은영역에서는선이뭉쳐면처럼보였다. 확대/축소렌더를확인하고 **14연결선/묶음**으로간격을열었다.14는표현상한/필수문법이아니며분할수는설정가능하다. 4.sfa의반복38객체를전역규칙으로복제하지않는다. 단순히선밀도를높여속도감이라고부르지않는다.
