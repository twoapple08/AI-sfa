# Gemini 업데이트 + 작업 지시 (2026-10-17 최신, Claude 작성)

> 이 글이 Gemini 작업의 **최신 기준**이다. 앞서 받은 "Gemini에게 붙여 넣을 현행 요약"과 다르면 **이 글을 따른다.** 사용자가 조정 권한을 Claude에게 맡겼으므로 역할 배정은 Claude가 정한다.

## 0. 지난 요약 이후 바뀐 것 (반드시 반영)

1. **임팩트 프레임 기준 (사용자 필수 조건, 최중요):** 임팩트 프레임은 **4B 연필로 직접 그린 선화 느낌만 학습**하고, 디지털 단색 느낌은 학습하지 않는다. 구분 태그 2개를 새로 만들었다.

| 태그 | 보이는 특징 | 학습 |
|---|---|---|
| `impact_frames_pencil` | 흑연 선 결이 보임, 방사형 해칭을 겹쳐 회색 농도를 만듦(빽빽할수록 진함), 흰 종이 바탕, 거칠고 갈라진 가장자리, 손으로 그은 불규칙한 선 굵기 | 함 |
| `impact_frames_digital` | 검정·흰·단색으로 꽉 찬 평면, 매끈하고 날카로운 가장자리, 선 결·해칭 없음, 면 안의 농도가 균일, 화면 전체 흰색·검정 깜박임 | 안 함 |

   - 디지털 기준 예시: https://www.sakugabooru.com/post/show/302394 의 **0–13프레임**(24fps, 0부터 셈). 흰 가시 섬광 면(0·2·3), 검정 전면(1·5·13), 흰 전면(8·11). 14프레임부터는 불꽃 이펙트다.
   - 연필 기준 예시: 사용자가 준 원화 사진(흰 종이 위 흑연 방사 해칭, 중심 흰 섬광, 인물 실루엣을 흰 여백으로 남김, 십자 섬광선). 사용자가 이 사진을 함께 보내 준다.
   - 판정 단위는 **프레임 구간**이다. 한 클립에 둘이 섞일 수 있다. 거칠지만 붓·먹 느낌이면 연필로 단정하지 말고 '후보'로 둔다.
2. **구작·최신작 비교:** 오래 활동한 작가는 기술이 뒤처졌던 시기의 작화에 사용자가 만족하지 못할 요소가 있을 수 있다. 구작과 최신작을 비교해 **양쪽 모두에 있는 기법은 중요도를 높이고**, 구작에만 있는 기법은 낮춘다. 작품 연도는 **그 장면이 실린 판본의 최초 방영·공개일**(게시일 아님). **에반게리온 클립은 학습 제외.**
3. **태그 보정:** Sakugabooru 태그는 사람이 달아서 빠진 것이 있다. 영상에 보이는데 태그가 없으면(예: 각진 다면체 파편인데 `yutapon_cubes` 없음) 우리 쪽 보정 표에 **근거 프레임 번호와 함께** 추가한다. Sakugabooru 사이트 자체는 고치지 않는다.
4. **nian41 범위:** 사람 몸 움직임만. 표정 같은 그림체, 머리카락, 이펙트, 연출은 학습 제외. 옷자락은 사용자 확인 대기.
5. **nian41 본인 작화 확정:** nian41 본인 X 게시물(본인이 "내가 그린 부분"이라고 밝힘)과 프레임 대조로, Sakugabooru 280544·280597·280830·280831·280833·280834·280835·287139·287140·301142·216085가 본인 작화로 확정됐다.
6. **원본 보관 완료:** Google Drive `AI-sfa/01_원본영상/`에 yutaka_nakamura 358건(GPT, 에반게리온 10건 제외)과 nian41 48건(Claude, Sakugabooru 36 + 본인 X 12). 모두 md5 검증 완료. Drive 남은 용량 약 4.7 TiB.
7. **역할:** GPT = yutaka_nakamura 수집·분석. Claude = nian41 분석, 측정·대조, 지식베이스 통합, 조정. **Gemini = 아래 작업 A·B·C.**

작가마다:

1. `presumed`가 아니고 단독 작가 표기인 클립을 **최근작 2개 이상 + 구작 1개 이상**(가능하면) 골라 직접 본다. 에반게리온은 고르지 않는다.
2. 다섯 항목을 평가한다.
   - **이펙트 축(yutaka 계열):** 2톤 평면, 날카로운 외곽, 각진 파편, 플래시 구두점, 제한 팔레트.
   - **몸 움직임 축(nian41 계열, 몸만):** 2s 바탕 + 순간 1s, 예비→순간→후속, 1프레임 스미어, 원근 과장. 표정·머리카락은 평가하지 않는다.
   - **임팩트 프레임:** 연필 / 디지털 / 섞임 / 없음. 근거 post_id와 프레임 번호.
   - **구작·최신작 지속성:** 그 작가의 대표 기법이 시기와 무관하게 이어지는지.
   - **앱 이식성:** Stick Fighter 재료(직선·원·곡선·평면 채우기·glow·투명도·색·선 굵기·레이어·프레임 배경색)로 재현 가능한지. 촬영 발광·그라데이션·블러·카메라 효과에 기대면 낮다.
3. 결론: **승낙 추천 / 보류 / 반려 추천** 중 하나와 이유 2–3줄.

## 3. 작업 C — 통과 후보 자료 추가 시스템 설계

사용자가 후보를 **승낙**하면 그 작가 자료를 어떻게 들여올지 정하는 절차와 서식을 만든다. 아래 초안을 검토하고 빠진 점·위험·개선안을 제시한다. 최종 확정은 Claude가 조정한다.

**초안 — 승낙 작가 편입 절차**

1. **편입 카드 작성 (Gemini):** 작업 A 결과를 카드 한 장으로 정리한다(서식은 4절). 학습 축(이펙트/몸 움직임/둘 다), 제외 범위(예: 그림체·머리카락), 대표 클립, 임팩트 성격, 구작·최신작 지속 기법.
2. **사용자 승낙:** 사용자가 카드를 보고 승낙·반려·범위 조정을 정한다.
3. **목록 만들기 (Claude):** Sakugabooru 작가 태그 전체를 메타데이터로 색인해 `catalog.csv`에 행을 추가한다. `presumed`는 별도 표시, 사용자 제외 대상(예: 에반게리온)은 제외 표시.
4. **출처 증명 (GPT 또는 Claude, Claude가 배정):** Sakugabooru 밖 자료까지 A 본인 게시 / B 공식·DB 크레딧 / C 커뮤니티 태그 / D 팬 귀속으로 등급을 매긴다. A·B는 컷 단위로 연결한다.
5. **원본 보관 (Claude가 배정):** Drive `01_원본영상/<작가>/`. 파일명 `<post_id>_<md5>.<ext>`, 독립 ZIP(≤90MiB) 또는 개별 파일. manifest에 post_id·url·md5·sha256·크기·태그·증명 등급·presumed 여부. Drive md5 대조 필수.
6. **태그 보정·임팩트 분류:** 보이는데 빠진 태그는 보정 표에 add. 임팩트 프레임은 `impact_frames_pencil`/`impact_frames_digital`로 프레임 구간마다 분류.
7. **분석:** 최근작부터. 각 기법에 `era`(최초 방영·공개 연도)와 `old_new_common`(구작·최신작 공통 여부) 표시. 부모-자식 게시물은 한 장면으로 센다.
8. **지식베이스 반영 (Claude):** 두 AI 이상이 같은 판독을 하거나 연속 프레임으로 확인된 규칙만 '규칙 후보'로 올린다. 단일 표본은 표시한다.

## 5. 규칙

- 근거 표시: [영상 직접 확인] / [추론]. 확정 규칙처럼 쓰지 않는다. 보지 못한 것은 "미확인"이라고 쓴다.
- 영상·이미지를 공개된 곳에 올리지 않는다. 토큰·키를 출력하지 않는다. 로그인 차단·접근 제한을 우회하지 않는다.
- 결과는 사용자가 Claude에게 붙여 넣는다. 작업 A·B·C를 나눠서 보내도 된다(A 먼저 권장).
- 작업 전에 이 작업에 맞는 모델·추론 설정을 먼저 알린다(사용자 공통 지시).
