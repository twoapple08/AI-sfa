# 태그 안내서 (2026-10-22)

`tools/tag_index.py`에 넣을 수 있는 태그 전체, 그리고 그 태그를 넣으면 무엇이 나오는지 적은 문서다.
모든 태그는 **한글 이름으로 쓴다**. 영어 원래 태그(괄호)로 넣어도 같은 것이 나온다.

- **지금 나오는 것**: `find <태그>`를 쓰면 해당 장면 목록이 나온다. `extract <태그>`를 쓰면 그 장면의 영상 조각(mp4)과 목록 csv가 나온다.
  - 영상 조각은 원본에서 잘라 낸 것이라 저장소에 넣지 않는다.
  - 기본으로 앞뒤 6프레임을 더 잘라 준다(`--pad`).
- **앞으로 나올 것**: 이 태그로 학습한 생성 AI가 그 태그를 받으면 만들 결과물(목표)이다. 아직 학습한 모델이 없어서 지금은 생성되지 않는다.
- **가중**은 그 태그를 얼마나 믿을 수 있는지를 나타낸다. 사람 판정은 1.0, AI 판정은 0.8, 자동 검출은 0.5, 게시물 전체 태그는 0.3이다. `--min-weight`로 걸러 쓸 수 있다.
- **하위 태그**: 상위 태그를 넣으면 하위 태그 장면까지 함께 나온다. 예를 들어 `공격`을 넣으면 `공격_킥`과 `공격_펀치` 장면도 나온다.

## 쓰는 예
```
python tools/tag_index.py tags                                  # 태그별 개수
python tools/tag_index.py find 공격_킥 --animator nian41          # nian41 발차기 목록
python tools/tag_index.py find 임팩트_연필 --min-weight 0.67       # 연필 진하기 2 이상
python tools/tag_index.py extract 폭발 <출력 폴더> --videos <영상 폴더>
```

## 아직 없는 것(다음에 늘릴 태그)
- 카메라·연출: 화면 흔들림, 슬로우, 줌, 컷 전환. 측정 자료(P2 카메라)는 있지만 태그 구간으로 묶지 않았다.
