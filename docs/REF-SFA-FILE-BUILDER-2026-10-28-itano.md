# 받은 창작 SFA(itano_circus_tween) 정리 시험 (2026-10-28)

잉크 파일을 준 sfa-file-builder 제작자의 창작 SFA. 원문 파일은 다른 사람 것이라 저장소에 넣지 않는다(scratch만). 여기에는 측정과 판단만.

## 구조 [서버 측정]
- 96장, (24,12)(트윈 24·재생 12, 사용자 설명), 레이어 1개, 직선 25,204·원 36·채우기 36. 장당 오브젝트 34–881(중간 177), 서로 다른 AO ID 8,518, 앞 장과 ID 이어짐 평균 66%.
- 사용자가 '불필요한 오브젝트'로 본 촘촘한 파란·빨간 점: 길이 약 0.45, 간격 약 0.56의 **점선 조각**(각자 시작점 Flags 3, 연결 없음). 굵은 모서리와 평행(약 7px 옆)하고, 화면에 실제로 점선으로 보인다. 장마다 약 1.6단위씩 아래로 이동하다 몇 장 뒤 사라진다 → **모서리를 따라 흐르는 빛줄기 이펙트**(의도된 움직임)로 판단. 12장 표본에서 점선 사슬 68개, 장당 평균 83조각.
- 진짜 군더더기: 0길이 직선 298개, 다른 직선 위에 통째로 덮인 직선(1px 이내) 2,720개(같은 색·굵기 2,326).

## 도구 `tools/sfa_line_clean.py`
0길이·덮인·중복 직선 지우기. 연결(AC) 있는 것·채우기가 쓰는 것은 두고, 트윈을 깨지 않도록 그 ID가 나오는 **모든 장**에서 지울 조건이 맞을 때만 지운다.
| --tol | 지운 오브젝트 | 렌더 차이(96장, 1920×1080) |
|---|---|---|
| 0.01 | 358 | 32 넘게 다른 화소 장당 최대 84, 96 넘는 화소 0 |
| 0.02 | 731 | 장당 최대 217, 96 넘는 화소 최대 25 |
| 0.05 | 1,619 | 장당 최대 838, 겹쳐 굵어 보이던 모서리가 약간 가늘어짐 |
`sfa.py validate` 오류 0. 앱 확인 전. 트윈 중간 장은 서버 렌더러가 그리지 않으므로 키 장만 비교.

## 남은 판단(사용자)
- 흐르는 점선 이펙트를 둘지, 배경만 남길지.
- 유타퐁 큐브용 '직선 몇 개로 된 상자'는 다음 단계: 상자 모서리(긴 직선)만 남기고 면별 4선으로 다시 그리기.
