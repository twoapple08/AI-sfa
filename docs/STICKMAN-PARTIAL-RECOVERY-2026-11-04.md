## 재사용 순서

1. 이 브랜치의 코드·프로필·장면 태그와 Drive 원영상/RTMW/선택관측을 준비한다. 스킬 파일만으로는 실행할 수 없다.
2. `scenes/nian41_432-1871_limb_views_v2.json`은 좌표 정답이 아닌 구도/범위/그림 키 메타데이터다. 새 장면에서는 원본에서 태그 의미와 관측 범위를 확인한다. 자동 분류라고 부르지 않는다.
3. 팔: `stickman_view_recovery.image_support`로 색 지지를 계산한 뒤 `stickman_limb_regions.regional_arm_tracks(K,support,observed,frames,spans,actor,width,regions)` 호출. `spans`는 해당 캐시의0기준 키 범위다. 결과 `tracks`는 기존 `stickman_scene.apply_scene`에 넣는다. 입력 미검출 프레임은 관측으로 쓰지 않는다.
4. 직선 스미어: `rtmw_validate.color_masks`의 해당 인물 마스크와 확인한 허브/방향/몸통 기준 관측 띠를 `stickman_smear_axis.measure_straight_limb`에 준다. 빈/짧은 관측은 실패 처리한다. 이 함수가 팔다리 종류를 자동 인식하지 않는다. 원본에서 굽은 동작에는 적용하지 않는다.
5. 가림은 장면 `occlusions`와 `stickman_occlusion.bridge_occlusions`를 사용한다. 뼈대 구조를 변경하지 않는다. 원본 전경 물체는 별도 변환기 대상으로,흰 배경의 뼈대 영상에는 넣지 않았다.
6. 새 좌표/측정 전체는 Drive만 보존한다. 기존 SFA의 수정 인물/장만 교체하고 실제 XML/관측·출력·원본/면 포함 검사/루트 전체시험을 대조한다. 최종 앱 편집과 포즈 눈 판정은 별도다.
