# GPT 지시문 T01 — 포즈 추적 눈 검사 (2026-10-21)

자료: Drive `AI-sfa/00_목록/_GPT용_시트/T01_포즈추적/`(시트 111장 + `T01_목록.csv`), 또는 `T01_포즈추적.zip`.
결과 파일: `gpt_T01_2026-10-21.csv` (UTF-8). Claude가 이 결과로 포즈 정리 도구(tools/pose_tracks.py)의 '사람다움' 기준값을 정한다.

---

아래를 그대로 GPT에 붙여 넣는다.

```
애니메이션 영상에서 자동으로 잡은 사람 뼈대(포즈)를 눈으로 검사해 줘.

첨부한 시트(T01_001.jpg ~ T01_111.jpg)는 각각 한 '추적'(같은 대상을 여러 프레임 따라간 것)이야.
시트 한 장 = 같은 추적의 4프레임(왼쪽부터 처음 → 끝)을 가로로 붙인 것.
빨간 선 = 몸 뼈대(코·어깨·팔꿈치·손목·엉덩이·무릎·발목을 이은 선), 초록 점 = 손가락·발 점.

시트마다 아래 중 하나로 판정해:
- A: 사람(사람 모양 캐릭터)이고 뼈대가 대체로 맞다(4프레임 중 3프레임 이상 관절 위치가 맞음)
- B: 사람이고 뼈대가 일부 틀리다(1~2프레임이 틀리거나, 팔·다리 하나가 엉뚱한 곳)
- C: 사람이지만 뼈대가 대부분 틀리다(3프레임 이상 엉뚱함, 좌우가 뒤바뀜 포함)
- D: 사람이 아니다(괴물·동물·로봇·물체·이펙트에 뼈대가 그려짐)
- E: 판단 불가(얼굴 클로즈업·너무 작음·화면이 하얗게 날아감 등)

규칙:
- 사람 모양이면 괴물 같은 외형이어도 팔다리가 사람 구조면 '사람'으로 본다. 동물 모양·물체는 D.
- 4프레임 중 일부가 다른 장면(컷이 바뀜)이면 메모에 '컷 섞임'을 적는다.
- 확실하지 않으면 메모에 '애매'를 적는다. 추측으로 채우지 않는다.

결과는 CSV 한 개로 줘(머리줄 그대로):
시트,판정,틀린프레임,메모
- 틀린프레임: 틀린 프레임 번호(1~4)를 ;로. 없으면 빈칸.
- 메모: 짧게(예: 좌우 바뀜, 다리 위치 틀림, 컷 섞임, 애매).
111행 모두 채워. 10장씩 끊어서 처리해도 된다.
```
