# 원본 회전 궤적의 독립 곡선 표현층 비교

## 사용자 합의와 이번 범위

권장 추론 High. 발 표현 합의는 계획표에 기록했다:기본 무릎→뒤꿈치 한 선,접지/밀어내기·타격 방향·근접 표현에 필요할 때만 뒤꿈치→발끝 짧은 선 추가. 이 합의로 기존 전체 프로필을 일괄 수정하지 않는다.

이전301158 태그의 신체변형 구간만으로 덧대는 효과를 분리하기 어려워 기존 승인 자료의 앞뒤를 확인했다. **손을 중심으로 회전하는 망치의 잔상/번짐과 밝은 호 궤적**이 읽히는 구간을 골랐다. 이 중 밝은 호 하나만 수동 근사해 독립 SFA 효과층으로 비교한다. 원본 전체 스미어·붉은 잔상/불규칙 끝/발광을 재현하거나 몸 뼈대에 붙인 완성판이 아니다. 몸동작 사례와 물체 궤적 사례를 같은 성공으로 세지 않는다.

## 원본과 직접 판독

- 기존 승인 [게시물301158](https://www.sakugabooru.com/post/show/301158),nian41 태그. 기존 목록의 귀속은 **C 커뮤니티 태그**,이번 독립 작가 확인은 없음. 나카무라 이펙트·연출 우선순위를 바꾸지 않는 보충 개발 사례다.
- 원본35,318,203바이트,MD5 `630377763bac23c822c64d3357a1dc6e`가 기존목록과 일치.854×480,1921장,원본24000/1001fps.
- 340~398의2장 간격30장 개요를 본 뒤388~399 연속12장을 추출하고390~396을 원본 크기로 직접 판독.390~394에서 선택한 밝은 호의 위치/방향이 변하고395에는 그 호가 사라져 망치 형상이 읽힌다. 다른 발광 전체가 사라진다는 뜻은 아니다. 실제 최초 시작은 선택 구간 전일 수 있다.
- 손/인체/의복/얼굴/머리카락은 추출·학습하지 않았다. 궤적을 스미어/잔상/발광으로 정확히 분해한 자동 정답도 아니다. `training_ready=false`,`held_out=false`.4.sfa의 배치/타이밍이나 형태를 가져오지 않았다.
- 임시 원본영상은 판독 후 삭제. 근거12장/PTS,수동 곡선·폭 입력,사건기록은 `/workspace/scratch/smear_layer/`에 비공개 보존했다.

## 실제로 만든 것

비공개 `/workspace/scratch/smear_layer/review/curve_layer_review.zip`에6장 SFA두개,사건 바인딩 두개,원본/A/B 비교PNG,한국어설명이 있다.

A `plain.sfa`:동일 중심곡선,일정 폭,글로우 없음.
B `variable_glow.sfa`:동일 중심곡선,구간별 폭 변화와 글로우.9개2차곡선 조각으로 폭을 달리한다.9는 비교 프로브 설정이며 표현개수 상한/필수문법이 아니다. 픽셀마다 선을 따지 않았다. 삼각형 하나에 고정하지 않는다.

각 장의 수동2차곡선3점/폭3값은 원본에서 판독한 근사다. 색·글로우 계수·폭 프로필은 정량 추정한 작가 스타일의 정답이 아니다. 양판의 중심 궤적/장/출현 조건은 동일하다.390~394는표현,395는색알파0/글로우0으로선택한호소멸. 소멸한 장의 비표시 기하는마지막형태를유지하며새관측으로세지않는다.

서버 렌더 비교에서 B는중간폭과번짐이읽히지만조각별폭변화경계가약간보인다. 원본의복수잔상/거친끝/반복무기형태가빠져원본전체보다훨씬단순하다. 이 제한을 미관합격/스타일학습성공으로 덮지 않는다. 글로우 근사와 화면여백0의 검토시트이며 앱 픽셀 일치 검증이 아니다.

출력24/24는사용자조건이다. 원본6장시간0.25025초,출력6장0.25초로0.1%빠르다. 원본장1:1대응을유지하고이차이를명시했으며시간이완전히같다고주장하지않는다. FPS조건은옆기록에보존한다.
