## 핵심 지시 (요약)
- 한국어로 대화한다.
- 혼자 가능한 일은 자율로 진행한다. 다만 이미 끝난 작업을 오판으로 반복하지 않는다.
- 품질 향상·토큰 절감 목적이면 어떤 외부 도구든 써도 된다. 같은 허용을 다시 묻지 않는다.
- SFA 결과물은 용량 제한이 없다. 목표는 "최상급 품질이면서 최대한 가볍게"이고, 크면 나눠서 전달한다.
- 레이어 기능은 항상 쓴다.
- SFA를 만들 때는 HANDOFF 4절 규칙을 반드시 지킨다.
  - AO ID별 형태 고정. 어기면 앱의 선 그리기가 망가진 실제 사례가 있다.
  - 프로브식 ID 범위
  - 앞뒤 순서는 레이어로
  - 채우기는 캔버스 근처로 자르기
- 원본 영상, APK, 역컴파일물, 다른 사람의 작품은 공개하지 않는다.
- 휴대폰 재설치·페어링은 실제로 문제가 생긴 경우가 아니면 요청하지 않는다.
