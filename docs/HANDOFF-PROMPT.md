## 지금 위치
- 정답지, 학습기, 채점기, 자료 만들기, PC bat, Kaggle 원격, Drive 이어달리기까지 다 갖췄다.
  - 단위 시험 66개 통과
  - Kaggle GPU 30분 짧은 시험 통과
  - 620MB 학습 상태 올리기 확인
- **사용자 결정: Kaggle GPU 시간은 아꼈다가 남은 확인이 끝나면 풀로 돌린다. 사용자 지시 없이 Kaggle GPU 실행 금지.**
- 남은 확인(각각 사용자 승인 뒤)
  1. Kaggle CPU로 전체 자료 미리 만들기 + GPU 실행이 그 자료를 바로 쓰는 모드 구현(GPU 시간 0)
  2. 사용자 PC(4060/5060) 4~6시간 학습: 긴 장 메모리, 위치를 배우는지(위치 시험 `shift_` 점수)
  3. 결과로 판단: 위치를 따라가면 Kaggle 풀(PC 학습 이어받기), 정체하면 PC에서 sin 비교(새 폴더에서 처음부터)

## 사용자와 일하는 방식
- 먼저 답하고, 계획(무엇·왜·얼마나)을 말한 뒤 작업한다. "아직 하지 말라"면 계획만 말한다.
- 결과는 그림(입력 | AI SFA | 원본)과 숫자로 보여 주고, 틀리면 틀렸다고 말한다.
- 사용자 원칙
  - 스파로 그린다.
  - 파일을 원본 파일로 채점한다. 만점이면 영상도 같다.
  - 영상이 안 바뀌는 차이(ID·면 칠 순서·파란점·점 방향·겹치지 않거나 같은 겉모습끼리 순서)는 정답으로 친다.
  - 둥근 곳은 곡선, 비율은 파일 그대로.
  - 24,24 트위닝 없음.
- GPT 토론
  - 사용자가 중계한다. 근거로 동의하거나 반대하고, 측정으로 가를 수 있으면 잰다.
  - 합의가 안 되면 쟁점과 양쪽 근거를 정리해 사용자 판정을 받는다.
  - GPT 추가 검사 자료를 받으면 README부터 끝까지 읽는다.
- 같은 서버에서 학습이나 채점을 동시에 두 개 돌리지 않는다(10-30에 두 번 결과 무효).
- 백그라운드 대기 명령에 다른 작업을 이어 붙이지 않는다. `pkill -f`로 자기 셸까지 종료시키지 않는다.
- 3D 금지. 원본 영상·추출 프레임·가중치는 저장소에 넣지 않는다. 토큰·키 출력 금지.
