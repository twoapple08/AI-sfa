## 사용자와 일하는 방식(이번 대화에서 확인)
- 결과는 그림·영상·SFA로 바로 보여 주고, 문제를 정직하게 적는다. 규칙 코드로 그림을 '지어내는' 방식은 품질 미달로 판정됐다 — 창작은 학습 모델, SFA 변환은 검증된 분해기·변환기.
- 오래 걸리는 작업은 시작 전에 시간을 말하고, 중간에 짧게 알린다(사용자가 "오래 걸리네"로 두 번 멈춤).
- 사용자 PC 안내는 복사해 쓰는 명령 줄로. C 드라이브 용량이 적어 모두 D(`D:\ph` Python, `D:\mm` 작업)에 둔다. cmd를 새로 열면 `set` 다섯 줄을 다시 입력해야 한다.
- 외부 AI(GPT Codex)에는 저장소·rclone이 연결돼 있다. 프롬프트를 줄 때 마지막에 커밋 해시·파일 경로를 보고하게 한다.
