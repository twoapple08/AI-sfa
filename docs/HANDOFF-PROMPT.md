## 0. 현재 우선순위와 핵심 문제

**우선순위:** 임팩트 프레임 거르기의 정확도. 사용자가 전부 직접 검사하기는 힘들다고 했다. 모델 훈련은 허가되지 않았다(추론만 가능).

**핵심 문제 — 앞뒤 문맥을 모른다 (2026-10-19 사용자 지적, 최중요):**
- 예: `임팩트_재분류_2026-10-19/optical-core/32488/재검사-임팩트쪽_f121-122_B007`. f119 청록 바탕 해골 얼굴 → f120–122 회색 바탕에 남색 선으로 눈 부분을 클로즈업 → f123–124 다시 청록 바탕 얼굴. **같은 컷 안에서 눈을 당겨 보여 주는 연출일 뿐인데** 임팩트(재검사-임팩트쪽)로 올라왔다.
- 사용자 말: "그냥 눈 부분을 클로즈업하는 건데 임팩트 프레임으로 판정하고 있잖아. 이건 앞장면과 뒷장면의 문맥을 모른다는 거랑 똑같은 거야."
- 왜 놓쳤나(분석):
  - 검출기·X-CLIP은 후보 구간 프레임만 본다. 바탕색이 잠깐 바뀌고 선화만 남아 무채색·고대비·'스케치'처럼 보이면 점수가 오른다.
  - 연속성 지표(cont, 경계 프레임 에지 상관)는 **구도가 바뀌는 클로즈업·줌**에서 낮게 나와, 같은 장면인데도 '끊긴 삽입'으로 오인한다.
  - 문맥 유사도(ctx_sim)는 변별력이 거의 없었다(AUC 0.44).
- 이전에 같은 계열로 틀린 것: 앞뒤와 이어지는 동화(24304 f179–200 등), 옷이 화면을 가림, 먼지·섬광·집중선, 실루엣 연출만 빌린 장면(A 판정 31건, 3차 기준).
- **필요한 판정 원리:** 임팩트는 흐름을 끊고 **다른 그림 방식**으로 끼워 넣은 프레임이다. 앞뒤 장면과 같은 인물·같은 대상을 같은 그림체로 이어서 보여 주는 클로즈업·줌·카메라 이동·동화는, 바탕색이나 밝기가 잠깐 바뀌어도 아니다. 판정은 반드시 앞뒤 문맥(최소 ±12프레임, 가능하면 컷 전체)과 비교한다.

- 토큰·키를 출력하지 않는다.
- 영상 원본·contact sheet·남의 작화·사용자 예시 이미지는 GitHub(공개)에 올리지 않고 Drive에만 둔다.
- Drive 삭제는 사용자 승인 후에만 한다(이번 구간별 slow_quarter 삭제는 "중복 영상은 하나로 통합" 지시에 따른 것).
- 자동 승인 거부·로그인/위험 제어 차단은 우회하지 않는다.
- 사용자 대화와 문서는 한국어. 문서·aggregate 메타데이터 커밋은 상시 허가.
- 혼자 가능한 일은 자율 진행한다. 모델 훈련은 명시적 허가 전 금지(추론은 가능).
