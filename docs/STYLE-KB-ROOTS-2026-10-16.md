# 스타일 지식베이스 v0 — 뿌리 애니메이터 (2026-10-16)

- 근거: `yutaka_nakamura` 8클립, `nian41` 1클립. 클립별 기록은 `data/style_kb/observations.jsonl`에 있다.
- 방법: 자동 타이밍 측정 [실측] + Claude가 contact sheet를 보고 판독 [추론].
- 아래는 표본 9개에서 반복해서 보인 **스타일 규칙 후보**다. 확정 규칙이 아니며, 표본이 늘면 다시 확인한다.
- 이펙트·연출·배경을 먼저 정리했다.

## A. 타이밍

1. 액션·이펙트는 거의 1s(매 프레임 새 그림)다. 9클립 중 7개에서 새 그림 비율이 86% 이상이었다. 단, 측정에는 카메라 이동과 촬영 효과도 섞여 있다.
2. 기 모으기·긴장 구간은 2s, 또는 미세 떨림(boil)을 1s로 반복해 길게 끈다. 그다음 급가속한다.
3. 원경의 작은 인물은 2s·3s 비중이 높다(157400: 2s 123회, 3s 49회).
- **SFA 적용:** 보간을 끈 (24,24)를 기본으로 한다. 긴장 구간은 같은 도형을 미세하게 흔들어 매 프레임 저장한다. 원경 동작은 프레임을 반복 저장한다.

## B. 이펙트 형태 어휘

| 이펙트 | 형태 특징 | SFA 재료 |
|---|---|---|
| 파편(yutapon cubes) | 각진 다면체, 밝은 면·어두운 면 2톤 평면, 크기 분포가 아주 넓음, 회전 | 직선 3–4개 닫힌 도형 + FR 2면, 엔진이 회전·낙하 계산 |
| 연기 | 평면 셀 2톤, 바깥쪽이 날카로운 가시 | 톱니 경계 FR 2층 |
| 불꽃 | 밝은 외곽 + 어두운 core 2톤, 톱니 외곽 | FR 2층 + 외곽 glow |
| 번개 | 꺾인 폴리라인, 강한 glow, 어두운 바탕 위, 매 프레임 경로가 바뀜 | 연결 직선 + glow, 매 프레임 새 경로 |
| 불티 | 짧은 streak가 방사하거나 흩어짐, 이동 방향으로 늘어남 | 짧은 직선 + glow + 투명도 감쇠(수명 몇 프레임) |
| 광선·레이저 | 평행 다발, 발사 직전 수평 광선 한 줄 | 직선 다발 + glow |
| 폭발 | 화구 + 흰 방사 집중선, 넓은 화염 벽 | 중심 방사 삼각 FR 다발 + 원(채움) |

공통점은 **그라데이션 대신 2톤 평면 + 날카로운 외곽**이다. 앱의 채우기·선·glow와 잘 맞는다 [추론].

## C. 연출

1. **플래시 구두점:** 흰 전면 프레임, 검은 프레임, 흑백 반전 임팩트 프레임을 1–2장씩 넣는다. 한 클립에 여러 번 쓴다.
2. **전환:** 집중선이나 배경 문지르기만 남은 프레임, 모션블러형 스미어 1–2장으로 컷을 넘긴다.
3. **역광 실루엣:** 단색 방사광선 배경 + 어두운 인물 + 흰 rim 발광.
4. **단색 조명:** 장면 전체를 푸른색·붉은색 한 계열로 통일한다.
5. **카메라:** 크게 회전하는 배경 작화, 강한 원근의 벽면 훑기, 부감 원경과 근접을 급격히 교대한다.

**SFA 적용:** 플래시는 Frame.BackgroundColor로 1장 바꾸거나 전면 FR로 표현한다. 카메라는 앱에 기능이 없으므로 엔진이 모든 점에 회전·이동·확대 변환을 적용한다(화면 밖 좌표 허용). 단색 조명은 장면 팔레트로 일괄 지정한다.

## D. 캐릭터 (nian41 축, 표본 부족)

- 옷자락 끌림을 털 같은 톱니 실루엣 스미어로 표현한다.
- 맨손 격투의 연속 동작은 1s로 그린다.
- `nian41`은 `yutapon_cubes` 비율이 28%로, 이펙트에서도 같은 계보다. 캐릭터 움직임 규칙은 nian41 클립을 더 분석해야 한다.
