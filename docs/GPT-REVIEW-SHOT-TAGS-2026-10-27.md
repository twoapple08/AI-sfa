# 나카무라 이펙트 태깅 전체 재검토

2026-10-27 검토 완료. 테스트 pilot30 30개 + b01~b16 각15개 + b17 7개 = **277/277 시트**. 모든 원본 JPG와 기존 JSON을 시각 대조했다. 71개 시트를 보완했고206개 시트는 의미 내용을 유지했다. 공통 표준화 과정에서 구형 부가 필드와 동일 뜻의 기타 표기는 정리했다.

결과는 AI-sfa/gpt-tag/의 기존18개 JSONL을 같은 Drive 파일 ID로 갱신했다. 중복 파일을 만들지 않았다. 각 JSONL은 시트당 한 줄이다. 별도 gpt_review_log.jsonl에는277개 시트 각각의 수정/유지 판정과 확인 내용을 기록했다.

## 적용한 판정

- 실제 장면의 구도·배율·피사체가 불연속적으로 바뀔 때 컷으로 구분하고,처음/끝1~2장짜리 실제 컷도 포함했다. 연속 카메라 이동·가림·강조 삽입은 새 컷으로 세지 않았다.
- 임팩트프레임은 길이 제한 없이 그림체·색이 바뀐 강조 화면으로 유지했다.4장 이상 구간의 섬광·사선·방사선·고리·깜빡임 등 실제 내부 효과는 별도 대상으로 기술했다. 몸 동작만 있는 경우 내부 효과를 만들지 않았다.
- 작은 붉은 조각·주황 불티·짧은 전기 가지를 확인했다. 카메라 접근이나 광량 변화만으로 급팽창을 단정하지 않았고,이미 여러 조각인 상태만으로 분열을 추정하지 않았다. 응축 근거가 없는 유지 상태는 잔류/발생으로 정정했다.
- =/~ 표시는 보조로 사용했다. 큰 몸 그림이 반복되어도 작은 효과가 새로 바뀌면 효과 리듬을 구분했다. 인물·배경·무기 바탕색은 효과 대상에서 제외했다.

## 검증

- 18개 JSONL 구문·정확한 필드·277개 원본 시트 이름/중복·검토 기록277개 일치를 확인했다.
- 각 시트 cuts와segments 시작점 일치,0장부터 마지막 장까지 세그먼트/리듬의 누락·겹침 없음,단계 범위/순서·허용 어휘·홀드 길이를 확인했다.
- 원본277개 시트 머리글의 장 수를 OCR로 대조했다. 불일치는 아래 검증 파일의 오류 목록에 남기며,완료 조건은 오류0개다.
- 모든 caption_en의 nkmr_fx 접두사와60단어 이내 조건을 확인했다. 구형 부가 필드와예상치 않은 한자/가나 표기 없음도 확인했다.
- Drive 폴더를 다시 읽어18개 기존 파일 이름과바이트 크기가 로컬 검증본과 일치함을 확인했다. SHA-256은 로컬 산출물의 식별값이다. 서버 내용의 해시를 별도로 읽어 비교한 것은 아니다.

판정은 제공된 접촉 시트에서 보이는 범위에 따른다. 가림·압축·밝기·원근 때문에 확인할 수 없는 물성/발생원/급팽창은 불명으로 남겼다. 원본 동영상 재생을 통한 추가 검증은 수행하지 않았다.
