# 정정: 얇은 선으로 다시 보기 (2026-10-28 사용자 권고)
- 원인: `tools/sfa_render.py`는 선·글로우 굵기를 1920px 화면 기준 고정 픽셀로 그린다 → 400px 시트에서 선이 약 4.8배 두꺼워 뭉개졌다. `PARAMS['thick_mul']`(= 그림 폭/1920) 옵션을 넣었다(기본 1.0 = 앱 대조용 그대로). 새 시트: scratch `drv/fxthin*.jpg`(이펙트 62), `wpn/thin*.jpg`(무기·도구 87), 도구 `exo/sheet_list.py`.
- 위의 눈 판정 중 고칠 것:
  - **무기**: 검은 덩어리가 아니라 날·홈·장식을 가는 윤곽선으로 그린 정교한 설계(속이 빈 선화). 품질이 생각보다 높다.
  - **바람·검기·선이펙·속보이펙트**: '굵은 직선 띠'가 아니라 **지그재그로 꺾이는 가는 선 하나**가 띠를 채운다(지그재그 해칭). 앱 화면(굵은 선)에서는 이 지그재그가 겹쳐 면처럼 보인다 → 면 채우기 대신 쓰는 기법.
  - **드림 이펙**: 가는 선 수백 개 해칭으로 검은 덩어리를 만든 것. **충격파**: 겹친 호 여러 겹. **카키 이펙트2**: 빨강·검정 두 겹 가시 십자.
  - asdf: 흰 조각 테두리를 가는 해칭으로 채운 소용돌이 + 방사 빛줄기.
- 교훈: 형태·구성 판정은 얇은 선(thick_mul) 시트로, 앱에서의 실제 겉모습은 1920 기준 굵기로 둘 다 본다.
