할 일
1. 사용자 정정(수집 SFA는 주 재료가 아니고, 이펙트·배경·인물 움직임 모두 실제 애니를 SFA로 변환한 것에서 배움. 인물은 스틱맨, 캐릭터 디자인은 나중에 입힘)을 전제로, 세 층 구조(G1 연출 계획 / G2 내용 / G3 SFA 조립)와 실제 애니 → SFA 세 갈래 변환(인물→포즈→스틱맨, 이펙트·배경→1단계 변환기)이 맞는지, 더 나은 분할이나 통짜 방식의 근거가 있는지. 반대하면 근거(논문·실측·계산)로.
2. 실제 애니 → SFA 변환의 영역 차이(손그림 vs SFA 렌더) 대책 중 무엇이 가장 싸고 효과적인지, 그리고 그것을 1단계 결과 전에 미리 잴 방법.
3. 장 사이 ID 잇기(추적) 방법 — 변환기가 장마다 따로 쓴 SFA에서 오브젝트 짝을 잇는 가장 단순한 방법과 실패 사례.
4. G2(태그 → 2D 관절 궤적·이펙트 과정)의 모델 크기·자료량 추정, 그리고 캐릭터 디자인을 뼈대에 입히는(리깅) 가장 단순한 방법. 비슷한 공개 연구(2D 동작 생성, text-to-motion을 2D로 쓴 사례)가 있으면 이름·핵심만.
5. 평가 지표 제안(자동 + 사용자 눈), 특히 '동작이 자연스러운가'를 숫자로.
6. 순서(P0–P4)와 첫 목표(P2 스틱맨 동작) 의견.
