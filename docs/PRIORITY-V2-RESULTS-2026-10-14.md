# v2 합본 세 개 — 왕복·실제 출력 비교

## 결론

01/02/03의 사용자 실행 결과를 받았다. 가장 중요한 새 근거는 **생성 SFA의 지정값이 가져오기/저장 후 모두 그대로 남지는 않는다**는 점이다. 뒤집은 DrawOrder 상대순서와 ObjectScale2가 바뀌었다. 해당 구간을 렌더러 기능 실패나 기능 자체 무효로 판정하지 않는다.

단순 구멍은 윤곽 방향을 반대로 해도 열렸고, 같은ID 도형의 이동/알파 중간값, 새ID 교체의 중간 누락, 채우기 생성/삭제의 비대칭 유지, 여러 글로우 변수의 효과를 실제 표본에서 확인했다. 모든Contour/부분곡선/TweenLink/물리단위/최종합성식의 완전 명세는 아직 아니다.

## ② 글로우 강도·범위·합성

선좌표/ThicknessScale은고정됐고기준은구간3(2–3초)이다. 전체굵기100%표본.구간11은ObjectScale가왕복에서1로바뀌어스케일효과시험에서제외한다.

- ObjectScale를2로주었을때같은출력이된것은입력값이1로바뀐상태와부합한다. “ObjectScale는표시영향0”이라고결론내리지않는다.
