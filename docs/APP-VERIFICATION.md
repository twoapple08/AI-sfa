# 실제 앱 검증 기록

## 현재 상태 — 2026-10-14

대상: Stick Fighter 51.0.0. v1 실제 앱 결과는 아직 제공되지 않았다. 자동 검사 18개 및 합본 구조 검사 통과는 앱 호환성/시각 검증으로 기록하지 않는다.

| 실험 ID | 목적 | 설정 (트위닝 FPS, 재생 FPS) | 기대 출력 | 실제 결과 |
|---|---|---|---|---|
| APP-V1-BASELINE | 16구간 저장 상태의 수용·표시·출력 | (24,24) | 24FPS, 768프레임, 32초 | 대기 |

| 구간 | 확인할 상태 | 판정 |
|---|---|---|
| 01–05 | 이동/회전/늘리기/반전/크기 좌표 변화 | 모두 대기. 편집 버튼 연산은 별도 |
| 06–08 | 선 색/알파/개별 굵기 | 모두 대기 |
| 09–12 | 글로우/곡선/채우기 색/알파 | 모두 대기 |
| 13–16 | 레이어 표시/순서/배경색/생성·삭제 | 모두 대기 |

## 결과를 받으면 기록할 항목

1. 앱 버전, 입력 파일/체크섬, UI 설정, 반환 영상 파일명.
2. 실측 FPS/프레임 수/길이/해상도. 기대값과 구분한다.
3. 16구간별 일치/불일치/판정 불가와 근거 시점·프레임. 재생 관찰과 정지 프레임 검사를 구분한다.
4. 실패 구간만 개별 파일로 좁힌다. 가져오기 실패/편집 화면 차이/출력 차이 중 관찰한 경로만 적는다.
5. 원인 확인 전에는 앱 또는 생성기 버그라고 단정하지 않는다. 성공 구간도 편집 UI 연산·보간·저장 왕복은 자동 완료 처리하지 않는다.

새 앱 결과 없이 manifest의 app_verified를 true로 바꾸지 않는다.
