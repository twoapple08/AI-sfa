# SFA 곡선 최적화 원칙 — 점 하나하나 따라가지 말고 곡선으로 형태를 만든다 (2026-10-25)

사용자 지시: "굳이 점 하나하나 따라갈 필요 없이 곡선으로 형태를 만들어서 최적화하는 방법을 기록해 놔."
근거: 같은 날 광사 그림(생성 인물)을 SFA로 옮기며 사용자 시연·지적을 받은 것. 앞으로 모든 그림→SFA 변환과 생성기(이펙트 포함)가 따른다.

## 원칙 (사용자 시연에서)
1. **곡선 하나가 길게 휘며 덮는다.** 2차 곡선(TypeId 3)은 조절점 하나로 구부림을 정한다. 어깨선 하나 = 곡선 2개(사용자 시연). 픽셀 윤곽을 따라 7px마다 곡선을 끊지 않는다.
2. **선은 '곡선 + 굵기'의 선 객체로 그린다.** 선을 채우기 면으로 바꾸면 양쪽 테두리마다 점이 생겨 두 배 이상이 된다. 끝이 빠지는 붓선이 꼭 필요할 때만 '왼쪽 변·오른쪽 변 긴 곡선 몇 개 + 채우기'(사용자 시연: 곡선 4개)로 닫는다.
3. **채색 면은 성긴 다각형으로 선 아래에 깐다.** 면 가장자리는 위의 선화가 덮으므로 정확할 필요가 없다(블로그 예시: 점 몇 개짜리 피부 면). 면을 선에 맞춰 촘촘히 따지 않는다.
4. **형태를 먼저 정하고 곡선을 놓는다.** 머리카락 한 가닥·눈동자 원·속눈썹 띠처럼 '그리는 사람이 긋는 단위'로 곡선을 둔다. 원은 곡선 몇 개로 닫고, 가닥은 시작~끝을 곡선 1–3개로.
5. **굵기·끝으로 표현한다.** 굵기 바리에이션(진한 외곽 굵게, 결은 가늘게), 끝은 가늘게. 앱 굵기 하한은 기본의 10%(ThicknessScale 0.1). 기본 굵기 배율 0.6(사용자 선택).
6. **일반 그림처럼 레이어를 나눈다.** 머리카락·얼굴·눈·눈동자·속눈썹·입·소품·옷·배경(사용자 지시). SFA LayerDef + AO LayerId.

## 남은 문제 (2026-10-25 마지막 앱 화면)
- 선 객체 판도 점이 아직 많다. 이유: 가운데 줄기를 갈림길마다 자르고 짧은 조각을 각자 맞춤 → 머리카락 끝·눈가에 짧은 곡선이 몰림. 곡선마다 점 3개를 따로 둔다(이웃 곡선과 끝점 공유 안 함).
- 눈: 작은 원·속눈썹이 다듬기·오차 설정(긴 선 기준)에 찌그러짐.

## 다음에 할 방법 (아직 안 함)
1. **선 단위 맞춤:** 한 가닥(이어 붙인 줄기) 전체를 '곡선 최소 개수'로 맞춘다 — 허용 오차 안에서 곡선 수를 줄이는 최적화(분할점을 오차 최대점이 아니라 전체 곡선 수 최소로). 짧은 잔가지(길이 < 기준)는 버린다.
2. **끝점 공유:** 한 가닥의 이어지는 곡선은 끝점을 같은 위치로 두고 AC(ConnPtId)로 연결해 앱에서 한 선처럼 움직이게.
3. **부위별 오차:** 눈·입처럼 작은 부위는 오차·다듬기를 작게, 머리카락·옷은 크게(부위 지도 `tools/part_masks.py` 사용).
4. **원·타원 맞춤:** 눈동자·선글라스 테처럼 닫힌 둥근 선은 원/타원으로 맞춰 곡선 4개로 닫는다.
5. **채색:** 성긴 다각형 면을 선 아래 레이어로(원칙 3).
