# GPT 프롬프트 — 학습 조각 인물 태그 (2026-10-28)

목적: 나카무라 이펙트 LoRA가 프롬프트에 없는 인물을 그리는 문제(학습 캡션에 인물 낱말이 거의 없어 `nkmr_fx`가 인물을 흡수) → 사용자 결정 3번: 효과 없음 23조각 제거 + 인물이 보이는 조각 캡션에 인물 문장 추가.
**로봇(10-28 사용자):** 나카무라는 로봇도 많이 그렸다 → 로봇은 줄일 대상이 아니라 프롬프트로 부를 수 있게 따로 이름 붙여 배울 대상. 로봇 전신(robot)과 부분 클로즈업(robot_part)을 나누고, 이펙트와 맞물림(fx_link)을 따로 표시한다. 다음 평가 프롬프트에 로봇 장면을 넣는다.
GPT는 정해진 낱말로 태그만, Claude가 문장으로 바꿔 붙이고 묶음마다 표본 대조. 대상 459조각 = 시트 01–13의 437 + 시트 14의 22(10-28 정정: 처음 목록 45는 캡션에 "No visible effects"가 들어 있기만 해도 뺐다 → 조각 전체가 효과 없음인 23만 제외, 일부 구간에 효과가 있는 22(로봇 s0195·s0242·s0320 포함)를 되살림).

붙일 파일(10-28 사용자: GPT 새 세션에서 진행): Drive `AI-sfa/02_분석자료/WanLoRA_인물태그/person_sheets_all_14p.pdf` 하나(14쪽, 쪽마다 위에 PAGE n/14, 1–12쪽 36조각·13쪽 5조각·14쪽 22조각). 원 시트 scratch `pdet/gpt`.
답이 길어 잘리지 않도록 한 번에 4쪽씩(1–4, 5–8, 9–12, 13–14) 받는다.

## 복붙용 프롬프트(새 세션, PDF 첨부)

```
[작업 설명 — 이 대화만으로 이해할 수 있게 적음]
나는 애니메이터 나카무라 유타카의 이펙트(폭발·번개·연기·섬광) 장면으로 영상 생성 AI(LoRA)를 학습시키고 있다.
학습 자료는 짧은 영상 조각 459개이고, 조각마다 이펙트만 설명한 영어 캡션이 있다.
문제: 캡션에 인물이 전혀 언급되지 않아, AI가 '이 화풍 = 인물이 나옴'으로 배워 프롬프트에 없는 인물을 그린다.
해결: 화면에 보이는 인물·로봇을 캡션에 따로 표시해, 인물이 '부를 때만 나오는 것'이 되게 한다.
로봇·메카도 이 작가가 많이 그린 중요한 소재라 지우지 않고 따로 표시한다.
네 일은 첨부 PDF를 보고 조각마다 정해진 낱말로 태그를 다는 것뿐이다(문장은 내가 만든다). 이펙트 자체는 판정하지 않는다.

[첨부 PDF]
14쪽. 쪽 맨 위에 PAGE n/14. 한 쪽에 칸 36개(3열 × 12줄). 13쪽은 5개, 14쪽은 22개(총 459개).
칸마다 위 흰 띠에 조각 번호(예: s0002_c0), 아래 3장 = 그 조각의 처음·가운데·끝 장면.

[출력 형식] 조각마다 JSON 한 줄. 인물이 없어도 반드시 한 줄(빠짐 확인용).
{"clip":"s0002_c0","person":"large","kind":"face","frames":"all","fx_link":"none","unsure":false}

person (화면에서 가장 큰 인물 기준, 3장 중 가장 크게 보이는 장으로):
 none = 인물·생물·로봇 없음
 small = 화면 높이의 1/4 미만(멀리 작은 인물)
 medium = 그 사이
 large = 화면 높이의 절반 이상이거나 몸 일부 근접(얼굴·주먹 클로즈업)
kind (가장 큰 것 하나):
 face = 얼굴·머리 위주   fist_arm = 주먹·손·팔 위주   body = 상반신·전신 인물
 several = 비슷한 크기 인물 둘 이상   silhouette = 검은 실루엣·윤곽만
 creature = 사람 아닌 생물·괴물
 robot = 로봇·메카·기계 거인의 전신·상반신   robot_part = 로봇 주먹·팔·머리·장갑판 클로즈업
 (로봇도 '인물'로 센다. 크기 기준 같음. person이 none이면 kind는 "none")
fx_link (인물·로봇과 이펙트의 관계, 가장 뚜렷한 것 하나):
 none = 따로 있음·관계 없음   emits = 인물·로봇이 이펙트를 냄(빔·불·번개를 쏨, 몸에서 빛·오라)
 hit = 인물·로봇이 이펙트에 맞음·휩쓸림   strike = 주먹·무기 타격과 함께 이펙트(임팩트)
 (person이 none이면 "none")
frames: all = 3장 모두 보임, some = 1–2장에만
unsure: 이펙트에 가려 인물인지 애매하면 true

[규칙]
- 이펙트(연기·불·번개·빛)가 사람 모양처럼 보여도 실제 인물이 아니면 none.
- 무기·건물·탈것(전투기·전함)만 있으면 none. 사람 모양 로봇·메카는 robot.
- 조각 번호는 칸 위 글자를 그대로 옮긴다. 추측해 만들지 않는다.
- 답이 잘리지 않게 한 번에 4쪽씩만: 이번 답은 PAGE 1–4. 쪽 순서·칸 순서(왼→오, 위→아래)대로.
- 출력은 코드 블록 하나에 JSONL만, 설명 문장 없이. 코드 블록 다음 줄에: "PAGE 1–4, n조각".
- 내가 "계속"이라고 하면 다음 4쪽(5–8, 9–12, 13–14) 순서로 같은 형식.
```
