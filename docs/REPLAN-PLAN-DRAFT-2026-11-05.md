## 0. 큰 구조(최종 모습)

```
입력: 캐릭터 시트 · 능력 글 · 무기 파일 · 장면 내용(글/태그/스토리보드/음악/앞 장면) · 보강 정도 · 부정 프롬프트
   │
   ▼
[생성기] 거대 사전학습 모델 + SFA용 어휘(LoRA 미세조정)
   │  만드는 것 = '중간 표현'(점 하나하나가 아님)
   │   - 인물: 장마다 관절 12개 + 가시성(스미어로 대체 등)
   │   - 무기: 장마다 손목 대비 위치·각도
   │   - 이펙트: 형태 사전 번호 + 매개변수(나중)
   │   - 카메라: 장마다 위치·확대
   ▼
[스타일 보정] 잴 수 있는 스타일 특징으로 타이밍 정리(유지 리듬·타격 멈춤 등)
   ▼
[컴파일러] 중간 표현 + 캐릭터 시트 모양 + 무기 파일 + 3D 배경 → .sfa (24,24)
```

핵심 판단: **생성기는 점 좌표를 직접 쓰지 않는다.** 스틱맨 모양은 컴파일러가 캐릭터 시트에서 그대로 가져온다(기존 `stickman_clip.person_aos`·고정 뼈대 재사용). 그래서 1단계 생성기가 배울 것은 "글 → 관절 움직임 + 타이밍"뿐이다 — 기존 변환기(장마다 SFA 전체 토큰)보다 훨씬 짧고 쉽다.

## 1. 단계

각 단계는 **끝 기준**을 미리 정하고, 그 기준에 닿으면 다음으로 넘어간다. 사용자 확인은 단계마다 한 번(◆).

### 단계 1 — 기반 정리 (GPU 없음)
- 중간 표현 형식 v1: 인물 관절 트랙(장마다 12관절·가시성·'스미어로 대체' 표시), 카메라, 장면 태그·시간 구간.
- 컴파일러 v1: 중간 표현 + 캐릭터 시트 → 스틱맨 .sfa. 캐릭터 시트 읽기(7칸·기준선·레이어)로 색·비율·머리·액세서리를 가져온다.
- 끝 기준: 기존 스틱맨 자료 한 구간을 중간 표현으로 바꿨다가 다시 .sfa로 만들었을 때 원래와 같게 나오고(자동 대조), 사용자 캐릭터 시트 모양이 입혀진다. 앱 불변 조건 검사 통과.
- ◆ 사용자: 사용자 캐릭터가 입혀진 스틱맨 .sfa를 앱에서 한 번 확인.

### 단계 2 — 움직임 자료 만들기 (대부분 CPU, 추출에 GPU 일부)
- 애니메이터 영상에서 액션 구간을 골라 스틱맨 관절 트랙으로(기존 추출 기술 v1·RTMW 결과 재사용, 새 구간은 같은 절차). 스미어 장의 부위는 '스미어로 대체' 표시.
- 태그·시간 구간 설명 붙이기: GPT가 대량 태깅(동작 종류·구도·카메라·리듬), Claude가 묶음마다 일부 대조 검수.
- 스타일 특징 측정: 유지 리듬, 예비 동작 길이, 타격 멈춤, 속도 곡선, 카메라 흔들림 → 분포 표.
- 끝 기준(초안 수치, 확정 필요): 액션 구간 N개(예: 300개, 합계 20분 안팎), 구간마다 관절 트랙 + 태그 + 시간 구간 설명, 품질 검사(관절 튐·빠짐 비율) 통과.
- ◆ 사용자: 무작위 표본 10구간 시트(원본 옆 스틱맨 + 태그)로 품질 판정.

### 단계 3 — 거대 모델 적합 시험 (Kaggle, 짧게)
- 후보 모델(예: Qwen2.5-VL 3B / 7B)을 4비트 + LoRA로 T4×2에 올려 메모리·학습 속도·생성 속도 측정.
- 끝 기준: 학습이 돈다(메모리 부족 없음), 3초(72장) 생성 시간 측정값 확보. 안 되면 더 작은 모델로 바꾸는 결정을 기록.

### 단계 4 — 학습 1단계: 정지 포즈 (Kaggle)
- "글 → 한 장의 포즈(관절 12개)". 단계 2 자료의 장들 + 태그.
- 끝 기준: 보관한 시험 글 묶음에서 포즈가 글 내용과 맞는 비율(눈 판정 표본) 기준 이상, 관절 구조가 깨진 출력 0.

### 단계 5 — 학습 2단계: 움직임 (Kaggle)
- "글·태그·시간 구간 → 관절 트랙(24장/초)". 스타일 세 겹 적용(애니메이터 자료 / 내부 표시 / 스타일 특징 학습 목표).
- 생성 후 스타일 보정(타이밍 정리).
- 끝 기준: ① 스타일 특징이 애니메이터 자료 분포 범위 안 ② 원본 구간을 거의 그대로 베낀 출력 비율이 기준 이하(외우기 검사) ③ 기준 글 묶음 출력이 앱에서 열리고 편집됨.

### 단계 6 — 첫 완성판
- 입력 = 캐릭터 시트 + 글(+태그·시간 구간·부정 프롬프트·보강 정도) → 출력 = 스틱맨 액션 .sfa (24,24).
- ◆ 사용자: 기준 글 묶음(예: 걷기→달리기, 날아차기, 연타 후 멈춤 등 10개) 결과를 보고 "이 느낌이 맞다/아니다" 판정. 이 판정이 이후 개선의 기준.
