{"shot":"s0015",
 "cuts":[0,5,8,...],                  // 각 컷이 시작하는 장 번호(0 포함). 같은 장면에서 카메라만 움직이면 컷 아님. 섬광 장 몇 장 뒤 같은 장면이 이어지면 컷 아님.

   {"frames":[0,4],
    "camera":["팬"],                   // 고정|팬|줌인|줌아웃|흔들림|회전|불명

    "targets":[                        // 이펙트 대상마다 하나(인물·배경은 "가림" 판단에만 쓰고 대상으로 넣지 않음)
