# 자체 태그 규칙 v1 (2026-10-17, 사용자 지시)

Sakugabooru 태그는 사람이 달아서 완벽하지 않다. 영상에 보이는데 태그가 없으면 **우리 쪽 태그 보정 파일**에 추가한다. Sakugabooru 사이트의 태그는 고치지 않는다(외부 사이트 편집은 하지 않음).

- 보정 파일: `data/style_kb/tag_overrides.csv` — `post_id, tag, action, frames, basis, grade, status, by, date`
  - `action`: add(추가) / remove(잘못된 태그 표시)
  - `frames`: 근거 프레임 번호(0부터, 원본 프레임 기준). 클립 전체에 해당하면 `all`
  - `grade`: [실측]·[추론]·[사용자 확인]
  - `status`: confirmed(사용자 예시 또는 연속 프레임 확인) / candidate(시트 판독만)
- 학습·통계는 `Sakugabooru 태그 + add − remove` 결과로 계산한다.

## 새 태그 2개 — 임팩트 프레임 구분 (최중요)

사용자 지시: impact_frames는 **연필 선화 느낌만 학습**, 디지털 단색은 제외. 기존 `impact_frames` 태그만으로는 둘을 못 가르므로 두 태그를 새로 만든다. 판정 단위는 **프레임 구간**이다(한 클립에 둘이 섞일 수 있다).

| 태그 | 뜻 | 보이는 특징 | 학습 |
|---|---|---|---|
| `impact_frames_pencil` | 연필(4B)로 직접 그린 선화 임팩트 | 흑연 선의 결이 보임, 방사형 해칭을 겹쳐 회색 농도를 만듦(선이 빽빽할수록 진함), 종이의 흰 바탕, 끝이 갈라지고 거친 가장자리, 손으로 그은 불규칙한 선 굵기 | **학습함** |
| `impact_frames_digital` | 디지털 단색 임팩트 | 검정·흰·단색으로 꽉 찬 평면, 매끈하고 날카로운 벡터 가장자리, 선 결·해칭 없음, 면 안의 농도가 균일, 전면 흰색·검정 깜박임 | 학습 안 함 |

**기준 예시 (사용자 제공, 2026-10-17)**
- 디지털: Sakugabooru 302394(My Hero Academia: Vigilantes #25) **0–13프레임** — 흰 가시 섬광 면(0·2·3), 검정 전면(1·5·13), 흰 전면(8·11). [사용자 확인 + 실측 프레임]
- 연필: 사용자가 준 원화 사진 5장(흰 종이 위 흑연 방사 해칭, 중심 흰 섬광, 인물 실루엣을 흰 여백으로 남김, 십자 섬광선). 원본 이미지는 남의 작화라 GitHub에 올리지 않고 Drive `03_스타일지식베이스/impact_reference/`에만 둔다.

**헷갈리는 경우**
- 거칠지만 붓·잉크 느낌(먹 번짐, 굵은 검정 면) → 연필로 단정하지 않고 candidate로 둔다.
- 연필 선화 위에 디지털 색면을 겹친 프레임 → 해당 프레임은 `impact_frames_digital`도 함께 단다. 학습은 연필 선 구조만 쓴다.
- 연필 결과 디지털 블러·노이즈가 한 프레임에 섞여 있으면 → 비중이 큰 쪽으로 분류하고 basis에 '섞임(연필 우세)'처럼 적는다. 근거: 사용자 판정 290900 157(2026-10-17, "섞인 건데 연필 비중이 더 커서 연필"). 흐린 가로 문지름 결은 AI가 블러로 잘못 읽기 쉬우므로, 한 AI만 판단하면 candidate로 두고 다른 AI나 사용자 확인을 받는다.
- 1프레임짜리 임팩트는 균등 표본 시트에서 빠질 수 있다. 시트에서 안 보였다고 부재로 단정하지 않고, 연속 프레임(`tools/sakuga_timing.py --run`)으로 확인한다.

## 기존 태그 보정 원칙 (예: yutapon_cubes)

- 영상에 각진 다면체 파편(밝은 면·어두운 면 2톤, 회전하며 비산)이 보이는데 `yutapon_cubes`가 없으면 add.
- 같은 방식으로 `impact_frames`, `debris`, `smears`, `explosions`, `smoke` 등 일반 태그도 보이는데 없으면 add.
- 근거 프레임 번호를 반드시 적는다. 시트 판독만이면 candidate.
- 참고: 사용자가 예로 든 302394에는 `yutapon_cubes` 태그가 이미 있었다(2026-10-17 API 확인). 사용자 확인: 예시를 잘못 가져온 것이며 **지시는 유지**한다.

## 추가 태그·처리 (2026-10-18 사용자 지시)

- `pencil_texture_reference`: 영상 임팩트가 아닌 정지 일러스트·원화·플립북에서 4B 연필(흑연) 질감이 보이는 자료. **연필 질감 참고 전용**이다. impact_frames_pencil 통계에는 넣지 않는다. 사용자 지정으로 17건을 표시했다(11b 10, 11a 7).
- 셀 시대 단색 섬광: 1990년대 셀 작업에서 화면 전체를 한 장의 옅은 단색으로 덮는 1프레임 섬광(예: 313715 122·165·201, Drive `03_스타일지식베이스/impact_reference/cel_flash_313715.jpg`). **사용자 결정(2026-10-18): 셀 시대는 빛을 실제로 비추는 방식이라 원하는 느낌과 다르므로 학습에서 제외한다.** 태그는 `impact_frames_cel_light`(학습 제외)로 한다. 연도표 era_year 1999 이하의 디지털 분류 행 40개를 이 태그로 바꿨다. 2000–2002년은 셀·디지털 전환기라 작품마다 확인이 필요하다.
- 폐기: 1475(원화 크레딧이 佐藤雅弘로 보임), 430(다른 작품 그림으로 보임). 사용자 지시(2026-10-18)로 학습·통계에서 제외했다. catalog status=discarded로 바꾸고 Drive 분석자료 폴더를 지웠다. 원본은 GPT의 ZIP(`yutaka_tagged_reference_001.zip`) 안에 남아 있다.

- **사용자 관찰(2026-10-18, 확인 전 가설):** 나카무라가 디지털 임팩트를 쓴 것은 비교적 최근이고, 몇 년 지난 작품은 연필선을 썼다. 따라서 디지털 시대 초·중기 작품에서 "디지털"로 분류한 구간이 실제로는 연필일 수 있다. 재검토 목록: `data/style_kb/digital_impact_before_302394_2026-10-18.csv`.

## 임팩트 프레임의 정의 (2026-10-18 사용자)

**임팩트 프레임 = 흑백(또는 반전)이 짧게 번갈아 바뀌며 시청자에게 번쩍이는 것.** 흑백 처리가 번갈아 바뀌지 않고 이어지기만 하면 임팩트 프레임이 아니라 **연출**이다(태그 `bw_direction`, 실루엣 액션은 `bw_silhouette_direction`). 컬러 집중선·발광 폭발처럼 흑백 번쩍임이 아닌 것도 임팩트 프레임이 아니다.

- 측정 보조 [실측]: 구간 각 프레임의 밝은 화소 비율로 극성(W/B)을 매기고, 극성 전환 횟수와 프레임 간 평균 밝기 차를 본다. 예: 302394 0–13 = 전환 4회, 평균 차 116(임팩트). 271644 1374–1387·203327 550–566/577–593·239055 216–225 = 전환 0회(흑백 연출로 재분류). 전환 1–2회 구간 5개는 구간 재분할이 필요하다.
- 309107(Marriagetoxin #12): 191–224 흰 바탕 검은 실루엣 = 연출, 189–190 컬러 방사 폭발·233–235 흰 전면 = 임팩트 아님. 따라서 302394 이후 작품에는 임팩트 프레임이 없다.
- 9프레임 이상 구간만 이번에 측정했다. 짧은 구간도 같은 기준으로 다시 봐야 한다(진행 예정).
