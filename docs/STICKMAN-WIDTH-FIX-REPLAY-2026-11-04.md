## Claude 재현 방식

스킬은 설명서다. 같은 구간을 같은 결과로 만들려면 지정 코드/프로필 지문과 보존한 입력·표시 키를 불러와야 한다. 영상만 주고 처음부터 눈 판정을 다시 하면 같은 출력이라고 보장할 수 없다. 기존 구간은 고정 자료를 이용한 재현 경로를 우선 사용한다.

`python tools/stickman_replay.py 재현묶음.zip --destination 새폴더`를 사용한다. 이 도구는 코드/프로필/입력SHA를 대조하고,묶음을 새 폴더에 풀고,기존 결과를 제거한 다음생성기를 실행해 새 출력의 XML SHA를 기대값과 대조한다. ZIP 저장시간 차이는 포즈/XML 차이와 구분한다. 실제 독립 폴더 재현 결과와 구현SHA/묶음 위치는 아래 후속 기록을 따른다.

원본/전체RTMW/가중치/토큰은 묶음에 넣지 않는다. 최종 생성은 보존한중간입력/표시키를 사용하므로 피팅을 반복하지 않는다. 원본 비교 영상을 다시 만들 때만 기존 Drive 원본을 별도로 복원한다. 캐시는 `ai-sfa-private/no_digits_20261104/`.


## 수동 보정·추론도 고정된 입력으로 실행

사용자가 수동 보정과 추론도 동일하게 작동할 수 있는지 질문했다. 기존 구간의 기준점/포즈 보완·가림/표시·폭 척도를 묶음의 필수 입력으로 고정하고,보간/폭 계산은 생성기가 실행한다. Claude는 이 구간을 재현할 때 눈 판정을 다시 하지 않는다. `locked_decisions` 지문이 다르면 입력 전체SHA를 갱신했어도 기존 결정 기록과 불일치로 거부한다. 결과에는 검증한 결정 입력 수와 통합지문을 남긴다.

이는 **보존한 중간 관측·보정 입력부터 최종SFA까지의 재현**이다. 원본만 주고 새로운 수동 판단을 자동으로 다시 생성해도 같다는 뜻이 아니다. 새 영상의 눈 판정까지 스킬 문장만으로 완전히 같게 만드는 것은 미완료다. 측정 가능한 조건은 코드화하고,판정이 필요한 경우 확정한 값을 필수 입력으로 기록한다.
