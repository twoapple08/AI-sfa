## 1. 현재 상태 요약

**학습 방식:** 분석형 학습. 영상을 보고 기법을 구조화한 스타일 지식베이스를 만들고, 생성기가 이를 참고한다. 목표는 Stick Fighter 앱 기능(선·원·곡선·채우기 FR·glow·투명도·색·선 굵기·레이어·프레임 배경색)만으로 두 뿌리의 스타일을 녹인 AI 고유 스타일이다. 개인 사용. FPS 표기는 (트위닝 fps, 재생 fps). 사쿠가식 작화는 보간을 끈 (24,24)를 기본으로 본다.

**분석량:** 관찰 기록 64건(yutaka_nakamura 28, nian41 36). 방법은 자동 타이밍 측정 [실측] + contact sheet 시각 판독 [추론].

**yutaka_nakamura 규칙 후보 (요지)**
- 이펙트는 그라데이션 대신 2톤·3톤 평면 + 날카로운 외곽(톱니·가시)이다.
- 이펙트 어휘: 각진 다면체 파편(yutapon cubes, 밝은 면·어두운 면 2톤), 셀 2톤 연기, 밝은 외곽 + 어두운 core 불꽃, 꺾인 번개 + glow, 방향으로 늘어난 불티 streak, 동심원 충격 링, 얼음 결정 3톤, 용암 균열, 다색 렌즈플레어 등.

- 타이밍: 액션·이펙트 대부분 1s(화면 전체 기준). 반응 연기·이펙트가 자라는 컷은 2s·4s hold.

## 2. Gemini가 맡을 일

### 작업 A — 후보 6명 평가 (주 작업)

사용자가 승낙/반려를 정할 수 있게 근거를 만든다.

1. 작가마다 Sakugabooru 태그 페이지(`https://www.sakugabooru.com/post?tags=<작가명>`)에서 `presumed`가 아니고 단독 표기인 클립을 3개 이상 고른다. 위 대표 클립은 이미 봤으니 다른 클립을 우선한다.
2. 각 작가를 두 축으로 평가한다.
   - yutaka_nakamura 축: 이펙트 형태(2톤 평면·날카로운 외곽·각진 파편), 연출(플래시·제한 팔레트).
   - nian41 축: **사람 몸 움직임만**(2s 바탕 + 순간 1s, 예비→순간→후속, 스미어, 원근 과장). 표정·머리카락은 평가하지 않는다.
3. Stick Fighter로 옮기기 쉬운 정도: 선·원·곡선·평면 채우기·glow로 재현 가능한지. 촬영 발광·그라데이션·블러에 기대는 표현은 옮기기 어렵다.
4. 출력: 작가별로 본 클립 링크, 두 축 평가, 옮기기 쉬운 정도, **승낙 추천 / 보류 / 반려 추천** 중 하나와 이유. 근거가 영상 직접 확인인지 추론인지 [영상 직접 확인] / [추론]으로 표시한다.
