## 복붙용 프롬프트

검토 고마워. 지적 20개를 코드와 대조해서 고쳤어. 수정본 3개를 첨부해. 아래는 항목별 처리와 내 의견이야. **반영이 맞게 됐는지, 그리고 내가 동의하지 않은 항목에 대한 반론이 있는지** 다시 봐 줘. 근거가 맞으면 인정하고, 아니면 근거로 반박해 줘.

### 고친 것(인정)
| 번호 | 처리 |
|---|---|
| 1 방향 마스크 | 방향·선 속성·종류 손실은 정확한 1px 가운데선 픽셀에서만(`loss_fn`의 `on_line`). 3px 띠는 가운데선 존재 손실에만 쓴다. |
| 2 검증 누수 | 원본 SFA 이름의 md5 해시로 학습/검증을 정한다(`is_val`, 약 5%). 해상도·반복·생성 실패와 무관하게 같은 쪽. 단계마다 학습·검증 원본 교집합이 비었는지 assert. |
| 3 반투명 가림 | 알파 < 128인 선·면은 번호판에서 뒤를 가리지 않는다(`OPAQUE`). 투명 면은 별도 번호판 `tbuf`, 맨 위 = max(buf, tbuf). 뒤의 선 가운데선은 정답에 남는다. |
| 6 파일 덮어쓰기 | 파일 이름에 seed. 임시 파일에 쓴 뒤 `os.replace`. |
| 8 희소 점 | 선 끝·관절은 CenterNet식 focal 손실, 정답 점(≥0.9) 개수로 나눔. |
| 10 글로우 | 글로우 세기는 모든 선 픽셀에서(없으면 0), 반경·두께·색은 글로우가 있는 선에서만. |
| 11 배경·채움 | 정답에 '실제 자리' 채널 추가(아래 빈칸 0). 배경색 손실은 실제 자리 중 아무것도 그려지지 않은 픽셀에서만. |
| 12 시험용 제외 | 시작할 때 학습 352개·시험용 37개를 세고, 겹치지 않는지 assert. `_done.json`에 시험용 목록 기록. |
| 13 입출력 | 파일을 한 번 풀어 그 안에서 8조각(이전 4조각 × 같은 파일 반복 접근 제거), DataLoader 묶음 2 × 8 = 16조각. |
| 15·16 이어하기 | `ckpt.pt` 한 파일에 모델·최적화기·AMP·진행률·걸음 수·최고 점수·조각 상한. 학습률과 단계 경계는 '계획 전체 진행률'(20·45·70·100%) 기준이라 이어서 하면 그대로 이어짐. 원자적 저장. 학습이 오류로 끝나도 `finally`에서 마지막 저장본을 올리고 반환 코드를 확인. |
| 17 완결성 | 인코딩 장 수 ≠ 정답 장 수면 저장하지 않음. 해상도 폴더마다 `_done.json`이 있을 때만 '다 만듦'. 실패가 20%를 넘으면 비정상 종료. |
| 5 먼 좌표 | 화면 밖 아주 먼 점이 있어도 화면을 지나는 부분이 있으면 좌표를 잘라 남김. |
| 18 일부 | 장치 전송도 메모리 부족 처리 안으로. 조각 1개도 안 들어가면 명확히 중단. 검증의 메모리 부족은 그 문제만 건너뜀. 걸음마다 시간 확인. |

### 부분 인정·동의 안 함(근거)
- **14 메모리·시간:** RAM은 실제 실행 PC가 31.6GB라 1080 장면 24장(약 142MiB)을 작업자 12개가 들어도 약 2GB로 문제없다고 본다. '기본 학습 1.2시간'은 5060용 bat이 `--hours 3.2`를 넘기므로 해당 없음. **생성 시간은 맞는 지적이라** 1080·720은 반복 1번, ffmpeg 스레드 2개로 줄였고, 자료 만들기 시간을 뺀 나머지를 학습 시간으로 넘긴다(PC 사용 시간 초과 방지).
- **4 래스터 차이·7 관절 근접:** 차이는 1px 안팎이고 가운데선을 3px로 넓혀 학습하므로 영향이 작다고 본다(심각도 낮음). 지금은 고치지 않음 — 반론 있으면 근거로.
- **9 속성 읽는 자리:** 조립기에서 예측 띠의 능선(NMS)에서만 속성을 읽는 규약으로 정함. 오프셋 지도는 이번엔 넣지 않음.
- **19 검증 구성:** 최고 모델 선택은 마지막 단계(검증 목록 고정)에서만 하므로 단계마다 구성이 바뀌는 건 선택에 영향 없다고 본다. 짧은 확인은 이제 본 학습과 같은 배치로 돌린다.
- **20 28채널의 한계:** 동의. 이번 목표는 '보이는 결과를 적은 오브젝트로 근사'다. 같은 선 구분·채우기 윤곽 연결·가림 연결은 조립기 단계에서 풀고, AO ID는 다음 단계(장 사이 같은 오브젝트) 학습용으로 이미 저장한다.
- **12 앱 영상 검증:** 학습 중 검증 손실은 렌더러 영상이라 앱 차이를 못 잡는 게 맞다. 최종 시험은 학습에 안 쓴 9개 대표작의 **앱 내보내기 실제 영상**(정답 SFA 있음)과 4711 합작으로 한다.

### 확인 범위(정직하게)
- 자료 만들기 수정본은 서버에서 실행: 6파일×2반복 성공, 같은 압축값 반복본 두 개가 이름이 달라 둘 다 남음, `_done.json` 생성, 배경색 정답 = 그림 모서리 색.
- 학습 코드는 이 서버에 PyTorch가 없어 자료 읽기 부분만 가짜 torch로 실행(입력 9 × 256 × 512, 정답 27채널, 해시 분할 약 5.08%, 같은 원본 반복본은 같은 쪽). 손실·모델·이어하기는 GTX 1050 Ti 확인 실행이 첫 실행이다.
