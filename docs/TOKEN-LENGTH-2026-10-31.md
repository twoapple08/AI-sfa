# 장별 정답 문장 길이 측정 (2026-10-31)

목적: 2,048단어 한도를 넘는 장을 2판에서 어떻게 다룰지 고르는 근거. **측정만 했고 아무것도 바꾸지 않았다.**

- 방법: 서버 CPU, `sfa_tokens.encode`로 모든 파일의 모든 장 정답 문장을 만들어 길이와 단어 종류를 셈. 그림은 만들지 않음.
- 대상: 학습 403파일 22,371장, 시험 38파일 2,195장. 읽기 실패 0, 문법 확인 실패 0.
- 단어 종류 세부(특수 단어 내역, 반복 좌표)는 학습 파일 60개 무작위 표본에서 파일마다 앞 40장만 잼(seed 0).
- 학습 자료(seq_data)는 파일마다 최대 300장을 고르므로 실제 학습 비율과 조금 다를 수 있다.

## 1. 길이 분포

| 한도 | 학습 장 | 시험 장 |
|---|---|---|
| ≤1,024 | 80.8% | 59.5% |
| **≤2,048(지금)** | **91.4%** | **76.9%** |
| ≤3,072 | 95.2% | 85.0% |
| ≤4,096 | 97.4% | 87.9% |
| ≤6,144 | 99.2% | 91.5% |
| ≤8,192 | 99.6% | 94.4% |
| ≤16,384 | 99.9% | 99.7% |

- 학습에서 2,048을 넘는 장은 1,931장이다. 이 장들의 길이 중앙값은 3,355, 90% 지점은 6,074, 99% 지점은 29,662, 최대는 99,232.
- 시험에서 넘는 장은 507장이다. 중앙값 4,305, 90% 지점 10,712, 최대 31,902. 4711 합작(47112 계열)이 대부분이다.
- 모든 장이 2,048을 넘는 학습 파일은 74개다. 일부 장만 넘는 파일은 101개다.
  - 오늘 자료 커널에서 빠진 작업 147개는 74파일 × (원본 + 늘리기 1벌)과 맞는다.
  - 다만 늘리기 사본 하나는 화면 밖으로 나간 부분이 잘려 짧아지면서 살아남은 것으로 보인다(추정).
- 긴 장이 많은 학습 파일: 페인트/연습(138/408장), Ekkee_Pivot (2)(65/96), my_animation_final(61/61), 연출ㆍ이펙트ㆍ연기ㆍ능력(55/55), 스가구신버2(53/145), 검성(51/51).

## 2. 무엇이 길이를 차지하나

| | 짧은 장(≤2,048) | 긴 장(>2,048) |
|---|---|---|
| 장당 오브젝트(중앙값) | 28 | 300 |
| 오브젝트당 단어 | 11.2 | 11.5 |
| 좌표 단어 | 37.3% | 37.9% |
| 특수 단어 | 46.8% | 46.3% |
| 연결(link) | 7.9% | 8.2% |
| 색·굵기·글로우 | 5.2% | 4.0% |

- 특수 단어의 내역(표본 기준, 긴 장): PT 17.4%, LINK 8.1%, SAME 8.0%, LINE 7.3%, SEG 2.1%.
- 같은 장 안에서 이미 나온 좌표를 다시 쓴 단어가 전체의 15.7%다(표본 기준).
  - 예: 이어진 막대에서는 앞 선의 끝점 좌표를 다음 선이 다시 쓴다(`LINE SAME x y PT LINK 1 …`).

## 3. 해석

- **긴 장은 오브젝트가 많아서 길다.** 오브젝트 하나를 쓰는 데 드는 단어 수는 짧은 장과 거의 같다(11.2와 11.5).
  - 그래서 압축으로는 모든 장이 같은 비율로 짧아질 뿐, 긴 꼬리 자체는 남는다.
- **한도만 늘릴 때:** 4,096이면 학습 97.4%, 8,192면 99.6%가 들어온다.
  - 시험 파일, 특히 4711 합작은 4,096에서도 87.9%에 그친다.
  - 최종 시험 대상이 긴 장에 몰려 있다는 점이 2판 판단에 중요하다.
- **압축 여지(추정, 정답지를 바꿔 실제로 재지 않음):**
  - 반복 좌표 15.7%를 앞 점 참조 단어 하나로 바꾸면 그 몫의 약 절반을 줄일 수 있다.
  - PT·SAME·LINK 같은 구조 단어(합계 약 33%) 일부를 합치는 여지도 있다.
  - 둘을 합친 실제 절감량은 정답지·채점기를 고쳐서 다시 재야 안다.
- **2판 후보 순서(제안, 미결정):**
  1. 한도를 4,096으로 올린다. 메모리 절약 어텐션, 다시 계산하기, 짧은 장 → 긴 장 순 학습을 함께 쓴다.
  2. 반복 좌표 참조 같은 압축을 넣는다.
  3. 8,192를 넘는 장(학습 0.4%, 시험 5.6%)은 이어 쓰기로 처리한다.
- 1판은 2,048 그대로 둔다. 위치를 배우는지가 아직 확인되지 않았다.

재현: `python tools/measure_toklen.py . toklen.json` 다음에 `python tools/analyze_toklen.py toklen.json`. 결과 json은 저장소에 넣지 않았다. 특수 단어 내역과 반복 좌표 표본은 이 대화에서 따로 한 계산이다.
