# 3D·실물 형태 자료 후보와 라이선스 (2026-10-21, Claude 웹 조사)

보충 계획 ②층(사물 형태, 기계류)의 형태 기준으로 쓸 3D 자료 후보를 정리한다. **아직 받거나 쓰지 않았다.** 사용 여부는 사용자 결정이다(`docs/SUPPLEMENT-PLAN-2026-10-21.md` 6절). 출처 대장의 S08 행이 이 문서를 가리킨다.

| 출처 | 라이선스(조사 결과) | 공백 요소와의 관계 | 판단 |
|---|---|---|---|
| Poly Haven | 공식 FAQ: 모든 자산 CC0. 원저자라고 주장하거나 다시 라이선스하는 것은 안 된다 | 배·소품·환경 위주이고 탈것·무기는 적다 | **1순위(조건이 명확함)** |
| Kenney | CC0 1.0(GitHub 미러와 커뮤니티 글로 확인, 공식 사이트 원문은 직접 확인 못 함) | 저폴리 탈것·무기·소품 | 2순위. 쓰기 전에 공식 페이지 원문을 확인한다 |
| Quaternius | 총기 팩(50종 이상)은 itch.io 설명에 CC0. 탈것·메카 팩은 팩마다 확인 필요 | 총기 부품(탄창·스코프 등), 우주선·메카 | 2순위. 팩별로 라이선스 원문을 확인한다 |
| Sketchfab | 대부분 CC BY이고 CC0은 일부. **이용약관이 사용자 콘텐츠를 생성형 AI 개발에 쓰는 것을 금지하고, 'NoAI' 표시도 있다** | 탈것·무기 종류가 가장 많다 | **쓰지 않는 것을 권한다.** 우리 용도는 형태 참고 분석이지만 약관과 충돌할 여지가 있다 |

## 쓰는 방법(정해지면)

- 형태 기준으로만 쓴다. 비율, 부품 배치, 실루엣이다. 음영·질감·움직임은 나카무라 문법(번역 규칙)으로 덮는다.
- 출처 대장에 모델 이름, URL, 라이선스 원문 링크, 받은 날짜를 한 줄씩 적는다. 원본 모델 파일은 저장소에 넣지 않는다.
- CC0이어도 '원작자라고 주장하지 않는다', '다시 라이선스하지 않는다'(Poly Haven 조건)를 지킨다.
