# Android 네이티브 출력 경로: 시간축·트위닝·굵기

대상: 사용자 제공 Stick Fighter 51.0.0. 다음은 APK 정적 분석 결과이며 현재 Flutter 화면 재생/내보내기 모든 경로와 일치한다고 보장하지 않는다. 앱 코드 전체를 저장소에 복사하지 않고 수학적 관찰과 근거 위치만 기록한다.

## 시간축

MainActivity.v를 JADX fallback으로 읽어 확인한 네이티브 export 경로:

- P = 원본 재생 FPS 인자(exportFps), T = 보간 FPS 인자(tweeningFps), N = 원본 프레임 수.
- T > P인 경우 보간 경로. 출력 FPS는 T, 출력 개수는 Math.round(N / P * T).
- T <= P인 경우 원본 경로. 출력 FPS는 P, 출력 개수는 N.
- 보간 시 출력 j의 원본 위치는 (j/T)*P. 앞뒤 인덱스를 범위 안으로 제한하고, 소수부를 보간 계수로 사용.
- 마지막 원본 프레임 뒤에 다음 프레임이 없으면 마지막 프레임을 유지. 처음으로 루프 보간하지 않는 경로.

`native_timing.py`에 시간축만 독립 구현했다. Java float32의 경계 반올림까지 비트 단위로 복제하지 않고 정확한 유리수 계산을 사용한다. Flutter 전체 알고리즘 재현이나 SFA 내부 FPS 설정 추가 기능이 아니다.

재현 검사: (T,P)=(60,12)에서 N=122 → 610개/60FPS, N=90 → 450개/60FPS. 제공된 두 영상 메타데이터와 일치. (24,24), N=48 → 48개/24FPS.

```bash
python native_timing.py 122 --fps 60 12 --sample 1
```

## 도형 보간

Y2.i.d/e의 네이티브 경로:

- 앞 프레임의 도형에 대해 같은 객체 ID를 뒤 프레임에서 찾아 대응시킨다.
- 좌표점은 DB의 index_number로 대응시킨다. Y2.c 생성자와 X2.a 로더에서 필드 연결을 확인했다. XML AP.Index와 importer의 연결 확인이 추가로 필요하며 AP.ID와 혼동하지 않는다.
- 대응한 점은 X/Y 선형 보간, 대응점이 없으면 앞 좌표를 유지하는 분기.
- ARGB 채널과 일부 글로우 속성도 보간.
- 두 프레임에 공통인 도형을 다루는 경로가 확인되나, 생성/삭제/수동 TweenLink/채우기 대응의 전체 정책은 미확인.

그러므로 관찰된 선형 보간을 곧바로 모든 사쿠가 동작에 적용하면 안 된다. 생성기는 원본 키포즈와 타이밍을 설계하고 스미어/타격 프레임 등 의도적 급변을 보존해야 한다.

## 좌표와 도형

- Y2.g: X는 표시 영역 너비, Y는 높이에 대한 백분율. 종횡비를 유지하며 화면 여백 계산.
- Y2.m: TypeId 1은 선분, 2는 두 점을 지름 양 끝으로 한 원, 3은 세 점을 이용한 이차 베지어.
- 네이티브 도형별 stroke 최소값/반올림/배율 보정 존재. 현재 HTML preview는 여전히 근사 표시.

## 개별 선 굵기

DB 로더 X2.a에서 thickness_scale과 object_scale을 서로 다른 도형 속성으로 읽는 것을 확인.
네이티브 일반 도형 경로 Y2.i.a는 대략 다음 배율을 기본 Paint 굵기에 적용:

`max(0.05, sequence.thickness / 100 * detail.thickness_scale)`

글로우 경로는 object_scale도 곱하는 분기가 존재. 원/직선/곡선 및 보간된 도형에 별도 보정이 있으므로 위 식 하나가 모든 출력의 최종 픽셀 굵기를 뜻하지 않는다. 현재 SFA 샘플에 시퀀스 기본 굵기 저장 항목이 보이지 않으므로 가져오기 시 기본 굵기 유실 가능성도 확인해야 한다.

## 남은 검증

- Flutter 가져오기 직후 (60,12)가 되는 초기값/설정 승계 경로.
- Flutter 트위닝과 네이티브 트위닝의 동등성.
- 점 대응 필드의 정확한 의미, TweenLink, 생성/삭제/레이어 변경/채우기 변화.
- 기준 굵기와 요소 굵기를 앱 영상에서 픽셀 단위로 비교.

상태: 정적 분석으로 일부 경로 확인. 앱 전체 분석 완료가 아니다.
