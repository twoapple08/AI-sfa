## 실행

비공개입력은`.sfa`기준뼈대와`sfa-smear-clip-input/1`장별원래사슬/축/색/효과ID이다. 원본영상자동판독기가아니다.

```bash
python tools/smear_clip_variants.py \
  --base /비공개/approved.sfa --input /비공개/input.private.json \
  --profile profiles/smear_density_v1_1_reference.json \
  --output /비공개/새출력 --narrow .55
```

새출력에`기본폭.sfa`,`좁힌폭.sfa`,`binding.private.json`을만든다. 코드저장소내출력/기존경로덮어쓰기는거절한다. 두판의기존자식노드보존/폭외좌표/점수·속성·연결일치/전체장ID중복/상호연결좌표검사를실행한다. 자동스미어검출·새학습/GPU는실행하지않았다.

실제입력/원본/240프레임/장별좌표/두SFA/전체24장렌더/비교시트는Git제외`/workspace/scratch/nian41_10s_smear/`에보존한다. 전달은두SFA+전체비교+원본겹침+적용24장시트와설명ZIP,영상미리보기는추가하지않았다. 새두판의미관은사용자판정대기다.
