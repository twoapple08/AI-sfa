# 보충 계획 — 층 구조와 단계 (2026-10-21, 사용자·Claude 논의 확정안)

순위 초안(`docs/ELEMENT-RANK-DRAFT-2026-10-21.md`)에서 부족한 요소를 나카무라 스타일에 녹아들게 채우는 계획이다. 사용자가 제안한 방법 1(자연 배경은 프리렌)과 방법 2(이름난 고수를 시험해 고르기)에 Claude 제안(이웃 컷, 번역 규칙, 3D, 동반 조합)을 합쳤다. **설계안이며 아직 시험 전이다.**

## 1. 원칙

- 뿌리는 나카무라다. 다른 출처에서는 **형태와 정지 화면만** 빌린다. 움직임·타이밍·이펙트·연출은 나카무라 문법을 쓴다. 예외는 nian41의 몸 뼈대 움직임이다.
- 외부 스타일은 마지막에 최소한으로만 들인다. 이미 섞인 것이 증명된 자료(이웃 컷)와 번역 규칙을 먼저 쓴다.
- 모든 보충 자료는 출처 대장에 적는다. 문제가 생기면 층 단위로 뺀다.
- 원본은 저장소에 넣지 않고 분석 결과(규칙·수치)만 남긴다. 새 출처는 사용자 승낙과 범위 규칙을 거친다(`docs/INTAKE-PROCEDURE-2026-10-18.md` §5).

## 2. 층 구조

| 층 | 담당 | 출처(먼저 쓰는 순서) |
|---|---|---|
| ① 움직임·이펙트·연출(뿌리) | 타이밍, 스미어, 파편, 연기, 폭발, 카메라, 배경동화 | 나카무라 → (이펙트·연출) riooo·optical-core·yukina → (몸 뼈대) nian41 |
| ② 사물 형태 | 무기, 탈것, 메카, 소품 | 이웃 컷 → 나카무라식 번역 규칙 → 3D·실물(기계류) → 검증된 고수 |
| ③ 자연 배경(정지) | 숲·산·물·하늘·설원 | 프리렌(사용자 지정) |
| ④ 인공 배경(정지) | 도시·건물·실내 | 이웃 컷 → 검증된 고수 → 배경미술 작품(후보 미정) |
| ⑤ 생물·디자인 | 괴물·용·짐승 | 이웃 컷 → 고수 → 번역 규칙 |
| 접착제 | 층을 하나로 묶기 | 나카무라의 빛·색 연출(배경 물들이기·명암 반전), 배경동화 전환, 동반확률(장면 조합) |

- **이웃 컷:** 나카무라 컷과 같은 작품·같은 화수의 다른 애니메이터 컷이다. 감독·작화감독이 이미 섞어 놓은 자료다.
- **번역 규칙:** 나카무라가 사물을 상자·각진 덩어리·평면 음영으로 단순화하는 방식을 분야별 3–5줄 규칙으로 정리한 것이다. 규칙마다 기존 나카무라 장면에 맞춰 검증한 뒤 채택한다.
- **고수:** 웨일린 장 등 이름난 애니메이터다. 두 점수가 모두 높아야 승낙 후보로 올린다.
  - 보충 점수: 공백·보충 필요 요소를 채우는 부족도 × 난이도의 합
  - 섞임 점수: 나카무라 지표 분포와의 거리, 그리고 블라인드 시험
- **배경 규칙:** 정지·느린 장면은 정지 배경 층을 쓴다. 카메라가 크게 움직이는 순간에는 나카무라식 배경동화로 바꾼다. 임팩트 순간에는 흑백·실루엣 임팩트 프레임으로 층을 한 번 납작하게 만든다.

## 3. 공백 요소 하나를 채우는 순서

1. 나카무라 자료에 있으면 그대로 쓴다.
2. 이웃 컷에 있으면 쓴다.
3. 나카무라식으로 번역할 수 있으면 번역 규칙을 쓴다.
4. 정밀한 기계류면 3D·실물로 형태를 잡는다(라이선스 확인).
5. 자연 배경이면 프리렌을 쓴다.
6. 없으면 검증된 고수의 형태를 쓴다.
7. 어디에도 없고 일반 빈도도 낮으면 트리에서 접는다.

어느 단계로 채우든, 장면에 넣을 때는 동반확률대로 나카무라식 조합 안에 둔다(예: 총이면 섬광·파편·연기와 함께).

| 단점 | 대응 |

| 4. 번역 규칙이 어렵다 | 충분한 사물(파편·폐허·메카·바위)부터 사례를 모은다. 규칙 하나마다 장면에 맞춰 검증한다 |

| 6. 측정이 약하다 | CLIP 재측정과 GPT 공백 확인(H01–H04)으로 '측정 확정' 칸을 만든다. 확정된 것만 보충한다 |
| 7. 인공 배경 출처가 빈칸이다 | 배경미술이 강한 작품 후보를 사용자와 고른다. 그 전까지는 이웃 컷·번역 규칙으로 메운다 |
| 8. 시간·비용 | 1–7번 대응으로 헛수고와 되돌리는 비용이 준다. 토큰이 드는 단계는 시작 전에 예상치를 알리고 승낙을 받는다 |
