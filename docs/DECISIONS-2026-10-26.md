## 2. 철회·바꾼 것
| 이전 | 바뀐 것 | 이유 |

| 부정어에 monochrome·grey smoke 등(n1) | 버림 | 보라 괴물·청록 폭발이 끼어듦 |
| 틈 고침: 불 층 4px 넓히기 | 배경 층을 불 밑으로 넓히기 | 불꽃 끝이 둥글어지고 주황 테가 생김 |
| `--tips`를 모든 층에 | 불 층에만 | 연기 가장자리 잔톱니 |
| 배경 밝기 단계만 | 색 묶음(생성 그림) | 다른 색 배경이 한 덩어리로 합쳐짐 |
| 영상 전체 공통 문턱·색(`--shared`) | 채택 안 함 | 섬광 장·흰 장이 섞이면 더 나쁨(깜빡임 12.2→15.1) |

| 인물 자리 검게 칠하기 | 마스크 손실(알파 0) | GPT 1차 지적, 3차 학습에 반영 |

## 3. 섞은 것
- 실행 위치 장기 후보 C안: 휴대폰은 곡선 조립(가벼운 생성기), 서버는 고품질 모드.
- 블로킹: 실측값 + 가정(면적 곡선 모양, 무게중심 이동 대신 조각 흩어짐).
- 움직임 시험 입력: 숫자 블로킹(우리 로직) + 나카무라 실루엣 블로킹(c0348, 화풍 지움) 두 가지 비교.
- 영상 모델 = 선생, 기기용 작은 생성기 = 학생(장기).
- 로봇은 캐릭터 쪽이라 묘사 품질은 나중(이펙트·연출 우선 유지).

## 5. GPT와의 대화로 바뀐 것
### GPT 1차(10-25, docs/GPT-RESEARCH-SFA-METHOD-2026-10-25.md)
- 인물 자리 검게 칠하기 → 마스크 손실: **3차 학습에 반영**.
- lora_split이 화면 전체 채도로 나눔: 지적 기록, 3차에서는 회색 연기 면적으로 태그를 따로 담(분할 방식은 유지).
- 폰에서 SDXL 배제하지 말 것: 2차 조사에서 Core ML SDXL 31초/장 등으로 확인, 그래도 24장/초 애니는 무거움 → B안.
- 실험 1–3 제안: 실험 1(곡선 최소 맞춤·VTracer) 채택 안 함, 실험 3(영상 변환) 공통 문턱 채택 안 함·같은 그림 다시 쓰기 채택.
- (24,24) 정정: GPT 브리핑에 사용자 결정 반영.
### GPT 2차(10-26, docs/GPT-RESEARCH-NAKAMURA-2026-10-26.md)
- 나카무라 전용 공개 모델 없음 → 우리 클립 781개가 핵심 자산(Claude 검색과 일치).
- 영상 LoRA는 존재하나 Kaggle T4 학습 공개 기록 없음 → 100 step 측정 후 결정.
- 실재 확인(Claude 대조): OmniLottie(CVPR 2026, 벡터 애니 생성 4B), ToonComposer(ICLR 2026, 스케치+색 참조 → 사이 장·채색), MobileWan(Qualcomm, Wan2.2 5B 축소, 연구용).
- 나카무라 작화: quick & slow, 1·2코마 위주(우리 실측과 일치), 실사 현상 과장, 카메라 흔들림을 직접 추가 → **이펙트 변형과 화면 흔들림을 따로 학습**, **임팩트 장 전후는 참조 초기화**.
- 회색 연기를 원작 스타일로 보지 말 것(우리 대조와 일치).
- 자료 후보: 『中村豊の白黒エフェクトの描き方』, 원화집 vol.2(타임시트) — 입수 가능 여부 미확인.
- GPT 추천 경로 A(지금 LoRA + 시간 참조) / B(벡터 시퀀스 생성기) / C(영상 교사 + 벡터 학생) → B안(서버) 기준으로 A를 먼저, B는 장기, C는 측정 후.
- GPT 제안 중 이미 끝난 것: SFA 왕복 검증(앱 열기·내보내기 성공).
