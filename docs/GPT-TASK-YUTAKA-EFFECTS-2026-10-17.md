## 4. 출력 형식

한 클립에 한 줄, JSON Lines. 30줄을 하나의 코드 블록으로 낸다. 파일로 저장할 수 있으면 `gpt_observations_2026-10-17.jsonl`.

```json
{"post": 123456, "artist": "yutaka_nakamura", "work": "작품명 회차", "timing_note": "2s는 기 모으기 구간, 나머지 1s [추론]", "effects": ["번개: 꺾인 청백 폴리라인 + 흰 core, 매 프레임 경로 변경"], "direction": ["흰 전면 플래시 1장 후 검은 1장"], "background": ["강한 원근의 벽면을 훑는 배경 작화"], "sfa": ["번개=연결 직선 + glow, 매 프레임 새 경로"], "confidence_note": "작은 타일이라 파편 모양은 불확실", "evidence": "GPT 시각 판독(contact sheet) [추론]"}
```

규칙:

- 모든 판단은 contact sheet를 본 결과이므로 [추론]이다. timing.json 수치를 옮길 때만 [실측]이라고 쓴다.
- 안 보이는 것은 쓰지 않는다. 흐릿하거나 작아서 확실하지 않으면 `confidence_note`에 적는다.
- 확정 규칙처럼 쓰지 않는다. "~로 보인다", "~가 반복된다" 수준으로 쓴다.
- 이미 지식베이스에 있는 어휘와 같으면 같은 이름을 쓴다(예: 2톤 평면, 톱니 외곽, 반전 실루엣, 플래시 구두점).
- 마지막에 30개를 통틀어 **새로 보인 이펙트 어휘·연출 규칙 후보**를 최대 10개 요약한다. 각 후보에 근거 post_id를 2개 이상 붙인다. 근거가 1개뿐이면 '단일 표본'이라고 표시한다.
