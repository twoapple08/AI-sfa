# 조합 문제 + 쉬운 것부터 학습 — 2026-11-01

사용자 제안(11-01): "자료에서 일부를 떼 와서 같은 오브젝트라도 위치를 랜덤하게, 처음에는 적은 양으로 시작해 점차 오브젝트 수가 많아지게. 끝에 도달하면 1080에서 720으로 내려가 그 사이클을 반복. 우리는 애니메이션을 학습시키는 게 아니라 보고 스파로 그려 내는 실력을 다지는 것 → 모든 문제를 다 다르게 낼 수 있다."

## 왜 바꿨나
- 이전 자료는 파일마다 '원래 자리 1번 + 고정된 늘린 사본 1번'뿐이었다. 같은 그림이 두 자리에서만 나와 '이 모양이면 여기'를 외우기 쉬웠다.
- 10-30 진단 실험에서도 외운 자세를 쓰는 경향이 보였다.

## 무엇을 만들었나
- **조합기** `tools/sfa_compose.py`
  - **묶음**: 한 장에서 관절 연결(AC)이나 같은 면(FR)으로 이어진 오브젝트들이다. 스틱맨 한 명, 칼 하나, 면과 테두리가 통째로 움직인다(관절 하나씩 흩으면 스틱맨 모양을 못 배운다). 숨긴 레이어와 안 보이는 묶음은 뺀다.
  - **조합 장**
    - 목표 오브젝트 수(1–250, 로그 고르게)까지 여러 파일의 묶음을 놓는다. 크기 0.35–1.6배, 좌우 반전, 자리는 모두 무작위이고 화면 안에 놓는다.
    - 좌표는 화면 화소 비율로 옮긴다. 원은 원, 모양은 그대로다.
    - 묶음마다 레이어를 새로 만들고, ID·연결·면 참조도 새로 매긴다.
  - **배경 묶음**: 원래 화면의 40% 이상을 덮는 묶음이다. 30% 확률로 한 장에 하나를 맨 아래에 원래 크기·자리로 깐다(앞에 놓이면 다른 것을 모두 가린다).
  - **실제 장(약 30%)**: 실제 한 장 전체를 **장마다 다른** 변환(반전·0.7–1.25배·±12% 이동·굵기 0.5–2배)으로 바꾼다. 실제 애니의 겹침·가림 배치를 배우기 위해서다.
  - **페인트 합성**(사용자 10-29 결정 유지): 흰 바탕 장의 30%에 배경·띠·땅·그림자·빛을 SFA로 더한다.
  - **굵기**: 정답 굵기 칸 값으로 맞춘다. 그림과 정답이 같은 굵기가 된다(0.01 미만 굵기가 칸 최솟값으로 잘리던 문제를 고침).
- **자료** `seq_data.py --compose N [--W 폭 --video]`(자료 판 4)
  - 해상도마다 씨앗이 달라서 **단계마다 서로 다른 문제**가 나온다.
  - Kaggle 자료 커널은 해상도마다 4만 장을 만든다.
- **학습기 '쉬운 것부터'**(`seq_train.py`, 끄기 `--no-curriculum`)
  - 각 해상도 단계 안에서 정답 길이 하위 20%부터 시작한다.
  - 단계 진행에 따라 5% 칸으로 늘려 단계의 80% 지점에서 전체를 쓴다.
  - 다음 해상도 단계에서 같은 사이클을 반복한다. 앞 단계 섞기(30%)는 전체 길이를 쓴다.

## 같은 날 보완(사용자 지적 반영)
- **2,048을 넘는 실제 장도 쓴다**: 예전에는 통째로 버렸다(실제 장 806장 중 491장만 남음).
  - 이제 무작위 지점에 가까운 묶음부터 원래 자리·원래 앞뒤 순서로 한도까지 담아 자른다(`real_crop`).
  - 묶음 하나가 혼자 넘으면 그 안에서 오브젝트 단위로 자른다(`object_crop`).
  - 시험 결과: 자르기 실패 44 → 0장, 쓸 수 있는 장 582 → 620장.
- **장이 적은 파일**: 같은 장을 최대 3번, 매번 다른 변환으로 쓴다.
- **목표 장 수 맞추기**: 실제 장 요청은 파일마다 min(30, 장 수 × 3)이다. 해상도마다 6,774장이라 30%(1만 2천)에 못 미친다.
  - 모자란 만큼과 길이 한도 탈락분(약 3%)을 조합 장으로 채운다.
  - 서버 시험에서 목표 3,000장 중 2,920장이 나왔다. **해상도마다 약 4만 장, 합계 약 16만 장**.
  - **실제 장 비율은 30%가 아니라 약 17%**다. 장 1–2개짜리 파일이 많아서다. 같은 장을 더 많이 반복하면 그 작품에 치우치기 때문에 반복은 3번까지만 허용했다.

## 바꾸지 않은 것
- **판정 장치는 그대로다**: 평가 목록 45단위·30승, 외움 기준선, 입력 교환. 새 방식이 정말 외우지 않는지 같은 잣대로 재기 위해서다.
- 시험 파일(sv)과 위치 시험(ss) 자료도 그대로다.

## 확인(서버)
- 조합 장 80장: 화면 밖으로 빠진 것이 없는 장은 모두 정답 왕복 만점이다.
- ID 중복이 없고, 연결·면·레이어 참조가 모두 유효하다.
- 목표 1개면 실제로 1–2개가 나온다.
- 640폭 1,185장을 4코어로 49초에 만들었다(실패 0, 조합 694·실제 491, 정답 길이 중앙 278토큰).
- 페인트 합성은 691장 중 177장에 들어갔다.
- 입력 그림과 합성 그림을 눈으로 확인했다(스틱맨·칼이 통째로 무작위 자리에 놓임, 실제 장은 장마다 다른 자리).
- 작은 학습 확인 항목
  - 854 → 640 단계 전환과 단계마다 '쉬운 것부터 25% → 95%'
  - 그때 해상도로 판정
  - 기본 자료는 단계 전환 때 읽힘
- 단위 시험은 108개가 통과한다. 조합·쉬운 것부터 7개를 추가했고, 바뀐 설정에 맞춰 기존 4개를 갱신했다.
