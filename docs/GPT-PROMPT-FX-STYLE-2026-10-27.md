# GPT 프롬프트 — 이펙트·연출 버전 질문 (2026-10-27)

붙일 곳: 사용자가 사전 정보 없이 시작한 GPT 세션(docs/GPT-FRESH-SESSION-2026-10-27.md)에 이어서. 첨부 없음.
목적: 캐릭터 움직임 기준이던 계획을 이펙트(관절 없음)에 맞게 — 중간 표현, 움직임·모양 분리, 픽셀→벡터 vs 벡터 직접 생성, 자료 적을 때 검색+변형.

---
앞의 계획을 '캐릭터 움직임'이 아니라 '이펙트·연출'(폭발, 번개, 불 벽, 파편, 연기, 충격파)에 적용하려고 해. 메인은 나카무라 유타카, 서브는 이펙트·연출만 보충하는 4명이야. 조건이 몇 개 있어:
- 최종 결과는 픽셀 영상이 아니라 벡터 애니메이션 파일이야. 곡선(2차 베지어) 선, 곡선으로 둘러싼 채우기 면, 선에 거는 글로우(크기는 선 굵기와 연동), 색의 반투명으로만 그린다.
- 24fps에서 보간 없이 모든 장을 직접 그린다(같은 그림 유지 = 홀드도 직접 표현).
- 3D는 쓰지 않는다(Blender 3D 리그·3D 카메라 금지). 2D만.
- 자료는 방송 화면 영상이라 이펙트 위에 촬영 단계 글로우가 얹혀 있고, 캐릭터·배경과 겹쳐 있다.
- GPU는 RTX 5060 한 장(VRAM은 확인 중), 무료 Kaggle/Colab T4도 가끔 쓸 수 있다. 유료는 제외.

질문:
1. 이펙트에는 관절이 없어. 캐릭터의 '2D 스켈레톤 + 타이밍'에 해당하는 이펙트용 중간 표현은 뭐가 좋을까? (예: 레이어별 덩어리 윤곽 + 색 단계 + 덩어리 수·크기·속도·홀드 시계열 같은 것) 무엇을 기록해야 '나카무라다운 움직임'이 남고 그림체는 빠지는지 구체적으로.
2. 이펙트는 움직임과 '모양 디자인'(각진 불꽃 끝, 평면 3–4색, 찢어지는 심)이 강하게 붙어 있어. 캐릭터처럼 움직임과 외형을 완전히 분리하는 게 맞아, 아니면 모양 디자인도 스타일로 함께 배워야 해? 나눈다면 어떻게?
3. 최종이 벡터라면, 픽셀 영상을 생성한 뒤 벡터로 바꾸는 게 나아, 아니면 처음부터 벡터(곡선·면·글로우 파라미터)를 생성하는 게 나아? 자료량(같은 종류 이펙트 장면이 수십 개 수준)을 고려해서 판단해 줘.
4. 방송 화면에서 이펙트 레이어를 깨끗이 떼어 내는(가려진 배경 메우기, 촬영 글로우 분리, 캐릭터와 분리) 무료 도구·방법 중 품질이 가장 좋은 것은? (영상 인페인팅, 매팅, 분할 모델 등 구체 이름과 GPU 요구량)
5. '학습 전에 손으로 목표를 먼저 만든다'를 이펙트에 적용하면, 첫 기준 결과물은 무엇이어야 해? 예를 들어 '나카무라 폭발 장면 하나를 벡터로 그대로 옮긴 것'으로 충분한지, 아니면 '두 장면의 움직임을 섞은 새 폭발'까지 손으로 만들어야 하는지.
6. 자료가 적은 상황에서 첫 생성기는 학습 모델이 좋아, 아니면 실제 장면 조각을 골라 변형·조합하는 방식(검색 + 변형)이 좋아? 각각 장단점과, 나중에 학습 모델로 넘어가는 시점.
7. '나카무라답다'를 사람이 아닌 방법으로도 평가할 수 있는 지표가 있을까? 없다면 사람 평가를 어떻게 설계하면 흔들리지 않을까?

각 답은 '추천 / 이유 / 우리 조건(벡터·24장·2D·5060)에서 주의할 점'으로, 막연한 원칙 말고 실제로 할 작업 단위로 써 줘.
