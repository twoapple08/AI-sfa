# 직진(팔 축 방향) 스미어 — 2026-11-08

## 문제(사용자)
"팔이나 다리가 호를 그리며 이동하면서 나오는 스미어는 문제가 없지만, 직진 이동을 위한 스미어가 없다."

기준판(GPT 표시 테이퍼판, SFA `e6556a67…`)은 국소 이동이 팔 축과 거의 나란한 효과(코사인 > .88)를 `flow_axial_candidate`로 분류한다. 그런데 이 효과 22개를 손끝 주변에 폭 '팔 길이×.22'의 짧은 지그재그로만 그려서, 화면에서는 화살촉처럼 보였다.

## 원본 관찰(비공개 프레임, Claude 눈 판독)
1173·1174·1181·1182·1230 등에서 같은 모양이 보인다. 팔 끝(주먹·손목)이 팔뚝 축 방향으로 늘어나면서, 팔 굵기만큼의 폭에 거의 평행한 가는 톱니 가닥 여러 개로 갈라진다. 가닥은 서로 이어진 지그재그이고, 주먹은 가닥 안에 들어간다. 예전에 사용자가 지운 '주먹 뒤 평행 빗살'(v5)과는 다른 모양이다.

## 형태(`tools/sfa_axial_smear.py`, 사용자 선택 B)
- 방향은 항상 팔꿈치→손, 즉 바깥쪽이다. 내지를 때는 주먹이 앞으로 늘어나고, 거둬들일 때도 지나온 자리가 바깥쪽이다. 1230은 자세 자료상 거둬들이기인데 원본 갈래가 바깥쪽에 있었다.
- 폭 = 팔 선 굵기(px)×2.1. 가닥 수 = 폭/(스미어 선 굵기×2)+1, 범위 3–6. 기존 규칙 '굵을수록 밀도를 줄인다'를 따른 것이다.
- 전체 길이 = max(팔뚝×1.2, 속도 외곽(최대 팔뚝×1.68)). 앞뒤 58:42는 기준판 그대로다. 가운데 가닥이 조금 길다(가장자리 −30%).
- 후보 A(폭×1.6, 길이×.85)는 사용자가 B를 골라 미채택했다.

## 직진/회전 분류
기준판 조건은 회전각을 보지 않아서, 1036(133°)처럼 크게 도는 팔에도 직진형이 들어갔다. 회전각은 이전→현재 팔뚝의 2D 각도 변화다.
- |각| ≤ 15°: 직진 갈래
- |각| ≥ 40°: 회전형(`flow_axial_rotation`, 기준판 표시 테이퍼). 관절 쪽 톱니 중 손끝 이동과 반대이거나 폭이 스미어 선 굵기보다 얕은 것은 뺀다(1158 첫 톱니 2px가 방향 검사를 깨뜨렸다).
- 15–40°: 회전각만으로는 나뉘지 않는다. 사용자 판정을 보면 1158(21°)은 회전, 1181(31°)은 직진이었다. 그래서 장면 설정 `scenes/nian41_1032-1271_axial_smear.json`의 사용자 판정을 쓴다. 판정이 없으면 직진으로 두고 `needs_review`에 남긴다.
