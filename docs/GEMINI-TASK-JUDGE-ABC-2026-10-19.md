# Gemini 작업 지시: 임팩트 판정 묶음 A·B·C (2026-10-19)

사용자가 직접 판정하기 전에 Gemini에게 먼저 판정을 맡긴다. Gemini 판정은 **사용자 판정이 아니다.** 결과는 Gemini 판정으로 따로 기록하고, tag_overrides의 confirmed 승격은 사용자 확인 뒤에만 한다.

## 복붙 프롬프트

```
너는 애니메이션 작화 판정자야. 내 Google Drive의 `AI-sfa/02_분석자료/` 안에 판정 묶음 3개가 이미 올라가 있어. 파일을 직접 열어 보고 구간마다 "임팩트 프레임"인지 판정해 줘.

[위치]

대개 흑백(또는 한 가지 색조)으로, 날카로운 선·실루엣·그림자·해칭처럼 강조할 부분을 집중해 그린 짧은 삽입 프레임(Sakugabooru의 ショックコマ).

- 흰 바탕+검은 선·해칭·연필 결·실루엣 / 검정 바탕+흰 날카로운 선·방사선·별 모양 섬광·실루엣
- 흑백 2색으로 처리된 거친 손그림 결, 한 색조(보라·적색·올리브 등) 해칭
- TV판처럼 명도가 낮아져 어두운 회색 바탕+해칭으로 보이는 것도 해당한다.
- 흰 바탕에 선이 조금만 있어도, 그려진 선·형태가 보이고 앞 문맥이 컬러 장면이면 해당한다.

[아니다]
- 흰색·검정 단색 전면(그림·선 없음), 흰 화면만 번쩍이는 섬광
- 원래 어둡거나 저채도인 장면(밤·동굴·연기·그림자)으로 앞뒤 문맥과 같은 장면이 이어지는 것

- 채도 있는 컬러 장면·컬러 집중선·컬러 색면(컬러 쇼크 프레임은 대상 아님)
- 그려진 형태 없이 부드럽게 번진 발광(글로·블룸) 촬영 효과
- 회색 3D/CG, 실사, 흑백 회상처럼 길게 이어지는 무채색 연출
- 원화·선화·콘티 같은 제작 자료 화면(흰 종이 위 연필 선화가 영상 내내 이어짐)

[부분]

[애매]
- 위로 확실히 나눌 수 없을 때만 쓴다. 억지로 정하지 마.

[중요 규칙]
- 반드시 실제 파일을 열어 보고 판정해. 파일을 열 수 없거나 폴더를 못 찾으면 추측하지 말고 label에 "열지못함"이라고 적어.

[출력 형식] 코드블록 안에 CSV로만. 머리줄은 매번 넣어.
묶음,no,post_id,frames,label,reason
```
