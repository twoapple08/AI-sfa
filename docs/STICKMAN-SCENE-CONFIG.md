# 새 장면에 같은 뼈대 시스템 적용

사용자 지시: 새 장면마다 완성된 뼈대 구조·코드를 바꾸지 않는다. 고정 프로필은 `profiles/stickman_2d_v1.json`, 장면 데이터는 `scenes/*.json`이다. 현재 실제 예시는 `scenes/nian41_1032-1271.json`이다.

## 고정하는 것

- 직선 몸통과 기존 팔다리, 원 머리, 내부 투명 연결을 가진11객체 구조.
- 장마다 새 점ID, 장간 객체ID 유지, 인물별 파란점 하나, 흰 머리, (24,24).
- `stickman-2d-11-v1`과 뼈대 원형의 SHA-256. 원형이 달라지면 장면 적용을 거부한다. 새 장면을 수용하려고 마디나 연결을 추가하지 않는다. 실제 구조 결함을 고칠 때는 버전·근거·기존 장면 회귀를 별도로 기록한다.

## 장면에서 바꾸는 것

- `start`, `end`, `cuts`: 원본 영상 장 번호. 재생기 번호1은 `start`다. 이벤트는 한 컷 안에 둔다.
- `source_sha256`: 원본 영상 식별. 지정하면 다른 영상에 설정을 적용하는 것을 막는다.
- `contacts`: 접촉의 구간·대상 끝점·목표점. `members`는 움직일 손목/발목이고 `target`은 상대 인물의 점이다. 선 위 접촉은 `{actor,start,end,t}`를 쓴다. 실제 그림의 손바닥/신발 때문에 양쪽 뼈대 끝을 함께 보정해야 하면 `anchor_keys`에 접촉 위치를 준다.
  - 가까움만으로 접촉을 추가하지 않는다. 1048–1049는 사용자 확인 근접 회피라 제약을 제거했다. 비접촉·회피·미확정을 접촉으로 바꾸지 말고 원본 근거와 사용자 판정을 따른다.
- `feather`: 접촉 전후의 부드러운 연결 길이. 기본2장, 컷을 넘지 않는다. 접촉 구간 안에서는 목표점에 정확히 붙고 전후에서 서서히 원래 포즈로 돌아간다.
- `straighten`: 뻗은 차기처럼 필요한 구간의 사슬 중간점을 뿌리–끝 선 위에 배치한다. 전체 장면의 고정 길이를 강제하는 옵션이 아니다.
- `tracks`: 원본에서 확인한 소량 보완 관측. `keys`의 좌표를 구간에 적용한다. 새 장면의 잘못된 검출을 고치려고 코드에 장 번호 예외를 넣지 않는다.
- `partials`: 전신 검출이 없어도 보이는 팔다리를 표현한다. 가까운 기존 인물 틀을 쓰되 `visible_segments`만 표시한다. 같은11객체·연결망을 유지하며 화면 밖 몸·머리는 숨긴다. 관측 안 된 몸 위치는 추론임을 `evidence`에 기록한다.

좌표는 **원본 영상 화소**다. 세로 검은 띠를 뺀 SFA 좌표가 아니다. 현재 예시는 원본1152×720, 위63을 잘라1152×648로 변환한다. 부분 인물의 표시 조각 번호는 프로필의 `objects` 목록을 따른다. 예:7·8은 오른쪽 허벅지·정강이,9·10은 왼쪽이다. 내부11번은 표시하지 않는다.

## 실행

```sh
python tools/stickman_clip.py /비공개/관측.jsonl.gz /비공개/원본.mp4 /비공개/결과.sfa \
  --start 1032 --end 1271 --cuts 1136 1234 --crop-y 63 --projection \
  --scene scenes/nian41_1032-1271.json \
  --thick-ref 40:blue:1.0 120:red:5.0 \
  --report /비공개/보고.json --joints /비공개/출력좌표.json
```

`--image-keys`는 이전 비교에서 만든 선택 옵션으로, 이 설정을 쓰기 위한 필수 조건은 아니다. 장면별 관측·리그 비율·거리 굵기는 기존 변환 입력/옵션으로 정하고, 뼈대 구조를 다시 편집하지 않는다. 새 인물 비율은 기존 규칙에 따라 비율표·관절 확인 그림으로 검토한다.

보고에는 프로필ID·프로필 해시·장면 해시, 접촉 전후 거리와 부분 인물 기록이 남는다. 접촉점이 같아져도 인물 사이에AC를 만들지 않는다. 만남은 좌표 관계이며 두 인물은 각각 편집 가능한 연결망을 유지한다.

원본이 접촉하는지 판단하는 과정과 관측 오검출 검토는 남는다. 이 설정은 모든 영상의 접촉을 자동 인식한다는 뜻이 아니다. 같은 형식의 새 장면은 데이터로 적용하며, 애매한 접촉은 원본 근거와 함께 사용자 판정을 받는다. 전체 관절·영상·발췌는 Drive/비공개 경로만 사용한다. 저장소의 실제 장면 예시는18개 소량의 수동/추론 키 좌표와 이벤트 설정이며 전체 원관절이 아니다.

## 재사용 기술 v1

전체 작업 절차는 `docs/STICKMAN-EXTRACTION-V1.md`, Claude용 스킬은 `.claude/skills/stickman-extraction/SKILL.md`다. 재피팅 없는 장면 적용은 `tools/stickman_finalize.py`, 저장 SFA 전수 검사는 `tools/stickman_quality.py`를 사용한다. 이펙트 가림1116–1117은 `tracks`의 추론 키, 빠른 다리1137–1138은 `partials`의 직선 무릎으로 보존했다.
