**5. 6차 §4 CPU 2D·3D 피팅 설계**

**진단의 목적과 큰 순서에는 동의합니다.** 처음에는 시간 평활 없이 장별 기하 피팅을 해 관측·골격 제약의 영향을 분리하고, 오류 관절을 넣고 뺀 민감도와 복수 초기값을 살펴보는 것이 유용합니다.

다만 실행 전에 다음을 고정해야 합니다. 아래는 설계 제안이며 아직 실험 결과가 아닙니다.

| 항목 | 보완할 내용 |
|---|---|
| 공통 골격·관측점 | 2D·3D가 같은 이름·연결의 중간 골격을 사용한다. RTMW 얼굴 5점·몸 12점과 앱 10조각을 무조건 일대일로 맞추지 않는다. 파생 목·골반을 원 관절과 중복 관측으로 넣어 가중치를 두 배로 만들지 않는다. |
| 길이·배율 정책 | 신뢰 가능한 관측으로 정한 같은 기준 길이/정책을 고정하고 입력 필터 판마다 다시 추정하지 않는다. 화면 투영 길이 중앙값을 3D 실제 길이 정답으로 취급하지 않는다. 전역 배율을 3D에만 자유롭게 주지 않는다. |
| 입력 마스크 | 원 RTMW판과 검수 필터판을 모두 실행하되, 보이는 오답 손목 10과 가려진 팔꿈치 8을 구분해 기록한다. 필터판에서 검증 못 한 관절은 0 가중치/제외로 두고, 원판은 오류 주입 민감도 조건으로 명시한다. RTMW 점수를 곧바로 확률 가중치로 쓰지 않는다. |

| 시간축 | 확인된 작화/포즈 구간만 상대 포즈를 공유한다. 루트 화면 위치·배율 등은 장별 보존한다. 숨은 관절을 채운 출력은 모델 추정으로 표시한다. |
| 구현 검증 | 고정 길이 위반·수렴 실패·계산 시간도 기록한다. 고정 길이 모델의 길이 일관성은 주로 제약 구현 검사이지 자연스러움 우열 점수가 아니다. |

**3D에는 다음 제한을 추가해야 합니다.**

약한 원근 투영은 대략 `q = s·Π(RX) + t`입니다. 루트 위치, 투영 평행 이동, 전역 회전, 배율을 중복해서 자유롭게 두면 같은 화면 결과를 만드는 해가 많아집니다. **루트 기준점·좌표축·카메라/몸 회전 중 무엇을 변수로 둘지·배율의 단위와 허용 범위를 고정**하고 자유변수 수를 보고해야 합니다.

실험은 먼저 공통 배율을 고정한 조건을 두고, 필요하면 양쪽 모두 같은 전역 배율 자유도를 주는 조건을 추가할 수 있습니다. 실제 영상의 배율 변화와 골격 길이 변화를 같은 변수로 몰아넣지 않도록 조건을 나누자는 제안입니다.

**깊이 부호만 문제가 아닙니다.** 배율이 미지이면 연속적인 해의 모호성도 생기며, 정면·뒷면 반전이나 뼈 축 회전처럼 2D 관절 위치로 정해지지 않는 정보가 있습니다. 여러 초기값에서 나온 해는 다음처럼 보고하는 편이 좋겠습니다.

- 수렴·실패 횟수와 각 해의 재투영 잔차.
- 같은 좌표 기준으로 정렬한 뒤 구별되는 해의 묶음.
- 전체 반사처럼 관측상 동등한 해와 장 사이 가지 전환을 구분.
- 초기값 수·허용 오차·최적화 종료 조건. 발견한 해의 수를 가능한 모든 해의 수라고 부르지 않음.

**필수 대조군으로 ‘3D를 평면에 제한한 판’을 추가**하겠습니다. 같은 골격·관측·손실에서 2D판과 비슷한 해를 내는지 보면 구현 차이와 깊이 자유도의 효과를 분리할 수 있습니다. 자유로운 3D판의 재투영 잔차가 더 작아도, 그 자체는 깊이가 맞거나 스틱맨이 더 자연스럽다는 증거가 아닙니다.

또한 **2D 고정 화면 길이와 3D 고정 공간 길이는 같은 제약이 아닙니다.** 3D 뼈는 길이가 같아도 투영되면 짧아질 수 있습니다. 원근 단축을 허용한 효과를 곧바로 ‘3D 방법의 우수성’으로 해석하지 말고, 단축 정책을 실험 조건으로 기록해야 합니다.
