## 2. 공식 판정 조건과 고해상도 종료 뒤 360 판정 — 기본 640 설정에서 확인 완료

`official_judgment()`는 마지막 판정·계획 끝·축소 아님·기본 입력 폭을 함께 확인한다. 기존 다섯 경우는 false/false/true/false/false로 의도대로 나온다.

실제 `judge_eval()` 함수의 제어 흐름을 추출해 평가·생성 부분을 대체한 단위 확인도 했다. 이는 모델 학습이나 실제 SFA 생성 시험이 아니라 분기·옵션 전달·상태 갱신 확인이다.

| 상황 | 결과 |
|---|---|
| 마지막·600/600분·전체 목록·640폭 | 공식 |
| 마지막·600/600분·축소 목록 | 추세 |
| 마지막·600/600분·전체 목록·1920폭 | 고해상도는 추세 |
| 위 고해상도 뒤따르는 640폭 | **공식**, 생성 상한 2048 |
| 축소 목록의 고해상도 뒤따르는 640폭 | 추세 |

고해상도 결과와 뒤따르는 360 결과가 한 실행에서 모두 공식으로 중복 계산되는 문제는 없다. 고해상도는 공통 추세 상한 178, 뒤따르는 공식 360은 2048을 사용한 것도 확인했다.

단, 함수는 숫자 640 자체를 고정하지 않고 `w == in_w`를 확인한다. 따라서 `official_judgment(True, 600, 600, False, 854, 854)`는 true다. 현재 기본 `in_w=640`에서는 이전 반례가 해소됐지만, **공식 판정을 반드시 360으로 제한한다는 요구를 설정 변경에도 보장하려면 `w == 640` 조건이나 공식 실행 시 `in_w=640` 검증도 필요하다.**

## 3. 남은 결함 — judge_official_n이 저장되지 않아 연장에서 다시 1이 됨

출처: [seq_train.py 최종 저장·평가 순서](https://github.com/twoapple08/AI-sfa/blob/b073a808f647efa9346de0458d63e7c86816a96c/tools/seq_train.py#L939), [공식 횟수 증가](https://github.com/twoapple08/AI-sfa/blob/b073a808f647efa9346de0458d63e7c86816a96c/tools/seq_train.py#L702).

최종 실행 순서는 다음과 같다.

1. `save_ckpt()`로 st를 저장한다.
2. `gen_eval(final=True)` → `judge_eval()`에서 `st['official_n']`을 증가시킨다.
3. 결과를 log.jsonl에 기록한다.
4. 증가한 st를 체크포인트에 다시 저장하지 않고 종료한다.

따라서 처음 저장본에 공식 횟수가 없으면 다음처럼 된다.

| 시점 | 메모리·로그 | 저장한 state |
|---|---:|---:|
| 최초 공식 판정 종료 | 1 | 키 없음, 0 취급 |
| 그 저장본으로 연장해 공식 판정 | **다시 1** | 여전히 이전 값 |

실제 소스의 마지막 저장·평가 AST 순서와 실제 `judge_eval()` 분기를 실행하고 저장 동작을 상태 복사로 대체한 제어 흐름 재현에서도 **first_log=1, first_memory=1, first_checkpoint=0, extended_log=1**이었다. 실제 torch 체크포인트나 전체 학습을 실행한 결과로 해석하지 않는다.

고해상도 종료 뒤 360 경로도 같은 문제다. `judge360_official_n=1`은 해당 실행의 기록에 나오지만, 증가값이 저장본에 반영되지 않는다.

필요한 수정은 다음과 같다.

- 공식 판정 뒤 공식 횟수와 판정 식별값을 영구 저장하고, 이어하기가 그 값을 읽도록 한다.
- **최초 공식 1 → 저장 → 재개 → 연장 공식 2**를 검사하는 회귀 시험을 추가한다.
- 한 실행 안의 고해상도 추세 + 360 공식은 공식 횟수가 한 번만 증가하는지 함께 검사한다.
- 사전 지정 최초 끝·연장 끝 두 기회라는 운용 조건은 유지한다.

로그에 결과가 남는 것과 이어하기 상태가 보존되는 것은 별개다. 이번 결함은 결과의 점수 계산이 아니라 공식 판정 기회 번호의 연속성 문제다.

## 5. 회귀 시험 — 이전 반례를 막지만 횟수 재개는 미포함

`tests/test_gpt_recheck.py`의 세 검사 메서드를 실행해 모두 통과했다.

- R.PARAMS 복원.
- 실제 1080 H.264 저장·복원의 검사 ON/OFF 비교.
- 공식 판정 조건 다섯 경우.

공식 조건 시험은 seq_train 전체 모델을 불러오지 않고, 실제 소스에서 순수 함수 `official_judgment()`만 AST로 추출해 연결했다. 렌더와 H.264 저장·복원은 실제 함수·ffmpeg 경로를 실행했다.

기존 세 검사는 이전 36→12화소·축소 목록·1920 공식 표시 반례를 제대로 막는다. 다만 **공식 횟수의 저장·재개와 고해상도 뒤 360의 실제 호출 연결**은 해당 세 검사에 없었다. 이번 추가 확인으로 후자 분기는 정상이고 전자의 저장 결함이 드러났다.

전체 119개 시험, 실제 모델 학습, GPU 실행, 앱 열기는 새로 실행하지 않았다.

## 부록 B. 회귀 시험·예외 복원·공식 호출·횟수 저장·캐시 확인

다음 코드도 같은 저장소 루트에 별도 임시 파일로 저장해 실행한다. 공식 제어 흐름에서는 모델·채점·저장을 대체하므로, 실제 학습·모델 생성·torch 파일 저장 검증과 구분한다. 횟수 결함을 재현하는 assert는 수정 전 상태를 기대한다. 결함 수정 뒤에는 기대값을 공식 1→2와 저장값 보존으로 바꿔야 한다.

```python
import ast
import contextlib
import copy
import importlib.util
import io
import json
import sys
import tempfile
import time
import types
import unittest
from collections import Counter
from pathlib import Path
from types import SimpleNamespace
from unittest.mock import patch

ROOT = Path(__file__).parent
sys.path.insert(0, str(ROOT / 'tools'))
import seq_check as SC
import seq_data as D
import sfa_render as R
import kaggle_seq_worker as KW

tree = ast.parse((ROOT / 'tools/seq_train.py').read_text())
helper = next(n for n in tree.body if isinstance(n, ast.FunctionDef) and n.name == 'official_judgment')
train = next(n for n in tree.body if isinstance(n, ast.FunctionDef) and n.name == 'train')
judge = next(n for n in train.body if isinstance(n, ast.FunctionDef) and n.name == 'judge_eval')
helper_scope = {}
exec(compile(ast.Module(body=[helper], type_ignores=[]), '<actual-helper>', 'exec'), helper_scope)
helper_fn = helper_scope['official_judgment']

# Run the exact three regression test methods; import only the pure helper from
# seq_train so this check does not require torch or load a training model.
helper_module = types.ModuleType('seq_train')
helper_module.official_judgment = helper_fn
sys.modules['seq_train'] = helper_module
spec = importlib.util.spec_from_file_location('test_gpt_recheck', ROOT / 'tests/test_gpt_recheck.py')
test_module = importlib.util.module_from_spec(spec)
spec.loader.exec_module(test_module)
result = unittest.TextTestRunner(verbosity=2).run(unittest.defaultTestLoader.loadTestsFromModule(test_module))
assert result.wasSuccessful() and result.testsRun == 3

# Restore settings even on an exception, beyond the normal-return regression.
seq, fr = test_module.scene()
R.PARAMS.update(pad=7.0, thick_mul=1.25)
before = dict(R.PARAMS)
with patch.object(R, 'render_frame', side_effect=RuntimeError('injected render failure')):
    try:
        SC.mismatch(seq, fr)
    except RuntimeError:
        pass
    else:
        raise AssertionError('exception was not raised')
assert R.PARAMS == before

# The final training tail is selected from the real AST, preserving save/eval order.
loop_idx = max(i for i,n in enumerate(train.body) if isinstance(n, ast.While))
tail = train.body[loop_idx+1:]
def is_save(n):
    return isinstance(n, ast.Expr) and isinstance(n.value, ast.Call) and isinstance(n.value.func, ast.Name) and n.value.func.id == 'save_ckpt'
def contains_gen(n):
    return any(isinstance(x, ast.Call) and isinstance(x.func, ast.Name) and x.func.id == 'gen_eval' for x in ast.walk(n))
tail_nodes = [n for n in tail if is_save(n) or (isinstance(n, ast.If) and contains_gen(n))]
tail_code = compile(ast.Module(body=tail_nodes, type_ignores=[]), '<actual-final-save-eval-order>', 'exec')
judge_code = compile(ast.Module(body=[judge], type_ignores=[]), '<actual-judge-controller>', 'exec')

def run_controller(state, width=640, reduced=False):
    st = copy.deepcopy(state)
    saved = {}
    cap_calls = []
    js = SimpleNamespace(stage={1920,1280,854}, tok=[[[0]*25,[0]*22,[0]*25,[0]*22]],
                         ents=[dict(hwr=.5625)], image=lambda i,d,w=None: (w or 640,d))
    def fake_evaluate(js_, gen, dirs, **kwargs):
        for d in dirs:
            gen(0,d)
        return {}, {}
    def gen_img(im,hwr,n_ans=None):
        cap_calls.append(dict(width=im[0], cap=2048 if n_ans is None else min(2048,2*n_ans+128)))
        return [1,2], True, 0.01
    env = dict(net=SimpleNamespace(eval=lambda:None, train=lambda:None), time=time,
               widths=[width], st=st, js=js, cfg=dict(in_w=640), js_reduced=reduced,
               official_judgment=helper_fn, reasons=Counter(), gen_img=gen_img,
               J=SimpleNamespace(evaluate=fake_evaluate, flat=lambda out,pre='judge_': {}, summary_line=lambda *x:'control-only'),
               memo={2:12.07,4:11.63}, judge_sheet=lambda *x:None, dev='cpu',
               a=SimpleNamespace(gen_minutes=1), rec={}, tm={'gen':0})
    exec(judge_code, env)
    env['save_ckpt'] = lambda: saved.update(copy.deepcopy(st))
    env['gen_eval'] = lambda final=False: env['judge_eval'](4,final)
    with contextlib.redirect_stdout(io.StringIO()):
        exec(tail_code, env)
    return dict(record=env['rec'], live=st, saved=saved, caps=cap_calls)

first = run_controller(dict(stage=0,done_min=600,plan_min=600))
resumed = dict(first['saved'],done_min=1200,plan_min=1200)
second = run_controller(resumed)
high = run_controller(dict(stage=0,done_min=600,plan_min=600),1920)
small = run_controller(dict(stage=0,done_min=600,plan_min=600),1920,True)
```
