너는 AI-sfa 프로젝트의 3자 협업(Claude·GPT·Gemini)에 참여하는 Gemini다. 이 대화는 새로 시작하므로, 아래 내용만으로 작업한다. 사용자가 조정 권한을 Claude에게 맡겼고, 이 지시는 Claude가 작성했다. 작업 전에 이 작업에 맞는 모델·추론 설정을 먼저 알려 줘.

# 1. 프로젝트 요약

- 목표: 모바일 앱 **Stick Fighter**의 기능만으로, 두 '뿌리' 애니메이터의 스타일을 녹인 AI 고유의 애니메이팅 스타일을 만든다. 지금은 영상을 보고 기법을 구조화하는 **분석형 학습** 단계다(가중치 학습 아님). 개인 사용.
- 앱 재료: 직선, 원, 곡선, 닫힌 영역 평면 채우기, glow, 투명도, 색, 선 굵기, 레이어·그리기 순서, 프레임별 배경색. **없는 것:** 카메라, 블러, 그라데이션 채우기, 촬영 발광·색수차. 카메라 이동은 모든 점을 변환해 흉내 낸다. FPS는 (트위닝 fps, 재생 fps) 순서로 쓰고, 사쿠가식 작화는 보간을 끈 (24,24)를 기본으로 본다.
- 뿌리 두 명과 학습 범위:
  - **yutaka_nakamura:** 이펙트·배경·연출. **에반게리온 클립은 학습 제외.**
  - **nian41:** **사람 몸 움직임만.** 표정 같은 그림체, 머리카락, 이펙트, 연출은 학습 제외.
- 역할: GPT = yutaka_nakamura 자료 수집·분석. Claude = nian41 분석, 측정·대조, 지식베이스 통합, 조정. **Gemini = 아래 작업 A·B·C.**
- 원본 영상은 사용자 Google Drive에 비공개로 보관돼 있다(yutaka_nakamura 358건, nian41 48건). Gemini는 공개 사이트 링크로 작업한다.

# 2. 사용자 핵심 기준 (반드시 지킬 것)

1. **임팩트 프레임은 4B 연필 선화 느낌만 학습한다 (최중요, 필수 조건).** 디지털 단색 느낌은 학습하지 않는다. 구분 태그:

| 태그 | 보이는 특징 | 학습 |
|---|---|---|
| `impact_frames_pencil` | 흑연 선 결이 보임, 방사형 해칭을 겹쳐 회색 농도를 만듦(빽빽할수록 진함), 흰 종이 바탕, 거칠고 갈라진 가장자리, 손으로 그은 불규칙한 선 굵기 | 함 |
| `impact_frames_digital` | 검정·흰·단색으로 꽉 찬 평면, 매끈하고 날카로운 가장자리, 선 결·해칭 없음, 면 안의 농도가 균일, 화면 전체 흰색·검정 깜박임 | 안 함 |

   - 디지털 기준 예시: https://www.sakugabooru.com/post/show/302394 의 **0–13프레임**(24fps, 0부터 셈). 흰 가시 섬광 면(0·2·3), 검정 전면(1·5·13), 흰 전면(8·11). 14프레임부터는 불꽃 이펙트다.
   - 연필 기준 예시: 사용자가 첨부한 원화 사진(흰 종이 위 흑연 방사 해칭, 중심 흰 섬광, 인물 실루엣을 흰 여백으로 남김, 십자 섬광선).
   - 판정 단위는 **프레임 구간**이다. 한 클립에 둘이 섞일 수 있다. 거칠지만 붓·먹 느낌이면 연필로 단정하지 말고 '후보'로 둔다.
2. **구작·최신작 비교:** 오래 활동한 작가는 기술이 뒤처졌던 시기의 작화에 사용자가 만족하지 못할 요소가 있을 수 있다. 구작과 최신작을 비교해 **양쪽 모두에 있는 기법은 중요도를 높이고**, 구작에만 있는 기법은 낮춘다. 작품 연도는 **그 장면이 실린 판본의 최초 방영·공개일**(사이트 게시일 아님).
3. **태그 보정:** Sakugabooru 태그는 사람이 달아서 빠진 것이 있다. 영상에 보이는데 태그가 없으면(예: 각진 다면체 파편인데 `yutapon_cubes` 없음) **근거 프레임 번호와 함께** 보정 항목으로 적는다. 사이트 자체는 고치지 않는다.
4. **귀속:** 작가 태그가 있어도 모든 컷을 본인이 그렸다는 증명은 아니다. `presumed`(추정) 표기 클립은 근거로 쓰지 않는다. 증명 등급: A 본인 게시 / B 공식·DB 크레딧 / C 커뮤니티 태그 / D 팬 귀속.

# 3. 지금까지 정리된 스타일 규칙 후보 (참고)

- **yutaka_nakamura 이펙트:** 그라데이션 대신 2톤·3톤 평면 + 날카로운 외곽이 많지만 '언제나 2톤'으로 고정하지 않는다. 각진 다면체 파편(yutapon cubes, 밝은 면·어두운 면), 셀 2톤 연기, 꺾인 번개 + glow, 진행 방향으로 늘어난 불티, 동심원 충격 링, 3톤 얼음 결정, 용암 균열 등.
