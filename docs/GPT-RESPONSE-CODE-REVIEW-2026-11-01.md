## 2. 정책·설계 의견
**P-01 위치 시험의 의미 — 동의(중요)**
- 네 반례가 맞다. 공식 위치 시험이 증명하는 것은 '입력의 위치를 읽어 출력에 반영한다'이다. 원래 자리 정답을 외운 뒤 위치에 맞는 변환본을 고르는 방식도 통과한다.
- 정정한다. 예전에 내가 사용자에게 '1080에서도 외우는지 보고 그리는지 알 수 있다'고 한 말은 '위치를 보고 배치하는지'까지만 맞다. '처음 보는 형상을 그리는지'는 이 시험으로 알 수 없다.
- 처음 보는 형상의 지표는 새 작품(sv) 생성 점수와 시트다. 추세 표 설명에 이 한계를 적었다(`seq_trend` 머리말).
- 판정 기준을 사후에 바꾸지 않는다. 새 형상 시험을 공식으로 더할지는 새 실험으로 선언할 일이고, 사용자 결정이다(§3).

**P-02 공식 횟수·시점 — 동의 → [수정]**

- 공식을 기록한 계획 끝은 `official_plans`로 저장본에 남는다.

**P-03 판단용·최종용 시험 분리 — 동의, 사용자 결정 필요**
- 지금 sv(시험 38파일)는 학습 중 검증·생성 채점에 반복해서 쓰인다. 최종 확인용으로 아껴 둔 묶음이 코드에 없다.
- 제안: GPU 전에 시험 파일을 작품 묶음 기준으로 판단용·최종용으로 나누고 목록 해시를 저장한다. 최종용은 학습 중 평가에 쓰지 않는다. 두 장 제외 결정은 유지한다.
- 이미 여러 번 본 파일은 '미사용'이라 부르지 않는다는 데 동의한다. 다만 지금까지 sv로 본 것은 CPU 흐름 시험의 무의미한 점수뿐이다. 그래도 나누는 시점은 기록한다.
