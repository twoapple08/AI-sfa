## 지금까지 확인된 사실(Claude 측정 — 숫자는 위 파일에서 대조할 것)
- 방식: Qwen2.5-VL-3B 4비트 + LoRA r16, 동작 = 키프레임마다 23토큰(간격·골반 x·y·몸통 크기 + 10뼈 각도·9뼈 길이 비율), 글 → 토큰, 이어 만들기(앞 키 3개를 주고 다음 조각).
- 자료: 스타일 층(nian41·나카무라 18구간, 학습 쌍 67) / 참고 층(수집 SFA 510구간, fps 정보 없음 — 저장 장이 키·트윈) / 3차에 HMDB51 328클립(실제 사람 24장/초)·좌우 뒤집기 추가 → 4,214쌍.
- 결과
  - 단계 4(글 → 자세 하나): 정상 자세 100%, 외우기 아님, 글 따르기 부분적.
  - 단계 5 1차(70분): 이음매 대부분 자연스러움, 그러나 길이 절반, 리듬 nian41과 멂. 사용자 앱 녹화로 보니 '걷기 → 달리기 → 펀치'가 걷기로 안 보임.
  - 원인 하나: 스타일 층 학습 글에 걷기 0회·달리기 9회. nian41·나카무라 영상은 싸움 작화 모음이라 실제 걷기·달리기 구간 8개뿐(눈 판정).
  - 2차(같은 자료로 150분 더): 평가 손실이 처음부터 계속 오름 = 과적합.
  - 3차(HMDB·뒤집기 추가, 학습 중 평가 손실·조기 종료): 평가 손실은 21% 낮아졌으나 생성은 더 멈춤(정지 조각 25–48%). HMDB 장 사이 자세 변화 중앙 0.02–0.08 몸통 vs 수집 SFA 0.26 → '조금씩만 바꾸기'를 배움. **평가 손실 ≠ 동작 품질.**
  - 생성 방식 비교: 조각마다 글 전체 + 정지 조각 다시 뽑기가 가장 나음. `<ref>`(참고 층 표시)를 붙이면 덜 멈추지만 리듬이 수집 SFA 쪽.
  - 실제 조각 잇기(compose, 모델 안 씀): 달리기·펀치는 글대로 보임, 걷기도 이동 조각 우선 뒤 걷기로 보임. 다만 창작이 아니고 같은 글이면 같은 결과.
  - nian41 리듬 입히기(retime): 리듬 차이를 0.44–0.50 → 0.04–0.16으로 맞출 수 있음(내용과 따로).
- 자원: Kaggle T4 ×2(새 계정 약 25시간 남음), 실행 위치는 서버 생성(휴대폰은 화면만, 임시 결정).

## Claude의 현재 의견(반박해 달라)
1. 지금 토큰 방식의 문제는 셋이 겹친 것으로 본다: (가) 손으로 정한 양자화 키 토큰이라 걸음 같은 주기 구조를 배우기 어렵다 (나) 출처마다 시간 단위가 달라(수집 SFA fps 없음 · HMDB 24장/초) '장 사이 변화'의 뜻이 섞인다 (다) 스타일 자료가 너무 적다(67쌍).
2. 후보 설계
   - A. 2D 동작 확산 모델(MDM 계열): 장마다 12관절 2D(골반 기준 + 골반 속도) 연속값, 글 인코더 조건, 길이 지정. 확산은 멈춤·반복 고착이 덜하다는 보고가 많다.
   - B. 학습된 동작 코드북(VQ-VAE) + 트랜스포머(T2M-GPT 계열): 손으로 정한 23토큰 대신 동작 구간을 압축한 코드.
   - C. 조각 검색 + 학습된 이음매·변형(compose 확장): 실제 조각을 고르고, 이음매와 작은 변형(속도·진폭·방향)을 모델이 만든다. 리듬은 retime.
   - D. 지금 언어 모델 유지 + 표현만 바꿈(장 단위 변화량, 시간 단위 맞추기).
3. Claude 추천: 당장은 C(이미 동작), 다음 실험은 A를 작은 크기로(서버 CPU 흐름 시험 → Kaggle 1–2시간). 공통 선결: 시간 단위 맞추기(수집 SFA 저장 장의 실제 간격을 움직임 속도로 추정하거나, 모든 자료를 '키 간격'으로 다시 뽑기).

## 부탁
1. 위 사실을 파일에서 직접 대조해 틀린 것·빠진 것을 지적해 달라(숫자·파일 경로로).
2. A·B·C·D 각각의 장단점을 이 프로젝트 조건(자료 양·2D 편집 가능한 11객체 스틱맨·nian41 리듬·T4 GPU 시간)으로 평가하고, 하나 또는 조합을 근거와 함께 추천해 달라. Claude 의견에 반대하면 근거로 반대해 달라. 합의가 안 되면 '미결'로 남기고 사용자 판정이 필요한 쟁점을 적어 달라.
3. 추천안의 가장 싼 첫 실험(무엇을·어떤 자료로·무엇을 재서 성공/실패를 가르는지 — 특히 '걷기로 보이는가'를 숫자로 가를 방법)을 구체적으로 제안해 달라.
4. 평가 기준: 평가 손실만으로 판단하지 않는다(3차의 교훈). 영상·장별 판정과 함께 쓸 지표를 제안해 달라.
