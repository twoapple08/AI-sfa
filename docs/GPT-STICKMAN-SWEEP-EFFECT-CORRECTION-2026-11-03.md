## 근거와 변경

**사용자 판정:** 재생106장 부근의 빨강 다리는 굽혀서 통과하는 것이 아니라 뻗은 채 빠르게 지나간다. 기존 near_miss_corrected 판의 다른 부분은 대체로 괜찮다는 피드백이다.

**파일·코드:** `scenes/nian41_1032-1271.json`만 수정했다. 원본1137–1138(재생106–107)의 부분 인물에서 골반·발목을 유지하고 추론 무릎을 중점으로 옮겼다. 기본11객체·머리 A안·흰 채움·Flags·AC·프로필·생성 코드는 바꾸지 않았다.

**CPU 계산:** 원본1116–1117에서 다리 객체는 모두 있었지만 관측이 한 지지 다리에 중복 배정됐다. 1116의 양 무릎 원관측은 (523.7,426.0)/(525.6,426.8), 발목은 (523.7,472.1)/(523.3,472.5)였다. 1117도 양 무릎 (523.0,433.5)/(528.0,436.5), 발목 (525.3,468.7)/(526.0,472.0)로 겹쳤다. 양쪽 모두 관측 가중치1이어서 낮은 가중치만 거르는 방식으로는 해결되지 않는다. 단순 객체 삭제 문제가 아니다.

**원본 눈 판독:** 원본1113–1120을 원래 화소 크기로 비교했다. 1116–1117에서 빨강의 허벅지는 골반에서 왼쪽 위의 흰 타격 이펙트 방향으로 이어진다. 이펙트가 달라져도 해당 인물 그림은 같은 자세다. 지지 다리는 아래로 남아 있다.

**추론:** 가려진 차는 다리의 무릎(485,365), 발목(450,350)을 두 장의 `tracks` 키로 보완했다. 끝점의 정확한 위치는 이펙트 때문에 판정할 수 없으며 접촉 정답으로 쓰지 않는다. feather1로 해당 두 장에만 적용한다. 지지 다리와 기존 접촉 제약은 유지했다. 다른 영상의 가림을 자동으로 해결한 것으로 확대하지 않는다. 새 장면에서도 같은 장면 설정 기능을 사용하며 이번 보완을 위해 뼈대 구조를 수정하지 않았다.
