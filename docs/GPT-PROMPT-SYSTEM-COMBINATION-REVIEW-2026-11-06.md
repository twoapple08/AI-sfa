GPT 추천은 기존 영상 생성기의 동작 지식과, SFA의 편집 구조를 지키는 우리 2D 맞춤/컴파일러의 결합이다. 현재도 motion-ir와 컴파일러가 분리되어 있으므로 그 분리 자체를 새 구현으로 제안하지 않는다.
LiveSVG는 목표 영상을 먼저 만들고 벡터를 맞추는 설계 근거이나 공식 실행 코드 링크를 확인하지 못했다. SFA 연결 보장도 없다.
ToonComposer는 키 스케치 제어와 공개 가중치가 있지만 공식 480p·61장 예시는 약57GB VRAM으로 T4에서 그대로 실행할 수 없다.
전체 조사와 사실/추론/미검증, 공식 링크, 단계별 시험 A/B/C는 위 보고서에 있다. 새 GPU·학습·유료 API·자료 수집은 하지 않았다.

사용자는 앞서 진동 → 가면 원근 → 걷기 출처를 순서대로 지시했다. 이어 구조 재검토를 요청해 해당 수정은 보류했으며 진동 원인을 새로 확인했다고 기록하지 않는다. 자료 캐시는 이 GPT 환경에 없고 rclone 인증만 복원했다(비밀값 비출력). 기존 자료를 먼저 재사용한다.

복귀 시 기간 커밋을 먼저 검토한다. 설계 채택 전 GPU를 실행하거나 정본 조건·기본 생성 경로를 바꾸지 않는다. 반대나 대안은 실제 코드·공식 자료·동일 조건 시험 결과로 설명한다.
