## 공통 장애

- **코드 경로 차이:** 네이티브 Java와 Flutter AOT가 함께 존재한다. 이번 영상의 렌더 경로 호출까지 연결되지 않아, 한쪽 식을 전체 앱 규칙으로 확정할 수 없다.
- **복원 한계:**
  - JADX 1.5.6 전체 처리에 62개 오류가 있고, 큰 렌더 함수에 제어 흐름 재구성 경고도 있다.
  - Java 분석이 Flutter 전체 복원이 아니다.
  - 오류 수만으로 나머지 소스의 정확성을 보장하지 않는다.
- **실행 피드백:**
  - 현재 작업에서 사용자 Android 앱을 직접 실행·조작하지 못했다.
  - 영상은 관찰 자료이지 내부 상태 추적 기록이 아니다.
  - 통제 실험이 필요해질 수 있으나, 지금 모든 샘플을 요청할 근거는 없다.
- **저장과 조작의 차이:** SFA의 결과 상태만으로 UI 선택·기준점·클릭 순서까지 유일하게 복원할 수 없다. 필요하면 조작 전후 근거를 추가해야 한다.
- **변수 혼재:** 실제 작품에서 좌표·객체 ID·채우기·색·글로우가 동시에 변한다. 단일 원인 판정에는 정적 추적이나 통제 실험이 필요하다.

- GitHub·기존 원본 접근은 이번에 성공했다.
- 사용자가 연결 설정·추가 작품 제공을 다시 해야 하는 상태가 아니다.
- 현재 가장 먼저 줄일 장애는 Flutter 렌더 경로 연결이다.
