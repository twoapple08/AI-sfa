**작업 C — 승낙 작가 자료 편입 절차 검토**
처음 받은 프롬프트 6절의 8단계 초안을 검토해 줘. 이번에 실제로 진행하면서 생긴 사정을 반영해야 해.
- 사용자 규칙: 섞인 프레임은 비중이 큰 쪽으로 분류하고 basis에 '섞임(연필 우세)'처럼 적는다(290900 157 사례).
- 셀 시대(1990년대) 단색 섬광을 "digital"로 부를지 사용자 결정을 기다리는 중이야.
- 하위 판독(같은 AI의 여러 에이전트) 결과는 표본 감사를 거쳐 병합했어.
- 연필 확정은 서로 다른 두 AI의 같은 프레임 판정이 필요해. 판정이 갈리거나 애매하면 사용자가 원 해상도로 최종 판정해.
- 이번에 드러난 위험: AI가 회차·연도·장면 내용을 지어낼 수 있음(정정 요청 1), 저해상도 시트에서 연필 결과 블러·잉크를 혼동함.

**검토 요청**
1. 단계 번호별 문제점과 개선안. 특히 회차·연도 검증 단계와 연필 확정 단계를 어디에 어떻게 넣을지.
2. 빠진 단계 추가안.
3. 위 6명 중 승낙될 가능성이 있는 yukina_kosaka(이펙트·연필 임팩트 한정)에 이 절차를 적용하면 첫 3단계에서 무엇을 하면 되는지 예시.

**출력:** 표(단계 | 문제점 | 개선안), 추가 단계 목록, yukina_kosaka 적용 예시. 승낙·반려는 사용자가 정하고 최종 절차 확정은 Claude가 해. 결과는 내가 Claude에게 전달할게.
