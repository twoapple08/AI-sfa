# GTX 1050 Ti(4GB) PC에서 동작 모델 추가 학습 돌리기 (2026-10-22)

서버 CPU에서도 같은 학습(3,000단계, 약 2시간)이 돌고 있다. PC GPU는 더 오래(1만 단계 이상) 돌리거나, 설정을 바꾼 두 번째 학습에 쓴다.

## 받을 것 (Drive `AI-sfa/07_도구/동작학습_1050ti/`)
| 파일 | 크기 | 내용 |
|---|---|---|
| momask_code.zip | 1MB | 동작 모델 코드(서버에서 numpy 2 호환으로 고친 판) |
| momask_checkpoints.zip | 188MB | 공개 기본 가중치(HumanML3D) |
| motion_data_mds.zip | 515MB | 학습 자료 4,297개(애니 471 + 모캡 4,000) — 원본 유래, 공유 금지 |
| ViT-B-32.pt | 354MB | 글 이해용 CLIP 모델(처음 실행 때 인터넷에서 받지 않게) |
| momask_finetune.py | — | 추가 학습 스크립트 |

## 순서 (Windows)
1. **파이썬 설치:** python.org에서 Python 3.11을 설치합니다. 설치 첫 화면에서 "Add python.exe to PATH"를 체크합니다.
2. **파일 받기:** 위 폴더를 통째로 받아 `D:\mm\`에 둡니다.
3. **압축 풀기:**
   - `momask_code.zip` → `D:\mm\momask-codes\`가 생기게 풉니다.
   - `momask_checkpoints.zip` → `D:\mm\momask-codes\` 안에 풉니다(`D:\mm\momask-codes\checkpoints\t2m\…`가 됨).
   - `motion_data_mds.zip` → `D:\mm\`에 풉니다(`D:\mm\mds\…`가 됨).
4. **CLIP 모델 넣기:** `C:\Users\<사용자이름>\.cache\clip\` 폴더를 만들고 `ViT-B-32.pt`를 넣습니다. 이 파일만은 D가 아니라 C의 이 위치에 둬야 프로그램이 찾습니다.
5. **명령 프롬프트(cmd)를 열고 설치합니다:**
   ```
   pip install torch==2.4.1 --index-url https://download.pytorch.org/whl/cu118
   pip install numpy scipy einops ftfy regex tqdm matplotlib openai-clip
   ```
6. **GPU 확인:**
   ```
   python -c "import torch;print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
   ```
   `True NVIDIA GeForce GTX 1050 Ti`가 나오면 됩니다.
7. **학습을 실행합니다:**
   ```
   cd /d D:\mm\momask-codes
   python ..\momask_finetune.py D:\mm\mds --steps 10000 --batch 16 --tag ft_anime_gpu --device cuda
   ```
   - `cd` 뒤의 `/d`는 다른 드라이브(D)로 옮길 때 꼭 필요합니다.
   - 메모리 부족(`CUDA out of memory`)이 나면 `--batch 8`로 다시 실행합니다.
   - 500단계마다 검증 손실과 '저장'이 화면에 나옵니다.
8. **결과 올리기:** `D:\mm\momask-codes\checkpoints\t2m\` 안의 `…_ft_anime_gpu` 폴더 두 개를 Drive `07_도구/동작학습_1050ti/결과/`에 올리고 알려 주세요.

## 공용 PC라면
- Google 계정 로그인은 파일을 받고 올릴 때만 하고, 끝나면 로그아웃합니다.
- 학습 자료(`mds`)와 결과는 원본 애니에서 나온 자료입니다. 다 올린 뒤 `D:\mm`을 지웁니다.
- 재부팅하면 지워지는 PC라도 로그아웃은 직접 합니다.
