# 기준 프롬프트 1 — 사용자 애니매틱(2026-10-23)

사용자가 글자 레이어("하늘"·"붉은 섬광"·"캐릭터"·"도시배경")로 직접 만든 느낌 표현 영상(13.2초, 60fps). "정확한 타이밍이랑 연출은 아니긴 한데 무슨 느낌인지 표현"(사용자). 원본: Drive `01_원본영상/사용자참고/bench01_사용자_애니매틱_2026-10-23.mp4`.

## 시간표(프레임 확인)
| 시각 | 화면 | 읽은 뜻 |
|---|---|---|
| 0.0–1.2초 | "하늘" 정지 | 하늘을 올려다본 채 멈춤(1.2초) |
| 1.2–1.4초 | 하늘 가운데 **아주 작은** "붉은 섬광" 글자가 잠깐 | 섬광은 화면 전체가 아니라 **먼 하늘의 작은 점 섬광**, 약 0.2초 |
| 1.6–2.5초 | 아주 작은 "캐릭터"가 천천히 커짐 | 먼 하늘에서 카메라 쪽으로 떨어지기 시작(아직 멀다) |
| 2.5–3.1초 | "캐릭터"가 빠르게 커짐 | 가까워지며 가속 |
| 3.2초 | 도시배경이 위아래로 **번진(모션 블러) 한 프레임** | 착지 순간 카메라가 **휙 내려옴**(약 0.1초의 빠른 틸트) — 천천히 따라 내려오는 게 아니다 |
| 3.3–7.5초 | "도시배경" 가운데 "캐릭터". 배경 글자는 점점 작아지고 캐릭터 크기는 그대로 | 착지 뒤 카메라가 뒤로 빠지고, 캐릭터는 같은 속도로 카메라를 향해 걸어와 **화면 속 크기가 일정** |
| 7.6–7.8초 | "캐릭터"가 화면을 꽉 채움(0.25초) | 순간이동 — 카메라 바로 앞, 펀치 |
| 7.85–13.2초 | 검정 | 암전(약 5초) |

## 지금 조립기와 다른 점
1. 섬광: 지금은 화면 전체를 빨갛게 → **하늘 속 작은 점 섬광**.
2. 낙하: 0.9초 동안 아주 작게 → 0.6초에 급격히 커짐(가속, 카메라 쪽으로). 지금은 처음부터 고르게 내려옴.
3. 착지 카메라: 지금은 낙하 내내 천천히 고개를 내림 → **하늘 고정 → 착지 순간 0.1초 만에 휙 내려옴(블러)**.
4. 걷기 구간: 지금은 카메라가 너무 멀어져 인물이 점이 됨 → **인물 화면 크기 일정, 배경만 멀어짐**(카메라가 걷는 속도로 함께 뒤로).
5. 펀치: 화면을 꽉 채우는 클로즈업 0.25초 뒤 바로 암전.
6. 착지 자세·일어서기·걷기→달리기 전환은 글자 애니매틱이라 표현되지 않음 — 원문 스토리보드를 따른다.
