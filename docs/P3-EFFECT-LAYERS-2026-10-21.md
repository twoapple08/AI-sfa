# P3 이펙트 층 분해 시제품 — 2026-10-21

도구: `tools/effect_layers.py` (AGENTS.md '그림 과정 그대로 그리기'). 원본 프레임·추출 형태는 저장소에 두지 않는다.

## 방법
- 층 순서: 밑색(불투명) → 명암(반투명 여러 겹) → 선(곡선 획). 모든 경계·선 = 2차 베지어(포물선 조각), 조각 수 상한 없음.
- 선: 회색조 블랙햇(7×7) > 28 이고 밝기 < 140인 가는 어두운 선 → 중심선 포물선 맞춤(굵기 포함).
- 밑색: 선 inpaint → 양방향 평활 → Lab k-평균(k) → 덩어리 색이 '밑색 + 흰색 또는 밑색×0.25 반투명 덮기'로 설명되면(BGR 거리 < 18) 같은 밑색으로 묶음.
- 명암: 밑색 B에서 S(흰색/어두운 쪽)로의 알파 a를 픽셀마다 구하고, 단계 0.12·0.25·0.4·0.55·0.7·0.85에서 '알파 ≥ 단계' 영역을 겹친다. 바깥(넓고 옅게) → 안쪽(좁고 진하게), n번째 겹 알파 = 1-(1-ℓn)/(1-ℓn-1) (누적 알파가 단계값).
- 검증: 층을 다시 그려 Lab ΔE.

## 남은 문제 (다음 작업)
1. 중간색(갈색 등) 일부가 아직 무채색 밑색에 합쳐진다 → 묶음 판정을 Lab 기준·덩어리 크기 가중으로.
2. 영역 경계의 얇은 틈(채우기 이음새) → 밑색을 1픽셀 넓혀 그리거나 경계 공유.
3. 불꽃 속 잔결 등 세밀한 질감 손실 → 밑색 영역 안에서 국소 k-평균(계층), 선 검출에 밝은 선(톱햇) 추가.
4. 배경과 이펙트를 아직 나누지 않음 → SAM 2(GPU)로 이펙트 영역만 분리한 뒤 분해.
5. 시간 축: 연속 프레임에서 층·조각 대응(추적)과 변형 수치.

## 2차 개선 (2026-10-21 밤)
- 합치기 기준을 Lab ΔE < 8로(BGR 거리는 갈색을 흰색의 어두운 명암으로 묶었다).
- 밑색 채우기에 같은 색 외곽선 2px(SFA: 채우기 + 같은 색 선)로 경계 틈 제거.
- 밝은 가는 선 층(톱햇) 추가: 불꽃 속 잔결·빛줄기 가장자리.

| 182904 불 | 8.84 → 7.49 | 20.03 → 17.56 | 13 |

육안: 틈 사라짐, 갈색 복원. 남은 문제: 검은 머리카락이 짙은 회갈색으로 옅어짐(검정 덩어리가 다른 밑색에 묶이거나 명암 단계 부족), 번개 빛줄기 대비 약함, 남은 문제 3–5(질감 계층·SAM 2 분리·시간 추적)는 그대로.

## 3차 개선 (2026-10-21 밤)
- 어두운 명암 목표를 밑색×0.25 → 검정, 단계에 0.95 추가(검은 머리카락이 회갈색으로 옅어지던 문제).
- k-평균 시작점 고정(cv2.setRNGSeed(0)): 같은 설정에서 ΔE가 실행마다 ±0.5 흔들려 비교가 불가능했다. 2차 수치는 이 흔들림을 포함한다.
- 15px 틀 시험: 어두운 선은 넓은 그림자를 선으로 잡아 악화(선 조각 483→1401), 밝은 선은 개선 없음 → 7px 유지.

## 8차 (2026-10-22): 건물 충격·창문 깨짐 시험에서 정한 임팩트 프레임 규칙(사용자 지적 반영)
시험: 사용자 건물 이미지 1장 → 건물 전체에 충격, 창 109장이 깨지는 SFA(서버 렌더 미리보기만, 저장소에 넣지 않음).
- **바탕:** 강조가 흰색이면 프레임 바탕을 검정, 강조가 검정이면 흰색으로 둔다. 화면을 덮는 큰 바탕 면을 그리지 않는다(프레임 BackgroundColor 사용).
- **충격 범위:** 건물 전체가 맞는 장면이면 한 지점에서 퍼지게 하지 않는다. 창은 거의 동시에(0–1프레임) 깨진다.
- **임팩트 흐름(모브사이코 1기 #8, 272649 655–663, 나카무라):** 그림마다 빛의 상태가 바뀌어야 번쩍인다. 같은 구성을 여러 장 반복하지 않는다. 그림 하나는 대부분 1프레임(첫 장만 2).
  검정 → 흰 바탕·건물 전체 목탄(층 모서리만 흰 띠, 그 아래 검은 결이 늘어짐) → 건물이 밝아짐(층 아래 그늘만)·하늘 목탄 시작 → 하늘 짙어짐·건물 옆 빛 → 검은 바탕·건물 가운데 띠만 흰빛(위아래 먹힘) → 컬러로 돌아와 모든 창에서 흰 섬광(깨지는 순간) → 검정 → 유리 조각.
  중간에 그림 없는 단색 장을 끼우지 않는다(처음·끝 검정은 허용).
- **연필(목탄) 느낌:** 그린 그림을 다시 층 분해하면 결이 짧은 불투명 조각으로 쪼개져 자글자글해진다 → SFA로 바로 그린다. 옅은 농담 면 몇 겹(겹치기 방식) + 가늘고 반투명한 획 수천–1만 개 이상(짙은 곳일수록 많고 진하게), 굵은 획 일부는 끝이 가늘어지는 띠. 촘촘함이 부족하면 연필로 보이지 않는다.
  판정 '맞음' 연필 임팩트(연필 진하기 3, 24장)의 공통점: 회색 면보다 흰 종이를 넓게 남기고 짙기는 획 밀도로, 화면 가장자리에서 빛 쪽으로 모이는 방사 해칭, 빛 근처는 하얗게 먹힘.
- **SFA 글로우로 빛 번짐을 그리는 방식은 쓰지 않는다**(사용자 평가: 덜 예쁨). 반투명 겹치기 방식 유지. 글로우는 `fx_impact_book.py --glow` 선택 사항으로만 남김.
- **유리 파편:** 건물이 흑백이면 파편도 무채색. 감속곡선: 깨지는 순간 3–4프레임에 거리 대부분을 튀고('빡!') 뒤는 아주 느린 표류(지수 감속). 빛은 옅은 번짐 한 겹 + 흰 십자 반짝임(과하지 않게). 먼지는 슬로우 장면에서 뺀다. 기본 선 굵기는 얇게(분해 굵기의 절반).
