## 기술 정착

- 고정 뼈대/생성기는 유지했다. 가림·부분 인물·빠른 다리·접촉/회피는 기존 장면 JSON으로 관리한다. `docs/STICKMAN-EXTRACTION-V1.md`에 새 장면 절차와 자동/수동 범위를 명시했다.
- 새 `tools/stickman_quality.py`: 기존 임시 검사 스크립트를 재사용 가능한 CLI로 정리했다. 구조 오류는 종료코드1, 가속도/중복 사슬은 눈 판독 후보로 분리한다. 빠른 동작·틀 밖 좌표 자체를 오류로 만들지 않는다. 수정 전1116 빨강 다리를 겹침 후보로 찾아내고 수정 후에는 해당 후보가 사라지는 반례 대조를 했다.1117까지 모두 자동 적중한 것으로 확대하지 않으며 앞뒤/같은 그림 확대 검토를 절차에 넣었다.
- 새 `tools/stickman_finalize.py`: 재피팅 없이 해시 고정 투영 SFA + 장면 JSON + 필요한 경우 구버전 가림 근거를 재적용한다. 입력 덮어쓰기/잘못된 입력 해시/가림 원본 해시 불일치를 거부하고 실제 저장 정밀도로 검사한 뒤 저장한다.
- 동일 좌표라도 곱셈/나눗셈 순서 차이로 네 장의0.0001% 반올림 차이가 생긴 첫 재현 시도는 실패로 처리했다. 변환 순서를 통일한 뒤 최종240장 XML 전체가 기존 전달본과 일치했다. 전체 새 피팅 동일성까지 검증한 것은 아니다.
- `.claude/skills/stickman-extraction/SKILL.md`에 시작·추출·후보 수색·원인 측정·장면 보완·재생성·회귀·전달 절차를 저장했다. Claude Code용 저장소 스킬이며 다른 Claude 환경도 직접 읽을 수 있다. 외부 계정의 스킬 설치는 수행하지 않았다.
