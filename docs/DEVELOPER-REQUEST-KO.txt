APK의 Android 네이티브 코드와 Flutter 처리 사이의 차이 때문에 아래 네 부분을 확정하지 못했습니다. 공개 가능한 범위에서 동작 설명, 의사코드 또는 관련 함수/소스 일부를 알려주실 수 있을까요? 전체 프로젝트 소스나 서명키, 사용자 데이터는 필요하지 않습니다.

우선 확인하고 싶은 공통 질문:
51.0.0에서 실제 MP4 내보내기용 프레임은 Flutter 렌더러가 만드는지, Android 네이티브 Canvas 렌더러가 만드는지, 또는 설정/기능에 따라 두 경로를 선택하는지 궁금합니다. 편집 표시·앱 재생·영상 내보내기 사이에 다른 렌더 규칙이 있다면 그 차이도 알고 싶습니다.

1. 채우기·구멍·그리기 순서

- 채우기와 도형의 LayerId/DrawOrder/FR 목록 순서는 어떤 우선순위로 합성되나요?
- Flutter와 네이티브 처리의 차이가 있나요? 네이티브에서 Contour를 다루지 않는 듯한 경로를 관찰했지만 실제 호출 여부는 확인하지 못했습니다.

2. 글로우 강도·범위·합성

- shaders/glow.frag의 uniform 설정과 shader/raster/mask-filter 선택 조건을 설명해 주실 수 있나요?

3. 트위닝·생성/삭제·채우기 대응
