## A 구간 특징 — [측정]
- 매 장 사람이 2명이다. 파란 인물은 상자 안 색 비율로 골랐고, 1496–1527 전 장에서 파란 인물이 골라졌다(눈 확인).
- **2컷 작화:** 새 그림 장의 관절 이동/몸통은 0.29–2.4, 멈춘 장은 0.01–0.13이다. 인물이 작아(몸통 33–65px) 멈춘 장의 RTMW 잡음이 B(0.007–0.016)보다 크다.
- 몸 방향이 여러 번 바뀐다. 어깨 좌우 x차 부호가 1507·1509·1515·1523에서 뒤집힌다. 좌우를 바꾼 쪽 이동이 더 작지 않아, 단순한 RTMW 좌우 바뀜이 아니라 실제 몸 돌리기로 본다(추정).
- 뺀 점은 기존 판정(docs/CLAUDE-RTMW-REVIEW-2026-11-02.json)을 따랐다: 1508 팔 7–10·다리 13–16, 1516 6·8·10, 1518 5–10.

## 결과 — [측정]
- A: 잔차 RMS/몸통 장별 중앙 0.380. 키포즈 시각의 잔차는 0.07–0.21(13키)이다.
  - 장별 잔차가 큰 것은 그림 하나에 몸통 1.5배 넘게 움직이는 장면을 보간해, 멈춰 있는 원본과 시간이 반 장씩 어긋나서다. 키포즈 자체의 맞음은 B와 비슷하다.
- A 가속도/몸통 중앙 0.266. 빠른 동작이라 B(0.016)와 직접 비교할 값이 아니다.
- B를 새 기본값으로 다시 돌린 결과(같은 13구간): 잔차 0.107, 가속도 0.016(시제품 3은 0.107·0.013). 사용자 판정을 받은 시제품 3 파일은 바꾸지 않았다.
- [Claude 눈, 작은 시트] 달리기 → 도약 → 공중 발차기 흐름이 이어진다. 인물이 작아 세부는 원본 크기 영상으로 판정해야 한다.

## 여자 캐릭터·작품별 비율 대비(사용자 지시, 설계 메모 — 아직 구현 안 함)
1. **인물 리그는 장면이 아니라 인물 단위로 모은다.** 같은 인물의 여러 장면(정면·옆·뒤)에서 뼈마다 상위 분위를 모으면 원근 단축이 빠진 길이에 가까워진다. 장면 하나로 정한 길이는 '장면 리그'로만 쓴다.
2. **틀을 강제하지 않는다.** 지금 방식처럼 길이는 관측에서 재고, 기본 스틱맨이나 남성 비율을 기준값으로 두지 않는다. 여캐는 어깨 폭 < 골반 폭, 긴 다리, 가는 허리처럼 비율이 크게 다를 수 있다.
3. **RTMW 관절 자체가 어긋날 수 있다.** 실사로 학습한 모델이라 치마·긴 머리·과장된 비율에서 엉덩이·무릎 위치가 틀릴 수 있다. 새 인물·작품마다 대표 장 몇 장의 관절 확인(사람 또는 GPT 눈)을 먼저 하고, 틀린 점은 빼는 규칙을 쓴다(B·A와 같은 방식).
4. **뼈대 구조가 다를 수 있다.** 치마·망토로 다리가 가려지면 다리 뼈를 관측할 수 없다. '관측 없음 + 이웃 키 보간'으로 처리하고, 가려진 구간이 길면 사용자에게 키포즈 지정을 부탁한다.
5. 검증 순서: 여캐 장면 하나를 골라(사용자 지정 또는 후보 제시) 같은 도구로 돌리고, 비율표·관절 확인 그림을 먼저 보여 준다.
