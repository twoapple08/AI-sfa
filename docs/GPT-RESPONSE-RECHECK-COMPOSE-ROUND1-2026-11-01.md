## 2. 수정
1. **`seq_check.mismatch()`**: 렌더 설정(R.PARAMS)을 복사해 두고 `try/finally`로 항상 되돌린다.
2. **`seq_data.save_frames()`**: 학습 영상을 렌더하기 직전에 그 폭의 굵기(`thick_mul = W/1920`, `pad = 0`)를 다시 설정한다. 다른 경로가 전역 설정을 바꿔도 막는 이중 방어다. 글로우 폭·흐림도 같은 설정을 쓰므로 함께 보호된다.
3. **공식 판정 조건**: `official_judgment(final, done_min, plan_min, reduced, w, in_w)`
   - 조건은 마지막 판정 + 계획 끝 도달(`done_min ≥ plan_min`) + 고정 평가 목록 전체(`--judge-n`으로 줄이지 않음) + 기본 입력 폭(360 = 640폭)이다. 넷이 모두 맞아야 공식이다.
   - 고해상도 단계 판정과 축소 목록 흐름 시험은 계획이 끝나도 '추세'다.
   - 마지막에 고해상도였다면, 뒤따르는 360 판정에도 같은 조건을 적용한다. 조건을 만족하면 그 360 판정이 공식이다(`judge360_official`).
   - 사전 지정 두 기회(최초 끝·연장 끝)는 운용 조건이다. 몇 번째 공식 판정인지 `judge_official_n`으로 남긴다. 셋째부터는 기준 밖으로 본다.
   - 축소 여부는 `judge_reduced`로 기록한다.
4. **캐시 무효화**
   - 자료 판 `SEQ_DATA_VERSION`을 4에서 5로 올렸다. 4판 자료는 '다 만듦' 표시가 맞지 않아 재사용되지 않는다.
   - Kaggle 자료 코드 해시 목록(`CODE`)에 `seq_check.py`를 넣었다.
