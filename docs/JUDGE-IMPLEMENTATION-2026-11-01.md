## 판정 계산
- 양방향 Δ와 파일(묶음)당 한 표
  - 양방향 Δ = [(S(P1,G1)−S(P2,G1)) + (S(P2,G2)−S(P1,G2))]/2다. S는 위치·형상 부분 점수(0–100)다.
  - 묶음 안에서는 Δ를 평균해 한 표로 센다.
- **동점 범위 |Δ| ≤ 0.5점**
  - 판정 기준에는 '사전 오차 범위'라고만 되어 있어 Claude가 제안했고, **사용자가 첫 판정 전에 확정했다(11-01)**.
  - 결과를 본 뒤에는 바꾸지 않는다.
  - 생성은 탐욕적이라, 같은 출력이면 Δ가 정확히 0이 된다.
- 부호 검정 규칙
  - 동점은 이긴 것으로 세지 않는다.
  - 평가 실패(OOM)도 이긴 것으로 세지 않고, N에서 빼지도 않는다.
  - 고정 N으로 단측 이항 꼬리를 계산하고, 승/동점/패/실패, p, 필요 승수를 기록한다.
- 효과 크기
  - 묶음별 Δ의 중앙값과 평균을 기록한다.
  - 합산 차이(맞는 입력 점수 평균 − 바꾼 입력 점수 평균)도 기록한다.
- 건전성
  - 대상은 정답이 비어 있지 않은 장이다. '빈 출력 ∪ 길이 한도 미완료'가 ⌊10%·n⌋장 이하여야 한다.
  - OOM은 재시도하지 않았다면 실패로 센다.
  - 오브젝트 수 비율의 중앙값과, 0.5–2 범위 밖 장 수를 기록한다.
- 보조 지표
  - A = 옮긴 정답 대비, B = 원래 자리 정답 대비, A−B를 기록한다.
  - 외움 기준선은 이 목록·방향으로 다시 계산한다(+5점은 참고선).
  - 엄격 점수: 재현율, 정밀도, 합산 F1 `2Σmatch/(Σpred+Σans)`, 파일별 F1 평균.
- 4방향 진단: 16칸 표(행 = 정답 방향, 열 = 입력 방향)와 축별 Δ를 기록한다. x만 다른 쌍은 (0,3)(2,1), y만 다른 쌍은 (0,2)(3,1)이다. 공식 합격 기회는 아니다.
- 생성 시간: 실제 생성 초를 출력 길이 셋으로 나눠(짧은·중간·긴) 중앙값과 합계를 기록한다.
- 현재 단계 해상도 대 기본 입력
  - 고해상도 단계일 때 평가 목록 앞 6장을 비교한다. 방향 0을 단계 해상도(1920·1280·854)로 생성한 점수와 기본 입력 점수를 나란히 기록한다.

## 채점기 원 수정(판정 기준 §4) — 같은 날 이어서 완료
`tools/sfa_objscore.py`를 고쳤다. 렌더러(`sfa_render.py`)는 면 경로를 T 값만으로 그리고 StartPtId/EndPtId는 쓰지 않는다. 그래서 원 조각은 위상과 길이로만 비교한다.

**바뀐 규칙**
- **원 부분 면**
  - 원마다 δ=(θP0−θA0)/(2π·circ_dir)를 구한다. θ는 화면 화소 비율 좌표에서 첫 점의 각도이고, circ_dir는 1이다.
  - AI 구간은 ((tP0+δ) mod 1, tP1−tP0), 정답 구간은 (tA0 mod 1, tA1−tA0)로 바꿔 비교한다.
  - 허용 오차는 0.002바퀴이고, 위상은 원형 거리로 잰다.
  - 끝점마다 mod를 하지 않는다. 그래서 0→1과 0→2, 0.9→1.1과 0.9→0.1이 구분된다.
  - 지름 두 점을 맞바꾸면 +0.5바퀴로 대응한다. 직선용 1−T 변환은 원에 쓰지 않는다.
- **WHOLE 원**
  - 윤곽에 조각이 하나뿐인 독립 닫힌 원일 때만 방향을 무시한다.
  - 복합 윤곽 안 WHOLE 원은 0→1 구간으로 보고 δ를 적용한다.
  - 복합 윤곽 안 직선·곡선 WHOLE은 점 방향이 뒤집혀 있으면 보수적으로 틀림 처리한다(새 규칙).
- **각도 불안정**: 반지름이 0.001% 미만이거나 점이 모자라면 면 대응을 틀림 처리한다(보수 처리).
- **perfect의 원 비교**: 원은 점 대신 중심·반지름이 같은 칸(반 칸 이내)인지 본다. 면 없는 원의 지름 회전은 영상이 안 바뀌기 때문이다.
- **면 비교 방식**: 튜플이 정확히 같은지 보던 방식을, 조각마다 허용 오차를 둔 비교(`fill_eq`)로 바꿨다.

**확인**
- **반례 시험 10개**(GPT 3차 §2 목록, `tests/test_sfa_objscore.py` CircleFillTest)는 모두 통과한다.
  - 옛 채점기로 돌리면 9개가 실패한다. 조각 순서 시험(8번)만 원래부터 맞았다.
- **렌더 화소 대조**(서버 렌더러, 640폭, 채널 차이 24 초과 화소 수)

  | 경우 | 채점기 판정 | 화소 차이 |
  |---|---|---|
  | δ로 옮긴 부분 면 | 같음 | 0 |
  | 같은 T로 회전 | 다름 | 250 |
  | 지름 교환 +0.5바퀴 | 같음 | 0 |
  | 지름 교환 1−T | 다름 | 250 |
  | 비율 0.45·0.5625 비스듬한 지름 | 같음 | 0 |
  | −0.1→0.1 대 0.9→1.1 | 같음 | 0 |
  | 0.9→1.1 대 0.9→0.1 | 다름 | 2,437 |
  | 복합 윤곽 WHOLE 원 교환(GPT 반례) | 다름 | 3,804 |
  | 단독 WHOLE 원 회전 | 같음 | 0 |
  | 면 없는 원 회전 | 같음 | 0 |

  채점기 판정과 화소 결과가 모두 일치했다. 다만 이것은 서버 렌더러 기준이고, 앱에서 다시 열어 본 확인은 아니다.
- **실제 파일 자기 채점**(정답을 정답과 채점, 2,048토큰 이하 장): 바뀐 채점기로도 모두 만점이다.
  - 평가 목록 46장과 학습 파일 40장, 합계 86장: 만점 아님 0.

  - 처음에는 학습 파일 4개 중 1개 × 5장으로 돌렸으나 900초 시간 초과로 결과를 얻지 못했다. 2,048토큰 넘는 큰 장이 섞였던 것으로 보이며, 범위를 줄여 다시 확인했다.
- **영향 범위**: 위치·형상 부분 점수(판정 장치의 S)는 면을 보지 않으므로 바뀌지 않는다. 바뀌는 것은 면 F1과 perfect다.
