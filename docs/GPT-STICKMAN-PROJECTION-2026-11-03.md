## 사용자 지시

제시한 두 시트는 예시다. 전체 구간에서 같은 문제를 확대 점검한다. 자세·구도·각도·가림에 따라 신체가 짧거나 길어 보이면 출력 길이를 바꿔도 된다. 고정 길이 때문에 포즈가 꼬이지 않게 한다. 고개 숙임은 사용자 녹화의 방법을 따른다. 모든 스틱맨 머리 내부를 흰색으로 채운다. 사용자가 “아직 시작하지 말라”고 한 뒤 추론 수준 상담을 거쳐 “ㄱㄱ”로 실행을 지시했다.

## 확인한 공통 원인 — 파일·코드

1. 기존 피팅은 장별 배율×컷별 고정 리그 길이를 쓴다.
2. 기본 스틱맨 변환은 목→팔꿈치·골반→무릎 길이를 다시 전 장 중앙값·좌우 평균으로 강제한다.
3. 머리 방향·위치는 몸통 연장으로 정해져, 얼굴이 몸통 앞쪽으로 내려가는 고개 숙임을 별도로 표현하지 못했다.
4. 어깨·골반 중점을 공통 허브로 만들 때 원래 뻗은 사슬도 꺾일 수 있다.

이를 개별 장의 좌표 패치로 처리하지 않고 새 투영 모드를 만들었다.

## 구현

- tools/stickman_projection.py: 키마다 유효 축의 관측 평균과 기존 피팅의 차이를 구해 PCHIP으로 보간한다. 완전히 가려진 축은 기존 풀이를 남긴다. 관측 구간 밖으로 보정량을 연장하지 않는다.
- 어깨·골반은 중점 허브, 팔꿈치·손목·무릎·발목은 화면 위치를 우선한다. 위팔·허벅지의 고정 비율 재정규화를 하지 않는다. 길이 변화가 허용된다.
- 원래 거의 직선인 사슬은 새 허브 때문에 다시 꺾이지 않도록 중간점을 허브–끝점 선으로 보정한다. 보간된 원래 사슬 직선도 0.98–1.00에서 연속 가중하며, 완전 관측 사슬에만 적용한다. 모든 무릎을 펴는 규칙은 아니다.
- 얼굴: 유효 귀 두 점 → 눈 두 점 → 코 순서로 키별 중심 후보를 얻는다. 검출 점수는 확률로 해석하지 않는다. 결측 장의 이웃 복사 얼굴을 관측으로 세지 않는다. 얼굴 키가 없는 컷은 기존 몸통 연장 위치다.
- 보고의 고정 피팅 잔차는 fixed_fit_rms_resid_torso_median으로 분리했다. 새 출력은 유효 축별 팔다리 끝점 RMS/몸통 중앙값(projection_endpoint_axis_rms_torso_median)으로 별도 기록하며 두 정의를 섞지 않는다.
- 머리 지름은 기존 몸통 배율×8.4/11.2를 유지하고 중심 위치만 바꾼다. 사용자 녹화를 추출해 원의 독립 이동·몸통과의 겹침을 확인했다. 모든 얼굴 좌표가 검증됐다는 뜻은 아니다.
- 머리 원의 두 점을 몸통 목과 독립시킨다. 투명 연결선으로 머리 아래 점과 목을 이어 파란점은 인물당 하나·편집 연결망도 하나로 유지한다. 내부는 11오브젝트, 보이는 기본 조각은 10개다.
- 머리 원의 흰 FR 채움과 앞쪽 그리기로 머리 뒤 몸 선을 가린다. 실제 렌더 픽셀에서 흰색 가림을 시험했다. 다른 인물과의 앞뒤 관계까지 추론하는 가림 모델은 아니다.
- 도구: stickman_clip.py --projection. 생략하면 기존 길이 풀이를 쓴다. 흰 머리 채움은 양쪽 모두 적용한다.

실행 예:
```
python tools/stickman_clip.py RTMW.jsonl.gz 원본.mp4 출력.sfa --start 1032 --end 1271 --cuts 1136 1234 --crop-y 63 --projection --key-start blue:1038 blue:1088 blue:1253 red:1038 --thick-ref 40:blue:1.0 120:red:5.0 --report report.json --joints joints.json
```

네 추가 경계는 원본 대조용 후보다. 기존 확인 경계 JSON을 수정하거나 자동 검출이 해결됐다고 기록하지 않았다. 이번 새 모드와 함께 평가할 비교 설정이며 길이 변화만 분리한 실험은 아니다.

## 확대 검사 — CPU 계산

사슬 직선도 = 뿌리–끝 거리 / 두 마디 길이 합. 원본 RTMW가 완전 관측이고 직선도≥0.98인 사슬을 골랐다. 출력 직선도<0.90을 접힘 후보로 센다. 이 수치는 실제 작화의 정답 판정이 아니다.

|---|---:|---:|---:|---|
| 파랑 | 193 | 26 | 9 | 0.9892→0.9999 |
| 빨강 | 233 | 25 | 11 | 0.9880→0.9999 |

기존 후보 34건은 해소됐고, 빨강 1201 오른팔·1237–1238 왼팔 3건은 새 후보가 됐다. 합계 51→20만 보고 전부 개선됐다고 말하지 않는다.

남은 20건은 키 평균부터 접힌 7건, 키 중간 시각 보간·허브 처리 추적이 필요한 13건으로 나눴다. 장별 키 구간·원본/키 평균/출력 직선도는 data/stickman_motion/projection_review_2026-11-03.json에 있다. 단일 임계값이 원인을 증명하는 것은 아니며, 후보 그룹을 나눈 근거다.

머리나 신체의 모양을 일괄 정답으로 승인하지 않는다. 관측 오검출·가림·빠른 보간 구간이 남아 있어 사용자 영상 판정 전 기준판 승격은 보류한다.
