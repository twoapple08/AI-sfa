### 방향과 표시 폭의 분리

`tools/sfa_flow_smear.py`:

- `local_motion()`은 관절 이동 + 회전 접선 +2D 부위 길이 변화를 사용한다. **꺾임 방향용** 추정2D 속도다. 실제3D/완전한 카메라 복원이 아니다.
- `motion_extent()`는 물리 속도 크기에 공통 배율을 적용하는 함수로 보존했다. 점별 하한/상한은 제거해 순수 회전의 `v=rω` 비율을 망가뜨리지 않는다. 평행 이동의 속도 자체는 일정한 것이 맞다.
- **`display_extent()`는 별도 표시 규칙**이다. 부착된 비축방향 팔/다리의 표시 폭은 `말단의 폭 × 관절→말단 위치비율(r)`로 정한다. 기본 외곽이 r=0/.25/.5/1에서0/.25/.5/1이 된다. 평행/혼합 이동도 안쪽은 좁아진다.
- 위 비율은 불균등 위상과 밀도 보강 전의 기본 표시 외곽이다. 모든 픽셀/개별 점이 단조 증가한다는 뜻은 아니다. 앞뒤 기본58:42도 계수이며 점별 픽셀 비율을 고정하지 않는다.
- 떠 있는 효과 및 작은 손목/발목 축방향 후보는 진행 좌표가 관절→말단 좌표와 다르므로 동일 테이퍼를 강제하지 않는다. 특히 앞뒤3D 움직임을 알아냈다고 주장하지 않는다.
- 표시의 시작 위치는 관절에서6%다. 원래 왕복쌍은 같은 반경에 두어 밀도 보강 뒤 안쪽 꼭짓점이 반경 방향으로 밀려 보이는 문제를 줄였다.

### 밀도 규칙을 되돌리지 말 것

`tools/smear_density.py`, `tools/smear_rail_fit.py`, **`profiles/smear_density_v1_1_reference.json`**을 사용한다. `smear_density`의 일반 CLI 기본값인v1로 잘못 돌아가지 않는다.

1. **새로 정의한 주요 꺾임점은 고정**, 벌어진 구간에 왕복 자동 추가. 원래 v18의 옛 AP 좌표까지 고정했다는 뜻은 아니다.

## 6. 현재 작업에 이식하는 순서

1. 진행 중인 Claude 작업/현재파일/리그 차이를 먼저 확인하고 보존한다. 이 문서 때문에 이전v18로 통째로 교체하거나 스미어 탐지를 처음부터 다시 시작하지 않는다.
2. 읽기 자료를 확인한 뒤 권장 추론 수준을 알린다. 문서/현재 차이 확인은Medium, 실제 기하 이식·불일치 해결은High를 권장한다.
3. 최신 비교의3/4번과 코드를 확인해 **방향/표시 폭/앞뒤 분배/밀도**를 별도 단계로 유지한다. 최신 Claude 생성기에서 해당 단계만 옮긴다.
4. 기존 몸/머리FS/의상·가면·글로우/선두께를 보존하고, 평행 이동과 관절이동이 섞인 회전에서도 안쪽 테이퍼가 나오는지 비교한다. 불확실 효과는 억지로 만들지 않는다.
5. 방향·밀도·보존 검사 후 기존/수정 SFA와 영상/확대를 제공한다. 원본참조가 필요한 탐지 의미문제와 이번 표시기하를 분리해서 보고한다. 실제 앱/편집 추종 검증은 실제 확인했을 때만 완료로 기록한다.

재현만 필요한 경우, 테두리 없는 원본XML을 읽어 `sfa_flow_smear.build(source, profile=json.loads(Path('profiles/smear_density_v1_1_reference.json').read_text()))`, 이어 `sfa_outline_trial.build(result, mode='glow', color=0xff303030)`을 적용한다. ZIP의XML을읽고`review.xml`로저장하면된다. 원본/결과/진단은 저장소 밖 새 비공개 폴더에 쓴다. 실제코드는Git의현행본을우선하며오래된ZIP코드로최신작업을덮어쓰지않는다.
