# 임팩트 판정에 앞뒤 문맥 넣기 + 재검사 291건 재분류 (2026-10-19)

모델 훈련은 하지 않았다(고전 영상 처리 규칙 + Claude 육안 판독). [실측]은 계산·건수, [추론]은 육안 판독이다.

## 1. 문제와 원리

- 사례: `optical-core/32488` f120–122. 청록 바탕 해골 얼굴 → 얼굴을 당겨 화면 대부분이 **얼굴 면색(밝은 회색)과 남색 선**이 됨 → 다시 청록 바탕.
  - 기존 지표(무채색도·고대비 비율·X-CLIP)는 이 프레임을 '흑백 삽입'으로 봤다.
  - 실제로는 문맥에 있던 색이 **면적만 커진 것**이다.
- 원리: 임팩트는 흐름을 끊고 **다른 그림 방식**으로 끼워 넣은 프레임이다.
  - 클로즈업·줌·카메라 이동·동화는 앞뒤 문맥의 면 색·선 색을 그대로 쓴다.
  - 그래서 면적 비율이 아니라 **"후보가 쓰는 색이 앞뒤 문맥에서도 쓰이던 색인가"**를 잰다.

## 2. 새 도구 `tools/impact_context.py`

- 문맥: 후보 앞 3–12번째 프레임(앞쪽)과 뒤 3–12번째 프레임(뒤쪽). 바로 붙은 2프레임은 전환·잔상이 많아 뺀다.
- 쪽마다 '주된 그림 방식' 색표를 만든다.
  - 면 색: 그 쪽 프레임의 40%를 넘는 프레임에서 화면 1% 이상을 차지한 색.
  - 선 색: 주변보다 어두운 국소 최저 화소의 색.
  - 옆에 다른 임팩트·섬광이 몇 장 있어도 과반이 아니면 색표에 들어가지 않는다.
- 후보의 면·선 화소 중 색표에 없는 색(Lab 거리 18 초과) 비율을 잰다(`pre_fill`·`post_fill`·`pre_line`·`post_line`, 최대값 `nov_max`).
- **same_style = 1**(같은 컷의 같은 그림 방식 → 아님 쪽)은 다음을 모두 만족할 때다.
  1. `nov_max < 0.3`
  2. 앞뒤 두 쪽 모두 계산됨
  3. 후보 프레임이 전부 그림 있음(단색 번쩍임은 비교가 성립하지 않아 기존 규칙에 맡긴다)
  4. 흑백 두 색 실루엣이 아님(`bilevel ≥ 0.05` 이면서 `dark_solid ≥ 0.15`이면 제외)
- 4번 조건은 육안 대조에서 생겼다.
  - 셀 시대 화면처럼 문맥에도 크림색·검정이 있으면, 흑백 실루엣 삽입(163174·258730·141149)이 '같은 색'으로 잡혔다.
  - 검은 덩어리(7x7 침식 뒤에도 남는 어두운 면)와 밝은 면이 함께 크면 제외한다.
- 시험했으나 뺀 것 [실측]:

  | 방법 | 결과 |
  |---|---|
  | X-CLIP에 '앞 문맥+후보+뒤 문맥' 창과 '같은 장면 클로즈업' 반대 문구 | AUC 0.54(변별력 없음) |
  | 면적 기반 무채색·고대비 증가량 | 줌에서 오판(32488 고대비 증가 0.25) |
  | SIFT 특징점 정합 수 | AUC 0.45–0.65 |
  | 색 분포 급변으로 컷 경계 자르기 | 줌 프레임까지 잘라 문맥이 줄어듦 |

  - 놓친 예: 회색 연기 와이프, 같은 장면 빛 십자, 컷 전체가 실루엣 연출로 이어지는 159418.
