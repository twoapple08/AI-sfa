# 기능별 시험 파일 v1 — 앱 출력 1차 비교 완료

이 자료는 **전체 기능 분석 완료본이 아니다.** 현재까지 저장 표현을 파악한 항목을 각각 분리해서 검사하는 1차 시험이다. 좌표 변경으로 표현한 이동/회전/늘리기/뒤집기/크기는 앱의 실제 편집 버튼 계산식을 복제했다는 뜻이 아니다.

## 파일

- `examples/probes_v1/feature_probes_v1.sfa`: 16구간 합본, 원본 768프레임.
- `examples/probes_v1/feature_probes_v1.zip`: 합본 + 16개 개별 SFA + manifest.
- `examples/probes_v1/manifest.json`: 기대 결과, 원본 프레임 구간, 미검증 항목.
- `build_feature_probes.py`: 재생성 코드. 원본 앱 코드나 사용자 작품을 복사하지 않고 단순 시험 도형을 생성.

## 먼저 확인할 설정

1. 합본을 현재 Stick Fighter 51.0.0에서 가져온다.
2. **(트위닝 FPS, 재생 FPS) = (24,24)**로 직접 맞춘다. SFA가 이 설정을 전달한다고 가정하지 않는다.
3. 이 설정이면 각 구간 2초, 전체 32초가 목표다. 기본값이 (60,12)로 들어오면 설정을 바꾼다.
4. 화면에 구간 이름을 넣을 텍스트 도형은 확인하지 못했으므로 아래 시간을 기준으로 구분한다.
5. 영상 내보내기는 비교용이다. 출력 영상과 UI의 실제 설정값을 함께 기록한다.

## 별도 조작 검사가 필요한 기능

### APP-V1-BASELINE 결과와 현재 요청

- 반환 영상 `1000326586.mp4`는 24FPS/768프레임/32초로 기대 시간축과 일치한다.
- 14구간은 표본에서 기대 변화와 일치했고, 13(레이어 표시)/14(순서)는 전환이 출력되지 않았다.
- 이후 사용자 확인으로 13번은 전체 프레임 적용 기능을 잘못 시험한 것으로 기대값을 철회했다.
- 남은 기대 불일치는 14번 도형 순서다.
- 자세한 근거와 한계는 [APP-VERIFICATION.md](APP-VERIFICATION.md)에 있다.
- 같은 영상/설정 화면을 재요청하지 않는다.

- 이전 요청은 **APP-V1-ROUNDTRIP: 가져온 합본을 앱에서 수정 없이 SFA로 재내보내기 한 파일**이다.
- 14번 DrawOrder가 저장 왕복에서 어떻게 처리되는지 먼저 비교한다.
- 13번 프레임별 레이어 숨김 재검사는 요청하지 않는다.

- 사용자 보고로는 가져오면 (60,12)가 되는 경향이 있다.
- 이를 실사용 주의로 기록하되 생성 시 FPS·가져오기 초기값·출력 설정을 구분한다.
- (24,24) 출력 성공을 Flutter 보간/편집 버튼/정확한 픽셀 렌더링 검증으로 확대하지 않는다.

### 후속 후보 — 아직 일괄 요청하지 않음

- 그룹/올그룹/해제와 연결점의 동반 이동·회전.
- 원근, 굽힘, 올가미 선택의 실제 버튼 결과 및 기준점.
- 수동 TweenLink, 도형 생성/삭제 사이 보간.
- ObjectScale 단독 변화와 전체/개별 굵기의 결합.
- 레이어 잠금·이름·순서·합치기, 복잡한 채우기 경계·구멍.
- 프레임 복제/정렬/삭제, undo/redo, 저장/불러오기.
- 양파 스킨/축 고정/편집 화면 확대/앵커 표시/빈공간 색 등 편집 보조.

- 편집 보조 기능은 완성 영상에 보이지 않을 수 있다.
- SFA 파일만으로 실제 버튼을 사용한 것처럼 검증했다고 기록하지 않는다.
- 사용자가 모든 기능을 일일이 샘플로 만들게 하기 전에 APK 분석으로 필요한 실험만 좁힌다.

## 효율과 테스트

- 프레임당 최대 20개 AO. 18개 자동 검사가 현재 통과했지만, 자동 검사는 구조·참조·변화 여부를 확인할 뿐 실제 앱 호환성과 표시 일치를 보장하지 않는다.
- 내부 접촉표는 근사 렌더링으로 구성/화면 범위를 확인했고 실제 앱 영상 1차 비교 결과는 APP-VERIFICATION.md에 기록했다.
- 생성 manifest의 app_verified는 재생성 초기값이며 실제 결과를 담는 파일이 아니다.

재생성 및 검사:

```bash
python build_feature_probes.py
python -m unittest discover -s tests -v
```

## 현재 우선순위에 따른 요청 보류

- APP-V1-ROUNDTRIP은 채우기·구멍·순서/글로우/생성·삭제·보간 분석 뒤로 보류한다.
- 추가 작품·전체 기능 샘플·기존 영상 재출력 요청은 없다.
- 기존 근거의 추가 결과와 향후 최소실험 후보는 [FILL-GLOW-TWEEN-ANALYSIS-2026-10-14.md](FILL-GLOW-TWEEN-ANALYSIS-2026-10-14.md)에 있다.
- 후보 목록은 사용자에게 현재 제작을 요구하는 목록이 아니다.
