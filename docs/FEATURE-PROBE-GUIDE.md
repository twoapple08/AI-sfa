# 기능별 시험 파일 v1 — 앱 검증 대기

이 자료는 **전체 기능 분석 완료본이 아니다.** 현재까지 저장 표현을 파악한 항목을 각각 분리해서 검사하는 1차 시험이다. 좌표 변경으로 표현한 이동/회전/늘리기/뒤집기/크기는 앱의 실제 편집 버튼 계산식을 복제했다는 뜻이 아니다.

## 파일

- `examples/probes_v1/feature_probes_v1.sfa`: 16구간 합본, 원본 768프레임.
- `examples/probes_v1/feature_probes_v1.zip`: 합본 + 16개 개별 SFA + manifest.
- `examples/probes_v1/manifest.json`: 기대 결과, 원본 프레임 구간, 미검증 항목.
- `build_feature_probes.py`: 재생성 코드. 원본 앱 코드나 사용자 작품을 복사하지 않고 단순 시험 도형을 생성.

## 먼저 확인할 설정

1. 합본을 현재 Stick Fighter 51.0.0에서 가져온다.
2. **(트위닝 FPS, 재생 FPS) = (24,24)**로 직접 맞춘다. SFA가 이 설정을 전달한다고 가정하지 않는다.
3. 이 설정이면 각 구간 2초, 전체 32초가 목표다. 기본값이 (60,12)로 들어오면 설정을 바꾼다.
4. 화면에 구간 이름을 넣을 텍스트 도형은 확인하지 못했으므로 아래 시간을 기준으로 구분한다.
5. 영상 내보내기는 비교용이다. 출력 영상과 UI의 실제 설정값을 함께 기록한다.

| 2–4초 | 49–96 | 회전 | 골반 기준 좌우 기울어짐 |
| 4–6초 | 97–144 | 늘리기 | 연결된 오른팔 두 선의 길이 변화 |
| 6–8초 | 145–192 | 뒤집기 | 비대칭 팔 자세의 좌우 반전 |
| 8–10초 | 193–240 | 크기 | 몸 전체 크기 변화 |
| 10–12초 | 241–288 | 선 색상 | 빨강에서 파랑으로 변화 |
| 12–14초 | 289–336 | 불투명도 | 파란 몸이 흐려졌다 선명해짐 |
| 14–16초 | 337–384 | 개별 굵기 | 오른팔 두 선만 굵기 변화 |
| 16–18초 | 385–432 | 글로우 | 어두운 배경, 주황 몸의 푸른 발광 변화 |

| 20–22초 | 481–528 | 채우기 색 | 삼각형 내부 색 변화 |
| 22–24초 | 529–576 | 채우기 알파 | 선 유지, 내부만 반투명해짐 |
| 24–26초 | 577–624 | 레이어 표시 | 겹친 빨강/파랑 몸 중 파랑 레이어 숨김 |

어느 구간이 다르게 보이면 그 구간의 개별 파일로 재검사한다. 특히 FR 알파, 레이어 Visible의 프레임별 저장, 글로우 단위 등은 실제 앱 확인이 남아 있다. 다르게 나왔다고 앱 오류라고 단정하지 않고 생성 데이터·importer·렌더러 가정을 점검한다.

## 별도 조작 검사가 필요한 기능

### 지금 요청하는 실험: APP-V1-BASELINE 한 번

합본을 가져와 **(24,24)**로 설정하고 영상 하나를 내보낸다. 실제 설정 화면 한 장도 함께 기록한다. 결과는 [APP-VERIFICATION.md](APP-VERIFICATION.md)에 남긴다. 현재 모두 대기다.

- 기대값: 출력 24FPS/768프레임/32초. 예측값이며 실측값이 아니다.
- 가져오기 자체가 실패하면 오류 화면/문구만 받는다. 메뉴 전체 녹화나 기능별 샘플 16개는 요구하지 않는다.
- 기대표와 다르면 해당 구간만 개별 SFA로 재검사한다. 앱 편집 화면에서도 다른지 확인해 importer/화면 렌더러/출력 경로를 구분한다.
- 저장 왕복과 편집 버튼 연산은 영상만으로 확정하지 않는다. 재저장 SFA 비교는 필요할 때만 요청한다.
- (24,24)는 원본 상태 수용/출력 시험이며 트위닝 정책 검증이 아니다. 보간 실험은 이 결과를 받은 뒤 최소 사례로 좁힌다.

### 후속 후보 — 아직 일괄 요청하지 않음

- 그룹/올그룹/해제와 연결점의 동반 이동·회전.
- 원근, 굽힘, 올가미 선택의 실제 버튼 결과 및 기준점.
- 수동 TweenLink, 도형 생성/삭제 사이 보간.
- ObjectScale 단독 변화와 전체/개별 굵기의 결합.
- 레이어 잠금·이름·순서·합치기, 복잡한 채우기 경계·구멍.
- 프레임 복제/정렬/삭제, undo/redo, 저장/불러오기.
- 양파 스킨/축 고정/편집 화면 확대/앵커 표시/빈공간 색 등 편집 보조.

편집 보조 기능은 완성 영상에 보이지 않을 수 있다. SFA 파일만으로 실제 버튼을 사용한 것처럼 검증했다고 기록하지 않는다. 사용자가 모든 기능을 일일이 샘플로 만들게 하기 전에 APK 분석으로 필요한 실험만 좁힌다.

## 효율과 테스트

프레임당 최대 20개 AO. 18개 자동 검사가 현재 통과했지만, 자동 검사는 구조·참조·변화 여부를 확인할 뿐 실제 앱 호환성과 표시 일치를 보장하지 않는다. 내부 접촉표는 근사 렌더링으로 구성/화면 범위를 확인했고 실제 앱 영상 검증은 대기 중이다.

재생성 및 검사:

```bash
python build_feature_probes.py
python -m unittest discover -s tests -v
```
