## 2. 확인한 것(결함 없음)
- **정적 검사**: 핵심 17개 파일에서 정의 안 된 이름·문법 오류 0. 사소한 것만 있었다(쓰지 않는 변수 `oom_`·`t_step`).

  - 예전 도구 `intake_step4_era.py`는 import가 빠져 실행하면 실패한다. 지금 경로와 관계없다.
- **채점 규칙**(사용자 10-31 '영상이 안 바뀌는 차이는 정답')
  - ID 무시, 점 방향(직선·곡선 뒤집기 짝)
  - 순서: 겹치고 겉모습이 다른 쌍만
  - 면·배경·스타일·점 같은 칸 → 만점
  - 점 연결(AC)은 만점 조건 밖(`sfa_objscore`)
- **판정 통계**: 고정 N, 동점 비승리, 실패는 N에 남김, 단측 α 0.025(`need_wins`), 묶음 한 표, 공식 지표는 두 방향만, 4방향은 진단만.
- **시험 작품 분리**: 조합 묶음 풀·실제 장 모두 `V.file_list()`(시험 파일 제외)를 쓴다. 판정 평가 목록은 학습 파일의 위치 시험이다(설계대로).
- **금지 파일**: 저장소에 가중치·영상·APK·판정 쌍이 없다. 큰 파일은 공개 보관이 허락된 수집 SFA(`data/user_sfa/`)다.
- **이번 대화에서 GPT와 함께 고친 영역**: 학습 진행 시계·마감·마지막 평가 예상·연장·섞기 기록·먼 곡선·큰 원·작은 시험 자료. 위 응답 문서와 회귀 시험으로 확인했다.
