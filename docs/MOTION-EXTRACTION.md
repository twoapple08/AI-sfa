# 영상에서 스틱맨 동작으로 연결하는 전처리 설계

상태: 후보 조사 단계. 아래 모델은 설치·실행·성능 비교를 하지 않았고 프로젝트에 통합되지 않았다.

## 후보

| 목적 | 후보 | 한계 |
|---|---|---|
| 사람 몸·손·얼굴의 의미 있는 관절점 | DWPose | 애니메이션 분포에 대한 정확도는 별도 평가 |
| 애니·일러스트 인물 포즈 | bizarre-pose-estimator | 일러스트 포즈 연구 모델로, 영상 전체 추적이나 SFA 변환 도구는 아님 |
| 지정한 점을 영상에서 추적 | CoTracker3 | 점의 궤적을 추적하며 "이 점은 팔꿈치"라는 의미를 자동 제공하지 않음 |
| 물체·인물의 픽셀 영역과 윤곽 | SAM 2 | 영상 segmentation이지 자동 벡터화나 관절 생성이 아님 |

## 권장 전처리

순서: 샷 분할 → 인물·물체 분리 → 관절 검출 또는 사람이 기준점 지정 → 시간 방향 점 추적 → 불확실한 프레임 검수 → 스틱맨·도형으로 대응 → SFA 출력.

**사람**
- 어깨·팔꿈치·손목·골반·무릎·발목 등을 매핑한다.
- 스틱맨 머리 원의 지름 양 끝과 관절점 검출기의 코·눈·귀 점은 같은 데이터가 아니다. 별도 머리 모델이 필요하다.
- 관절 중심 하나가 SFA에서는 여러 AP 끝점과 연결 참조로 표현될 수 있다.

**물체·효과**
- 칼은 손잡이와 끝점으로 이동·방향을 근사할 수 있다. 원근·굽힘·블러까지 복원되지는 않는다.
- 상자 등은 꼭짓점과 내부 기준점을 추적한다.
- 연기·불·스미어는 고정 골격보다 윤곽·변형·효과 도형으로 따로 표현한다.
- 물체의 관절 구조는 별도로 정의해야 한다.

**검수 항목**
- 카메라 이동, 가림, 좌우 관절 바뀜, 컷 전환, 반복 프레임, 임팩트 프레임, 스미어를 검수한다.
- 스미어를 포즈 추정 오류처럼 평활화하지 않는다.
- 가려진 점을 검증 없이 정답으로 보충하지 않는다.
- 신뢰도·가시성·수정 이력을 보존한다.

**범위와 실행 위치**
- 추출은 관찰된 동작의 데이터화다. 새로운 행동을 창작하는 학습·생성과는 별개다.
- 데이터 전처리는 외부 GPU 또는 고성능 PC에서 수행하고, 앱에는 검수한 데이터나 경량화 모델을 배포하는 구성을 우선 검토한다.
- 일반 폰에서 무거운 후보를 모두 동시에 실행하는 것은 목표로 두지 않는다.
