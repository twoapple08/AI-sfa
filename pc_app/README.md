# Stick Fighter PC (개인용 임시판, 2026-10-28)

브라우저에서 여는 .sfa 편집기. 로그인 없음. 앱 코드·그림 자원은 쓰지 않고, 저장소의 SFA 형식(`sfa.py`)과 그리기 규칙(`tools/sfa_render.py`)으로 새로 짰다.

- 기능: .sfa 열기·저장(앱 형식, 열 때 채우기 면·모르는 속성 보존), 직선·곡선·원 그리기(기존 점에서 시작·끝내면 관절로 이음), 점·오브젝트 이동(이어진 점 함께), 색·알파·굵기·글로우(정수), 장 복제·빈 장·삭제·순서 바꾸기, 레이어(추가·숨김·잠금·이름), 어니언 스킨, fps 재생, PNG 내보내기, 되돌리기.
- 없음: 채우기 면 새로 만들기·편집(열린 파일의 것은 표시·보존), 트위닝 미리보기, 오브젝트 회전·크기 도구.
- 검증(서버, 헤드리스 Chromium): 예제 3개(막대인간·글로우·채우기)와 글로우 켜진 장의 1920×1080 렌더가 `sfa_render.py`와 평균 차 0.00–0.01. 마우스로 그린 파일을 저장 → `sfa.py validate` 오류 0. 앱에서 연 확인은 아직 없음.
- 쓰는 법: `stickfighter_pc.html`을 브라우저로 연다(JSZip을 cdnjs에서 받음). 인터넷 없이 쓰려면 JSZip을 넣은 오프라인판을 쓴다.
